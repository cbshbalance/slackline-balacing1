# v22 발표 무대 운용 — 조종석 · 무대 · 측정실 (2026-09-03)

전람회 발표(3분 + 질의응답 10분)를 v22 서버 하나로 돌린다. 창은 셋, 모니터는 둘.

| 창 | 주소 | 어디에 | 무엇 |
|---|---|---|---|
| **조종석** | `/deck` | 노트북 | 큐 8개(←/→, PgUp/PgDn, 발표 리모컨, 숫자키), 로봇 명령, 상태 판독, 트윈 미리보기, 질의응답 버튼, 옛 버전 갤러리 |
| **무대** | `/show` | 세로 큰 모니터 (전체화면 F) | 조종석 신호대로 한 창 안에서 장면 전환: 실사 영상(재생·휘청 반복+오버랩·모델 변신), 트윈(+상태공간), 상태공간 크게(ε* 기하), 옛 시뮬 iframe, 식 카드 |
| **측정실** | `/lab` | 실험 날 노트북 / 질의응답 때 무대에 | 엑셀 방식: 원본 표 + 시간 차트 + XY 차트, 구간 드래그 → 추세선(선형·지수→λ·감쇠사인→ω·놓기점→r·추천), 선택 구간 TSV 복사 |

로거 앱(`/`)은 그대로 있다(고급 조작·콘솔·파이프라인).

## 1. 현장 설정 (5분)

1. 노트북 HDMI → 큰 모니터. 윈도우 디스플레이 설정: **확장**, 큰 모니터만 **90° 회전**(세로).
2. `run_v22.bat`(또는 `python server.py`) → 브라우저에서 `http://localhost:8220/deck`.
3. 조종석의 「무대 창 열기」 → 새 창을 큰 모니터로 끌어다 놓고 그 창에서 **F**(전체화면). 커서는 자동으로 숨는다(**C** 로 토글).
4. 로봇 USB 연결 → 조종석 「연결」. 칩에 `COMx @115200 · 100 Hz` 가 뜨면 D행이 들어오는 것.
5. 좌우 확인: 로봇을 손으로 왼쪽으로 기울여 무대 트윈도 왼쪽으로 가는지 본다. 반대면 조종석의 「무대 좌우 반전」.
6. (선택) 1:1 축척: 모니터 가로 mm 와 가로 px 를 넣고 「적용」 → 트윈 프레임이 실물 크기로.

무대 창은 발표 중 손대지 않는다. 모든 전환은 조종석에서.

## 2. 발표 큐 (조종석 1~8)

| 큐 | 무대 | 로봇 | 말 |
|---|---|---|---|
| 1 문제 | 실사 재생 → 끝에서 정지 | 매달림(대기) | 서양은 장대. 한국 광대는 부채뿐. 어떻게? |
| 2 발상 | 휘청 구간 반복 + 모델 오버랩(동기) | | 줄이 흔들리니 발을 옮길 수 있다. 무게중심 너머로 던지면 뒤집힌다 |
| 3 수단 | 트윈 | 「접기 시연 δ 20→0」 (mode 0, k 토크ON 상태) | 허리를 접어 발을 옮긴다. 비례해 접자 = ε |
| 4 균형의 재정의 | 트윈 + 원위치 평면 | 손으로 안정모드선 위에 놓고 뗀다 | 균형 = 줄과 함께 흔들리는 것 |
| 5 모드 | 원위치 평면 크게(±6°) | 손으로 기울인다 | 안정모드 직선, 벗어나면 발산. 불안정모드 소거 = 균형 |
| 6 ★클라이막스 | 평면 + ε* 기하 (흰 점선·초록 점) | 손으로 기울여 교점을 보인다 | 접기는 무게중심 불변 직선을 따른다. 교점 = ε* 닫힌해 |
| 7 한계와 답 | 트윈 + 예측점 평면 | mode 2 · g · 놓기 | 넣어도 안 선다(말안장). 자란 만큼 다시 접는다 |
| 8 방점 | 트윈 크게 + HUD(유지 시간·접기 횟수) | 균형 유지 중 | 그 로봇이 어름이다 |

## 3. 질의응답 버튼 (조종석 오른쪽 아래)

실사 반복+오버랩 · 실사→모델 변신 · 트윈 크게 · 트윈+원위치 · 트윈+예측점 · 원위치/예측점 크게 · **ε\* 기하(라이브)** · v21 발표 시뮬(/pres) · 측정실 차트 · ε\* 카드 · 검은 화면 · 옛 버전 시뮬(V1~V18, 무대 또는 노트북에서).

"어떻게 λ 를 쟀나" → 측정실 차트를 무대에 올리고 구간을 드래그해 지수 추세선을 보인다.
"이론을 설명해 달라" → 로봇을 손으로 잡고 ε\* 기하: 기울이면 흰 점선(무게중심 불변 직선)과 초록 점(접으면 가는 곳)이 따라온다.

## 4. 안전판

- 로봇이 안 서는 날: 조종석 「끊기」 → 로거 앱에서 `logs/` 의 좋은 주행을 불러오고 재생(▶). 무대의 트윈·평면·HUD 는 재생 데이터로 똑같이 움직인다.
- 장치 없이 연습: 조종석 「가짜: MuJoCo」 → 가상 로봇. 로거 앱 콘솔에 `sim release 1 0` (β=1°, φ=0° 로 잡았다 놓기), `sim hold 0.3 0`, `sim free`.
- 인터넷 불필요(외부 CDN 없음).

## 5. 실사 오버랩 씬의 동기

`tools/track_jultagi.py` 가 `presentation/media/jultagi_6s_stab.webm` 에서 광대의 발 위치·상체 기울기를 프레임마다 추적해 `static/media/jultagi_trace.json` 을 만든다. 무대는 그 파일이 있으면 영상의 `currentTime` 에 맞춰 모델의 φ·β 를 그 궤적으로 구동하고, 휘청 구간 `[t_a, t_b]` 를 위상이 맞는 지점에서 잘라 반복한다(모델과 영상이 같이 까딱거린다). 파일이 없으면 합성 흔들림(2.2°, 1.15 s)으로 대신한다. 화면 좌우 부호는 카메라 투영으로 자동 보정.

정합 카메라·기하는 /pres 의 8/17 결과 그대로(az 140.61, el −5.42, dist 15.19, fov 30, roll −3.01; 영상의 y 607~1407 띠 = 사진). 선 굵기 `thk` 2.6, 몸 굵기 1.7 (조종석 신호 `args.thk/body` 로 조절).
