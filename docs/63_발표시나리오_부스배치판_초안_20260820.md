## 3. 씬 체인 사용법 (v21)

- `v21_pres/scenes/chain.json` 이 씬 배열. **`]` = 다음 씬, `[` = 이전 씬.** 좌하단 HUD 에 씬 번호·제목·발표자 노트 표시(5초 후 흐려짐).
- 액션 어휘: `click`(버튼) / `check`(체크박스) / `send`(서버 명령) / `dm`(키네마틱 시연) / `fs`(평면 전체화면/해제) / `presmode`(발표 모드).
- **순서 교체·씬 추가 = chain.json 수정 후 새로고침.** 코드는 건드리지 않는다 (문서 56 §3F 요구사항).
