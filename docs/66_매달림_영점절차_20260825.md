# 66. 엔코더 영점 — 매달림 절차 (2026-08-25)

> 배경: 절편 ~1° 문제. 영점 오차 1° = A 오프셋 1° > 트리거 0.6° — 로봇이 똑바로 서 있어도
> "기울었다"고 믿고 접기 시작 → 한쪽으로 밀려 낙하. 눈대중 수직 세우기의 정확도가 딱 이 급.
> 원리: 눈대중은 기하학적 축을 세우지만 균형 변수 β 는 **질량중심** 기준이다. 매달면 중력이
> CoM 축을 직접 연직에 정렬한다 — 더 정확한 게 아니라 애초에 맞는 기준.

## 절차 (세션당 1회, 재조립 후 필수)

1. **최종 조립 상태 그대로**(USB 케이블·테이프 포함) 서보 토크 OFF, 로봇을 줄에 매달아 완전히 멎을 때까지.
2. **양방향 정착 평균**: 건마찰 데드밴드 대응 — 왼쪽에서 접근해 멎은 판독과 오른쪽에서 접근해
   멎은 판독을 각 채널(φ·발목·δ) 기록 → 중간값을 영점으로.
3. 오프셋 저장: **φ=0, α=180°, δ=0** (크랭크 수직 / 몸통 CoM 이 발목 아래 / 상체 CoM 이 힙 아래).
4. ⚠ **서는 자세 변환은 코드 한 곳에서**: α_직립 = α_매달림기준 + 180°. 이 플립이 ±180° 래핑이
   사는 자리 — 래핑 안전하게 단일 지점 처리 (펌웨어 검토 체크 항목).
