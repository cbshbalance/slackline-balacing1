1. 이 PC에서 작업·검증한 변경을 커밋하고 GitHub로 푸시한다.
2. 다른 PC에서 해당 변경을 받아 작업한다. 미커밋 변경은 자동 전송되지 않는다.

## 원격에서 같은 PC로 이어가기

2026-09-06에 확인한 [OpenAI 공식 Remote 안내](https://learn.chatgpt.com/docs/remote)에 따르면 휴대폰에서 연결된 Mac/Windows PC의 작업을 시작하거나 이어갈 수 있다. 제공 여부는 배포 상태와 워크스페이스 설정에 따른다.

1. 이 PC의 데스크톱 앱에서 Settings → Connections → Control this Mac or PC → Set up 또는 Add를 선택한다. 공식 문서는 앱을 ChatGPT desktop app으로 표기한다. 설치 버전에 따라 표시가 다를 수 있다.
2. 원격 접근 승인과 요청되는 인증을 진행한다.
3. 휴대폰으로 QR 코드를 스캔하고 같은 ChatGPT 계정·워크스페이스로 로그인하여 연결을 승인한다.
4. 휴대폰 ChatGPT 앱에서 Remote → 이 PC → 기존 작업을 연다. 새 작업이면 '줄타기' 프로젝트와 로컬 작업을 선택하고 이 메인 폴더를 사용하도록 지정한다.
5. PC가 켜져 있고 인터넷에 연결되어 있으며 절전 상태에 들어가지 않도록 유지한다.

이 방식은 연결된 PC에서 작업을 실행하므로 GitHub로 파일을 옮길 필요가 없다. 현재 세션에서 원격 페어링이나 휴대폰 접속 성공은 확인하지 않았다. 메뉴가 없으면 앱 업데이트 및 계정/워크스페이스의 기능 제공 여부를 확인한다.
