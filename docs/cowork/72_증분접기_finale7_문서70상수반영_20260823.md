## 2. 핵심 구조 변경 — λ 와 κ 를 분리했다

finale6 의 `lam 2.97` 은 λ 실측값이 아니라, 속도항을 키우려고 λ 자체를 낮춰 놓은 임시방편이었다.
문제는 λ 가 A 에만 쓰이지 않는다는 것이다.

```
w = [ −1/r , 1 , −κ/(rλ) , κ/λ ]
```

- **A 안에서는** λ 와 κ 가 `λ/κ` 라는 비로만 나타난다 → 5.44/1.5 = 3.63 /s = "0.28 초 앞을 본다"
- **A 밖에서는** λ 가 단독으로 배가시간 T₂ = 693.1/λ 을 통해 사이클 길이 판정·화면 표시에 쓰인다

즉 finale6 은 배가시간을 **233 ms** 로 믿고 있었는데 실측은 **127 ms** 다.
`deriveConstants()` 의 속도항에만 κ 를 곱하고, λ 는 물리값으로 되돌려 둘을 갈랐다.

근거: `w_속도 = w_위치·(λI − C)⁻¹` 이고 `1/λ` 는 감쇠 C = 0 일 때만 성립하는 항등식이다 (문서 54 §1).

**γ 를 9 까지 올려도 계속 실패한 원인이 γ 가 아닐 수 있다.** 손댈 순서:

1. `rest 30` — REST 60 → 30 ms. 사이클 116 ms = 0.91·T₂. 가장 싸다
2. `acc 500` — FOLD 단축. ⚠ 전압 강하 — `b` 로 먼저 확인
3. `trig 0.5` — 접기량이 줄어 FOLD 도 짧아진다. ⚠ 잡음 바닥 0.15° 이하일 때만
4. `kv 1.8` — 실측 범위 위끝. 더 일찍 본다

`t` 명령이 이제 "한 사이클 ○○ ms = 배가시간의 ○.○○ 배" 를 찍고, 1.0 을 넘으면 경고한다.

## 4. ★FOLD_SIGN — 아직 못 골랐다. 기본값을 바꾸지 않았다

서로 반대로 답하는 논증이 둘 있다.

**논증 A → sgn = +1** (finale6 채택). 매달기 시험에서 +δ 는 발목각 α 를 − 로 보냈다 (기울기 −0.4285).
β>0 일 때 발이 무게중심을 지나쳐야 하므로 +δ.
※ 매달기에서는 무게중심이 축 아래에 매달려 **β 가 보존된다**. 이 시험은 δ→α 만 말해 주고 δ→β 는 말해 주지 않는다.

**논증 B → sgn = −1** (판정식 미분). β = α + P2R·δ, A 의 β 계수 = +1 이므로 ∂A/∂δ = +P2R > 0.
|A| 를 줄이려면 Δδ 가 Â 와 반대부호여야 한다 → sgn = −1.
※ "δ 를 접는 순간 α 는 안 변한다" 를 전제한다. 논증 A 는 그 반대를 전제한다.

**두 전제 중 어느 쪽이 줄 위에서 참인지는 계산으로 못 가른다.** finale6 헤더도 "이건 예측이지 측정이 아니다" 라고 이미 적어 두었다.

### 판정 방법 두 가지 (펌웨어에 넣어 두었다)

- **바닥 시험**: `y` dry-run 에서 접기가 걸릴 때마다 `[DRY] Ahat=… -> dcmd ±○○ deg` 한 줄이 찍힌다. 그 방향으로 손으로 허리를 접어 로봇이 **기울어진 반대쪽으로** 돌아오는지 본다.
- **로그 사후 판정**: 접기 직후 |Â| 가 줄어들면 맞다. 커지면서 `hold` 가 한 방향으로만 ±55° 까지 쌓이면 **반대다**.
  ⚠ 이 증상은 "γ 가 작다" 와 똑같이 보인다. **구분법: γ 를 2 배로 올렸는데 더 빨리 ±55° 에 붙으면 γ 문제가 아니라 부호 문제다.**

## 5. 부수적으로 고친 것

- `dumpSource()` 버그: `ilim`·`vmin` 이 둘 다 `ENC_FAIL_MS` 로 찍혀 나왔다. `d` 출력을 그대로 붙여넣으면 컴파일이 안 됐다.
