# 모터 토크·속도 수지 재계산 — "토크는 남고 속도가 병목" (2026-08-07)

> ★다른 세션이 먼저 읽어야 할 문서. 실측 질량표(7/30-31) + 실측 λ_u=6.68(문서 38) 기준 재계산.
> 결론: **모터 토크는 충분하다. 회복 천장을 정하는 것은 속도이고, 지금은 그 속도조차 우리 설정이 먼저 막고 있다.**

## 1. 핵심 — 유효 관성이 두 개다 (혼동 금지)

| 상황 | 서보가 느끼는 관성 | 근거 |
|---|---|---|
| **줄 위 (자유)** | **0.0059 kg·m²** | 모달 J_δ=0.0076 → φ·β 자유 반응의 Schur 보수 0.0029 **+ armature 0.0030** |
| 지그·손으로 잡음 | 0.0477 kg·m² | 하체 고정 → 상체 전 관성 J_θθ=0.0447 + armature |

**8배 차이.** M2 실험의 I_δ=0.045는 지그값이며, 줄 위 접기에는 그 1/8만 상대한다
(접기 반작용으로 하체·줄이 반대로 움직이기 때문 — FWE '발 던지기'의 뒷면).
⚠ 이 둘을 섞으면 토크 판단이 8배 틀린다.

## 2. 토크 수지 — 충분하다

- 스톨 3.0 N·m(2.3A)로 줄 위에서 가능한 각가속도 = **475 rad/s² = 27,000°/s²**
- 현재 설정 `PROF_ACC=250`(5,364°/s²)이 요구하는 토크 = **0.55 N·m = 스톨의 18%**
- 정적 유지: δ=40° → 0.48 N·m, δ=55° → 0.64 N·m (연속 정격 안쪽)
- **강건성**: I_δ가 2배 틀려도 필요 토크 1.1 N·m(37%) — 속도 지배 구조라 결론 불변

## 3. 진짜 한계 — 속도, 그리고 회복 천장

접기는 시작 1~2ms에 속도 한계(무부하 462°/s, 부하 시 ~420)에 붙는다. 전 구간 속도 제한.
배가시간 104ms(λ_u=6.68 실측) 안에 끝나야 의미가 있으므로:

| 접기량 | 모터 한계 | 현재 설정(acc250) | 회복 가능 β |
|---|---|---|---|
| 10° | 46ms | 86ms | 1.5° |
| 20° | 73ms | 122ms | 2.8° |
| 30° | 97ms | 150ms | 3.8° |
| 40° | 121ms (>배가시간) | 174ms | 4.8° |

**모터를 다 쓰면 β ≈ 4.0°까지 회복 가능** — 시뮬 예측 A*≈3°(v19_sim README #11)와 정합.
모델 검증: r11 깨끗한 계단 4개 = 4.5°/26ms(174°/s) vs 모델 5°/31ms(161°/s) — 일치.

## 4. ★조치 목록 (미적용 — 다음 세션에서 처리)

1. **`fwe_async_v19.ino`의 `PROF_ACC_UNIT` 250 → 600** (12,875°/s², 필요토크 1.33 N·m = 스톨 44%).
   효과: 20° 접기 122→81ms, 회복 천장 β 2.8°→3.6°.
   ⚠ 벤치에서 잡을 사람 두고 적용할 것 — 결합부 7 Hz 진동(문서 32·33 미해결)을 더 세게 두드린다.
   `PROF_VEL 300`(412°/s)은 무부하 462의 89%라 더 올릴 실익 없음.
2. **`v19_bringup/params_v19.py`가 placeholder로 되돌아가 있음** (8/6 저녁 push, m1=0.15·m2=0.55·
   c_phi 정정 소실). compute_gains·sim_check가 잘못된 값을 쓰므로 실측판 복원 필요.
   실측 정본: m1=0.1094, m2=0.6406, L1=0.259, L2=0.375, ell1=0.084, ell2=0.1917,
   I1_cm=8.85e-4, I2_cm=2.116e-2, I_r=4.50e-3, c_phi=3.3e-4, tau_coulomb=3.1e-4.
3. (선택) 로그만 100Hz로 데시메이션 — 제어 200Hz 유지. D행 51B라 200Hz 스트리밍이
   115200baud의 89%를 먹는다(실험② 펌웨어가 167Hz로 주저앉은 실제 원인).

## 5. 설계 함의 (보고서감)

토크가 남고 속도가 병목이므로 **더 센 모터로 바꿔도 소용없다.** XM430-W210은 이미 계열에서
빠른 쪽(212.6:1, 77rpm)이라 여기서 더 얻기 어렵다. 남은 길은 **로봇을 키우는 것** —
λ ∝ L^(−1/2)이라 크면 배가시간이 늘어 같은 서보로도 여유가 생긴다. 형상 최적화(6/15)의
"전체 길이↑가 큰 레버" 결론과 정확히 같은 이야기이며, 실물 수치로 뒷받침된 셈이다.
