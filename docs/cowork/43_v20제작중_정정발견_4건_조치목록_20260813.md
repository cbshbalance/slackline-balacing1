## ① γ_cyc 이 e^{λT_rest} 배 과대하다 — 확정

### 무엇이 문제인가

`model_v19.fwe_map_constants` 는 사이클 맵 `A⁺ = G_cyc·A⁻ − g_cyc·δ_f` 의 두 상수를
**서로 다른 구간에서** 잰다.

```python
A_end2, _ = _simulate_A(F, b, w, lu, sched, zero)   # sched = 접기+대기+펴기 (휴지 없음)
gc = -A_end2
Gc = float(np.exp(lu * (Tf + Tw + Te + Trest)))     # ★휴지 포함
```

휴지는 자유 전개이므로 그 사이 A 는 e^{λT_rest} 배가 된다. **g 에도 같은 배율이 붙어야**
짝이 맞는데 지금은 G 에만 붙어 있다. 따라서 γ = G/g 가 그만큼 부풀어 있다.

### 근거 — v19 자신의 캘리브레이션 코드

`v19_sim/sim_engine.py` 의 `fwe_autocal()`, 즉 실측 γ\*=18.6 을 만든 함수:

```python
if ph0 == PH_IDLE  and phase == PH_FOLD  and Ap is None:
    Ap, dfp = self.risk_A(xe), self.fwe["df"]     # A⁻ = 트리거 시점
if Ap is not None and ph0 == PH_REST and phase == PH_IDLE:
    rows.append((Ap, dfp, self.risk_A(xe)))        # A⁺ = ★휴지 끝
```

**실측 맵은 접기→대기→펴기→휴지 전체 구간**이고 G\*·g\* 짝이 같은 구간에서 나온다.
실측이 정합이고 이론이 부정합이다.

### 수치

| 세트 (시간표) | v19 γ_cyc | 정정 γ_cyc | 비 = e^{λT_rest} |
|---|---:|---:|---:|
| 로봇 · 설계추정 (60/20/90/**60**) | 39.382 | **26.875** | 1.465 |
| 로봇 · 실측정본 (150/20/90/**60**) | 24.693 | **17.423** | 1.417 |
| 문서 08 시간표 (80/60/80/**50**) | 30.03 | **21.86** | 1.372 |
| 사람 스케일 (T_rest = 0) | — | 동일 | 1.000 |

정정 후 δ_f = γ_cyc·A 가 사이클 끝에서 A 를 **1e-11°** 로 지운다(deadbeat 검증 통과).
정정 전 잔여는 −2.71° 였고, 이 알람이 문제를 드러낸 계기다.

### 서사에 미치는 영향

문서 08 시간표 기준, 실측 γ\* = 18.6 대비:

| | γ | 실측 대비 | g 로 보면 |
|---|---:|---:|---|

**"이론 28.9 vs 실측 18.6" 갭의 대략 3/4 이 장부 오류이고, 실제 실행 갭은 나머지 1/4 정도**로 보인다.

### 왜 v19 때는 안 드러났나

1. **이론 γ 로는 원래 안 섰다.** NIGHT_LOG 기록대로 공칭 γ FWE 는 발산했고 γ\* 로 바꾼 뒤에야
   유계가 됐다. γ 가 1.46배 크면 과접기 → 유효 ρ 가 수축창 밖 → 발산. 증상이 정확히 그랬는데
   그 발산이 전부 "실행 프로파일 갭" 으로 해석됐다.
2. **가장 강한 검증(결정 실험)이 이 자리를 비껴간다.** "실제 δ(t) 를 이론식에 넣으면 0.16° 일치"는
   **마스터 전파법칙**을 한 궤적 위에서 검증한 것이다. 문제는 전파법칙이 아니라
   **(G, g) 를 어느 시점에서 재느냐**이므로 궤적 검증으로는 잡히지 않는다.
3. **model_v19 의 assert 3개가 전부 구조 검산이다** (φ행 δ열=0, G의 δ열=0, 무질량 극한 ε\* 복원).
   "δ_f = γ·A 를 넣고 실제로 돌리면 A⁺=0 인가" 라는 자기일관성 검사가 없다.

### 아직 확정 아닌 부분

문서 08 의 공칭 g = 0.197 과 v20 계산 0.184 가 **7% 어긋난다**(파라미터 세대 차로 추정).
45사이클 최소제곱을 재현한 것도 아니다. 위 "3/4" 는 **자릿수 추정**이다.

## ② 감쇠 포함 예측점 일반형 — 문서 41 '남은 일 ②' 해소 · 확정

### 문서 41 이 물었던 것

불안정 모드를 읽는 벡터가 프로젝트 안에 **두 개** 있다.

| | u₂ (문서 41 의 지도) | w (문서 16·38·실기) |
|---|---|---|
| 어디서 | **무감쇠** 2×2 `A₂ = M₂⁻¹G₂` | **감쇠 포함** 4×4 `F₄` |
| 차원 | 2 (위치만) | 4 (위치 2 + 속도 2) |

문서 41 의 닫힌형 `δ_f* = −u₂ᵀq_pred/(k·u₂ᵀe)` 는 u₂ 를 쓰는데 실기는 w 를 쓴다.
**바꿔 끼워도 형태가 살아남는가?** — 단순 계수 문제가 아닌 이유는, 무감쇠에서는
`u₂ᵀq_pred = 2A` 라는 **등식**이 성립해서 "예측점이 안정선 위 ⟺ A=0" 그림이 정확했기 때문이다.
이 등식이 깨지면 평면 위 직선이라는 그림 자체가 무너진다.

### 답 — 형태는 살아남는다, 단 예측점의 정의가 바뀐다

w = (w_q, w_v) 로 쪼개고 `wᵀF₄ = λwᵀ` 를 블록으로 쓰면

```
w_v A₂ = λ w_q
w_q + w_v D̂ = λ w_v      →   w_q = w_v (λI − D̂)
```

따라서

$$A \;=\; w_q\!\cdot\! q + w_v\!\cdot\!\dot q \;=\; w_q^{\mathsf T}\Big[\, q + (\lambda I - \hat D)^{-1}\dot q \,\Big]$$

D̂ = 0 이면 w_q = λw_v 이므로 **기존 q + q̇/λ 가 정확히 복원**된다.
u₂ 자리에 w_q(β성분=1 정규화)를 넣고 예측점을 위 형태로 일반화하면
`δ_f* = −A/(k·w_qᵀe)` 가 그대로 성립한다.

### 실제로 필요했다는 증거

로봇 실측정본의 w = (0.6043, 1, **0.1040**, **0.1686**), λ_u = 5.813:

| 성분 | 값 | w_q/λ | 일치? | 왜 |
|---|---:|---:|:--:|---|
| w_φ̇ | 0.1040 | 0.1040 | **일치** | c_φ ≈ 0 → φ행 감쇠 거의 없음 |
| w_β̇ | 0.1686 | 0.1720 | **불일치** | B_θ = 0.01 이 β행에 감쇠를 만듦 |

두 행이 다르게 어긋나는 것이 이 구조의 지문이다. 단순 `q + q̇/λ` 로 찍으면 A 와 어긋난다.

### 부수 효과

**안정선(A=0)의 기울기가 무감쇠 r 과 미묘하게 다르다.**
설계추정에서 r = −1.5347 인데 A=0 선은 φ = −1.5552·β 다.
판정선이 곧 그림이어야 하므로 v20 은 초록선으로 **A=0 선**을 그린다.

문서 41 의 예상("계수만 바뀔 것")은 **절반 맞았다** — 계수만이 아니라 예측점의 정의도 바뀐다.

- [ ] 보고서 **Ⅸ-2** 의 예측점 정의에 감쇠 일반형 병기 (현재는 q + q̇/λ 만 적혀 있다)

## ④ 실기 파라미터 δ_f\* 지도 — 문서 41 '남은 일 ①' 해소 · 완료

$$\delta_f^*[\deg] \;=\; c_\beta\,\beta_{\text{pred}} \;+\; c_\varphi\,\varphi_{\text{pred}}$$

| 세트 | c_β | c_φ | r (무감쇠) | k |
|---|---:|---:|---:|---:|
| 사람 스케일 R=0.7 (문서 41 재현) | 13.029 | 6.148 | −2.1194 | 0.21748 |
| 로봇 · 설계추정 | 9.533 | 6.130 | −1.5347 | 0.21424 |
| **로봇 · 실측정본** | **6.144** | **3.713** | −1.6344 | 0.35167 |

사람 스케일 값이 문서 41 과 **차이 ≤ 0.02%** 로 일치하는 것으로 이식이 검증됐다.

### 함께 나온 주의사항 — 문서 41 의 k 식을 로봇에 그대로 쓰면 안 된다

문서 41 은 `k = μ·M_t R²/det M₂` 로 적었는데 이는 **무질량 줄 전용**이다.
줄 관성이 있으면 M₂[φφ] = M_tR² + I_r 이므로 일반형은

```
Δq = k·δ_f·e ,   e = (s, −1),   s = M₂[φβ]/M₂[φφ] ,   k = μ·M₂[φφ]/det M₂
```

I_r = 0 이면 s = h/R, k = μM_tR²/detM₂ 로 문서 41 의 식이 정확히 복원된다.
**그대로 쓰면 설계추정 세트에서 10.7% 틀린다.**
