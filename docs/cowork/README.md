# docs/cowork — 코웍(채팅) 쪽 연구문서 정본

이 폴더는 **클로드 코웍 프로젝트 "줄타기"** 에 쌓인 연구문서를 저장소로 옮겨 놓은 것이다.
2026-08-25 에 일괄 백필했다.

## 왜 따로 두는가 — 문서 번호가 두 갈래다

이 연구에는 **번호 체계가 두 개** 있고, 8/19 부터 갈라졌다.

| 갈래 | 위치 | 번호 60~67 이 가리키는 것 |
|---|---|---|
| **클로드 코드 (v21_pres)** | `docs/` 바로 아래 | 60 = v21 후속개발 로드맵, 61 = 접기스파이크 재검증, … 67 = 놓기프로토콜 v2 |
| **코웍 채팅 (이 폴더)** | `docs/cowork/` | 60 = 증분접기 실기펌웨어, 61~65 = 발표흐름, 66~70 = 실측 ②·③, … 78 = single_fold_host |

번호가 겹치므로 **덮어쓰지 말고 폴더로 갈라 두었다.**
문서를 인용할 때는 `docs/61_…` 인지 `docs/cowork/61_…` 인지 경로까지 밝힐 것.

## 무엇이 들어 있나 (36 개, 문서 37~78)

8/1 이후 코웍에서 만들어졌고 저장소에 없던 것 전부.

- **37~45** 브링업·토크수지·예측점평면·v20 시뮬·실측 실험설계
- **47·48·52·61~66** 발표 영상/앱/흐름/대본
- **52(P2R 펌웨어)·60·71·72·73·76·77·78** 펌웨어·호스트 제어 개발 기록
- **64~70** 실측 ②·③ (P2R 0.433, λ 5.44, r·c₀) 과 최종 정리
- **74·75** 이론 공부 (모드해석의 기원, 제어 기호 사전)

이미 `docs/` 에 올라가 있던 46·49·50·51·53~59 는 중복 방지를 위해 넣지 않았다.

## 앞으로 — 왜 안 올라갔나

`git_auto_sync.bat` 은 5 분마다 도는 것으로 되어 있으나 **"자동 동기화" 커밋이 한 건도 없다.**

(`incremental_fold.ino`, `70_measurements_final.md`, `lambda test/`, `p2r test/`, `r test/` 등).
