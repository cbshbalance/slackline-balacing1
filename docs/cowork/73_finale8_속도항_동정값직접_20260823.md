# 73. finale8 — 속도항을 κ 로 흉내 내지 말고 동정값을 직접 넣는다 (2026-08-23)

> 문서 72(finale7) 의 §2 를 대체한다. 나머지(FOLD_SIGN 미결, 사이클 빠듯함, 부수 수정)는 그대로 유효하다.
> 사용자 지적: **"κ = w_v ÷ (w_q/λ) 가 κ 의 정의인데, 거기에 w_v 가 들어가 있잖아.
> 그러면 실측한 w_v 를 그냥 대입하는 게 더 정확하겠다. 람다는 5.66 으로 두고."**

---

## 1. 지적이 맞다 — κ 는 유도 단계가 하나 더 있는 표현일 뿐이다

문서 70 §7-2 가 κ 를 계산한 방식이 바로 그 정의다:

```
κ_φ̇ = w_v[0] ÷ (w_q[0]/λ) = 0.1945 ÷ 0.1174 = 1.658
κ_β̇ = w_v[1] ÷ (w_q[1]/λ) = 0.3049 ÷ 0.1768 = 1.726
```

즉 **κ 를 계산하려면 이미 w_v 를 알고 있어야 한다.** 그런데 finale7 은 그렇게 얻은 κ 를
다시 `w_v = κ·w_q/λ` 로 되돌려 쓰고 있었다 — 왕복이고, 그 왕복에서 손해가 난다.

| | finale7 (κ 경유) | **finale8 (직접)** |
|---|---|---|
| 필요한 값 | r, λ, κ | r, wf, wb |
| 근사 | 두 성분(1.658/1.726)을 **스칼라 하나로 뭉갠다 — 3.9 % 손해** | 없음 |
| λ 가 A 에 | 들어간다 (λ/κ 로) | **안 들어간다** |

## 2. ★가장 큰 이득 — λ 가 A 에서 빠진다

λ 에는 값이 두 개 있다.

| 출처 | λ | 무엇을 쟀나 |
|---|---|---|
| 문서 65 (실측 ③) | 5.44 ± 0.59 | φ 의 배가시간, 놓기 18 회. **모델 없이** |
| 문서 69 (실측 ②) | 5.66 ± 0.09 | 4×4 동정의 불안정 고유값 |

finale7 에서는 이 선택이 A 의 속도항을 4 % 흔들었다. **finale8 에서는 아무 영향이 없다.**
λ 는 배가시간 표시(T₂ = 693.1/λ)와 사이클 길이 판정에만 남는다.

**그래서 `lam` 은 5.66 으로 둔다** — w 와 같은 동정에서 나온 값이므로 한 묶음이다.
(T₂ 122 ms vs 5.44 의 127 ms. 사이클 판정 결론은 어느 쪽이든 안 바뀐다.)

## 3. 새 파라미터

```c
float R_SLOPE = -1.506f;   // [r ] 위치항 — 독립 3 경로 확인 (단단하다)
float WV_PHI  =  0.1945f;  // [wf] 동정 w 의 φ̇ 성분
float WV_BETA =  0.3049f;  // [wb] 동정 w 의 β̇ 성분
float VGAIN   =  1.0f;     // [vg] 속도항 배율. 1.0 = 실측 그대로
float LAMBDA  =  5.66f;    // [lam] ★배가시간 전용. A 에 안 들어간다

W_PHI = -1/R_SLOPE;  W_BETA = 1;
W_PHIDOT = VGAIN*WV_PHI;  W_BETADOT = VGAIN*WV_BETA;
```

검산: `w = [0.66401, 1.00000, 0.19450, 0.30490]` — 문서 69 §1 의 동정값과 자릿수까지 일치.
`w_φ = −1/r = 0.66401` 이 동정된 `+0.6641` 과 같다는 것이 **r 과 wf·wb 가 같은 고유벡터의 성분**이라는 증거다.

## 4. ⚠ 이 표현이 감춰서는 안 되는 사실

**위치항은 단단하고 속도항은 무르다.**

| | 검증 경로 | 조건 바꿨을 때 흔들림 |
|---|---|---|
| r (위치항) | **3 개** — 동정 −1.506 / 놓기점 경계 −1.494(미분·모델 미사용) / Ȧ=λA 시험 | −1.37 ~ −1.65 |
| w_v (속도항) | **1 개** — 동정뿐 | κ 환산 **1.46 ~ 2.47** (평활창에 따라) |

이건 κ 를 쓰든 w_v 를 직접 쓰든 **같은 사실**이다 — 표현을 바꾼다고 없어지지 않는다.
직접 대입이 이 사실을 더 잘 드러낸다는 점에서 오히려 낫다 (κ 라는 이름이 "보정계수" 처럼
들려서 무름을 가리는 면이 있었다).

**무른 쪽을 손보는 노브가 `vg` 다.** 위 흔들림 폭을 vg 로 옮기면 대략 **0.88 ~ 1.45**.
그 밖은 실측이 아니라 튜닝이라고 화면이 말해 준다.

## 5. Â 가 얼마나 달라지나 — γ 는 그대로 9

| | w_φ̇ | w_β̇ | finale6 대비 |
|---|---:|---:|---|
| finale6 (lam 2.97) | 0.2236 | 0.3367 | 기준 (γ 9 를 이 위에서 맞췄다) |
| finale7 (κ 1.5) | 0.1831 | 0.2757 | −18 % / −18 % |
| **finale8 (직접)** | **0.1945** | **0.3049** | **−13 % / −9 %** |

**finale8 이 finale6 에 더 가깝다.** γ = 9 가 더 잘 이월된다.
미리보기 시간은 φ 293 ms / β 305 ms — 두 채널이 3.9 % 다른데, 그 차이가 바로 κ 스칼라가
뭉개던 부분이다.

## 6. `kv` 는 없앴다 (같은 이름 다른 눈금 방지)

finale7 의 `kv` (κ, 1.5 언저리) 와 finale8 의 `vg` (배율, 1.0 언저리) 는 눈금이 다르다.
손에 익은 대로 `kv 1.5` 를 치면 속도항이 1.5 배가 되어 버린다.
⇒ `kv` 를 치면 파라미터가 아니라 **안내문**이 나오게 했다 ("옛 kv 1.5 ≈ 지금 vg 0.90").

## 7. 검증

```

kappa 환산 = 1.66 / 1.73        (문서 69 §5 의 1.66 / 1.72 와 일치)
```
