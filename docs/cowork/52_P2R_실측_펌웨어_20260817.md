# P2R 실측 펌웨어 `p2r_test.ino` (2026-08-17)

> 문서 46 「실측 ① — P2R」을 그대로 실행하기 위한 스케치. 문서 17(모터 프로파일 테스트)의
> 배선·SPI·Dynamixel 초기화를 재사용하되, **조작을 정수 입력 하나로 줄였다.**

## 1. 무엇이 달라졌나

| | 문서 17 (`motor_profile_test`) | 이 스케치 (`p2r_test`) |
|---|---|---|
| 이동 명령 | `g 30` (글자 + 숫자) | **`30`** — 정수만 치고 Enter. z 영점 기준 **절대각** |
| 줄바꿈 설정 | Newline 필요 | **무관** — 마지막 글자 후 200 ms 지나면 자동 실행 |
| 화면 | `p`/`s` 로만 확인 | **4 Hz 읽기용 모니터 기본 ON**, `α/δ` 실시간 표시 (기대 −0.412) |
| `s` 키 | 100 Hz 스트리밍 ON/OFF | **출력 정지/재개** — 화면을 멈춰 값을 받아적는다. 정지 중에도 명령은 먹음 |
| α 계산 | 없음 (ank 원값만) | **α = ank + phi** — 문서 37(8/5) 확정 규약 내장 |
| 위치 모드 | `OP_POSITION` | `OP_EXTENDED_POSITION` — 0/360 경계 감김 제거 |
| 각도 제한 | ±90° | **±55°** (기구한계) |

## 2. 명령

| 키 | 동작 |
|---|---|
| `20` / `-20` / `0` | **δ 절대각 이동** (z 영점 기준) |
| **`s`** | **출력 정지 / 재개** — 화면이 멈춰서 값을 받아적을 수 있다. 정지 직전 한 줄을 남기고 멈춘다. 멈춘 동안에도 숫자·`z`·`p` 등 명령은 그대로 먹는다 |
| `z` | 엔코더 2개(φ·발목) 영점 + 모터 홈(δ=0). ★완전히 멎은 상태에서만 |
| `p` | 현재값 1회 출력 (정지 중에도 됨) |
| `m` | 출력 형식 전환 — 읽기용 4 Hz ↔ 100 Hz CSV `D,t_ms,phi,ank,alpha,del_cmd,del_now` (exp_logger 호환) |
| `v 30` / `a 10` | 프로파일 속도·가속도 (기본 v=30 ≈ 41 °/s, a=10 ≈ 215 °/s²) |
| `u` / `k` | 토크 해제 / 복구(현재 자리 유지) |
| `x` | 비상정지 — 줄바꿈 안 기다리고 즉시 |
| `t` | 설정·상태 요약 |

모니터 한 줄 형식:

```
dcmd=+20  d=+19.98 | phi=+0.03  ank=-8.19  alpha=-8.16 | alpha/d=-0.409
```

| 항목 | 뜻 |
|---|---|
| `dcmd` | **명령한** δ — 타이핑한 정수 |
| `d` | **실제** δ — 서보 내장 엔코더가 읽는 허리각 (`δ` 를 ASCII 로 쓴 것) |
| `phi` / `ank` | 두 AS5047P 원값 (영점 기준) |
| `alpha` | `ank + phi` — 문서 37 확정 규약 |
| `alpha/d` | 그 자리에서 읽는 **P2R**. 예측 −0.4122 근처면 합격 |

★`alpha/d` 는 **명령(`dcmd`)이 아니라 실제 `d` 로 나눈다.** 매달면 상체 무게가 허리
관절에 토크를 걸어 목표보다 처지는데, α 는 '명령한 각도'가 아니라 '실제로 접힌 각도'에
대응하기 때문이다. 20° 명령에 19.4° 만 도달한 경우 두 방식의 차이가 **3%** 다.

⚠ `alpha/d` 는 **한 점의 비율**이라 영점 오차에 그대로 노출된다. 절차대로 매달아 멎은
자리에서 `z` 를 눌렀으면 맞지만, 의심스러우면 **두 점의 차이** `Δα/Δδ` 로 계산할 것 —
그쪽은 오프셋이 상쇄되어 항상 맞는다.

## 2-1. 값 받아적는 흐름

```
20   →  (화면이 흐르며 멎는 것을 본다)  →  s  →  화면 멈춤, 마지막 줄 받아적기  →  s  →  30
```

★`s` 는 **화면만** 멈춘다. 모터·엔코더·명령은 그대로 살아 있다.

## 3. 측정 순서

1. 줄에서 내려 **발목축에서 매단다** (발목이 자유롭게 도는 상태).
2. δ=0 에서 완전히 멎을 때까지 기다린 뒤 `z`.
3. `10` → `20` → `30` → `40`, 이어서 `30` → `20` → `10` → `0`.
   각 점에서 **살짝 흔들어 준 뒤** 멎는 자리를 읽는다.
   ★같은 δ 의 올라갈 때·내려올 때 두 값을 평균하면 마찰 데드밴드가 상쇄된다 (문서 46 주의사항).
4. α 대 δ 직선 적합 → **기울기 = −P2R**.

예측표 (기울기 −0.4122): δ=10/20/30/40° → α = −4.12 / −8.24 / −12.37 / −16.49°

## 4. ⚠ 영점 위치에 관한 주의 (문서 46 보완)

매달린 δ=0 평형은 **물리적으로 정확히 α=0** 이다 (무게중심이 축 바로 아래 = β=0).
그러니 거기서 `z` 를 누르면 발목 엔코더의 **참 영점**을 얻는다 — 대신 기존 영점 오차가
그 순간 지워지므로 **적합 절편은 구조적으로 0 이 된다.**

문서 46이 말한 "절편 = 발목 엔코더 영점 오차"를 보고 싶다면 **기계 기준면으로 영점을 먼저
잡아두고, 매단 뒤에는 `z` 를 누르지 말 것.** 둘 중 하나만 얻을 수 있다:

| 하고 싶은 것 | 절차 |
|---|---|
| 참 영점을 **얻는다** | 매달아 멎은 뒤 `z` → 이후 α 는 참값. 절편은 0 |
| 기존 영점 오차를 **잰다** | 기계 기준면에서 `z` → 매단 뒤 `z` 금지 → 적합 절편이 곧 오차 |

## 5. 검증

Arduino API를 스텁으로 대체해 g++ 컴파일 + 명령 파서 단위시험 통과:
줄바꿈 유/무 두 경로, 범위 초과 클립(999→55), `-` 오타 무시, **`v 45` 의 45가 각도명령으로
새지 않음**, 40° → 455.11 tick 환산, `x` 즉시성, `x` 후 숫자 입력 시 토크 자동 복구,
**`s` 정지 중 주기 출력 0 바이트 · 명령은 정상 수신 · `s` 재개**, `m` 으로 CSV 전환.

실기 검증(모터·엔코더 실제 응답)은 미실시 — 배선·부호는 문서 17·37 확정값을 그대로 따랐다.

## 부록. `p2r_test.ino` 전문

```cpp
/*
 * p2r_test.ino — P2R 실측 전용 (매달고 δ 명령 → 발목각 α 읽기)
 * ============================================================================
 * 문서 46 「실측 ① — P2R」용 스케치.
 *
 *   매달린 상태의 평형 = 무게중심이 발목축 바로 아래 = β = 0
 *   β = P1R·α + P2R·θ = 0,   θ = α + δ,   P1R + P2R = 1
 *      →   α = −P2R · δ        ★ α–δ 직선의 기울기가 −P2R
 *
 *   예측(실측 파라미터 기준): 기울기 = −0.4122
 *       δ = 10° → α = −4.12° | δ = 20° → α = −8.24°
 *       δ = 30° → α = −12.37° | δ = 40° → α = −16.49°
 *
 * ----------------------------------------------------------------------------
 * [조작]  시리얼 모니터 115200 baud.  ★정수만 치고 Enter 하면 그 각도로 간다.
 *
 *      20   →  δ = +20°   (z 영점 기준 '절대각')
 *     -20   →  δ = −20°
 *       0   →  영점 복귀
 *
 *   줄바꿈(Newline) 설정을 안 해도 동작한다 — 마지막 글자 후 200 ms 지나면 자동 실행.
 *
 * [키]
 *   s        ★출력 정지 / 재개 — 화면이 멈춰서 값을 받아적을 수 있다 (기본 출력 ON)
 *            멈춘 동안에도 명령(숫자·z·p …)은 그대로 먹는다.
 *   z        영점: 엔코더 2개(φ·발목) + 모터 홈(δ=0).  ★완전히 멎은 상태에서만
 *   p        현재값 1회 출력 (정지 중에도 됨)
 *   m        출력 형식 전환 — 읽기용 4 Hz  ↔  100 Hz CSV (exp_logger.py 호환 D행)
 *   v 30     프로파일 속도   (1 unit = 1.374 °/s,  기본 30 ≈ 41 °/s)
 *   a 10     프로파일 가속도 (1 unit = 21.46 °/s², 기본 10 ≈ 215 °/s²)
 *   u        토크 해제 (손으로 돌려볼 때)
 *   k        토크 복구 (지금 자리에서 유지 — 홈은 그대로)
 *   x        비상정지 (토크 OFF, 즉시 — 줄바꿈 안 기다림)
 *   t        설정·상태 요약
 *
 * ----------------------------------------------------------------------------
 * [배선] 절차서 5.2절 그대로
 *        φ CS = D10,  발목 CS = D9,  SCLK = D13, MISO = D12, MOSI = D11
 *        모터 XM430-W210-R, RS-485 4핀, ID 1.
 *        ★배터리 필수 — USB 전원만으로는 모터가 안 움직인다.
 *
 * [부호] 문서 37 (2026-08-05 정합점검 확정)
 *        α = ank + phi     (발목 s = +1, 즉 ank = α − φ 형)
 *        MOTOR_DIR = +1
 *
 * ----------------------------------------------------------------------------
 * [측정 순서]
 *   1. 줄에서 내려 발목축에서 매단다 (발목이 자유롭게 도는 상태).
 *   2. δ=0 에서 완전히 멎을 때까지 기다린 뒤  z  (영점).
 *   3. 10 → 20 → 30 → 40  (올라가며), 이어서 30 → 20 → 10 → 0 (내려오며).
 *      각 점에서 살짝 흔들어 준 뒤 멎는 자리를 읽는다.
 *      ★같은 δ 의 올라갈 때·내려올 때 두 값을 평균하면 마찰 데드밴드가 상쇄된다.
 *   4. α 대 δ 로 직선 적합 → 기울기 = −P2R.
 *
 *   ⚠ 영점 위치에 대한 주의
 *     매달린 δ=0 평형은 물리적으로 정확히 α=0 이다. 그러니 거기서 z 를 누르면
 *     발목 엔코더의 '참 영점'을 얻는다 — 다만 그 순간 기존 영점 오차는 지워지므로
 *     적합 절편은 0 이 된다. 문서 46이 말한 "절편 = 발목 엔코더 영점 오차"를 보고 싶으면
 *     기계 기준면으로 영점을 먼저 잡아두고, 매단 뒤에는 z 를 누르지 말 것.
 * ============================================================================
 */
#include <SPI.h>
#include <Dynamixel2Arduino.h>

// ---------------- 하드웨어 ----------------
#define DXL_SERIAL   Serial3
#define DXL_DIR_PIN  84
const uint8_t DXL_ID  = 1;

const uint8_t PHI_CS  = 10;    // φ (크랭크/줄 각도) 엔코더
const uint8_t ANK_CS  = 9;     // 발목 엔코더

// ---------------- 규약·상수 ----------------
const int   MOTOR_DIR       = +1;        // 문서 37 확정
const float TICK_PER_DEG    = 4096.0f / 360.0f;   // XM430 = 4096 tick/rev
const float VEL_UNIT_DPS    = 1.374f;    // PROFILE_VELOCITY     1 unit
const float ACC_UNIT_DPS2   = 21.4577f;  // PROFILE_ACCELERATION 1 unit
const long  DELTA_LIMIT_DEG = 55;        // 기구한계. 넘는 명령은 잘라낸다
const uint32_t PERIOD_US    = 10000;     // 100 Hz 스트리밍
const uint32_t MON_MS       = 250;       // 4 Hz 읽기용 모니터
const uint32_t LINE_TIMEOUT_MS = 200;    // 줄바꿈 없는 모니터 대응

Dynamixel2Arduino dxl(DXL_SERIAL, DXL_DIR_PIN);
using namespace ControlTableItem;

// ---------------- 상태 ----------------
uint32_t dxl_baud = 0;
bool     motor_ok = false;
float    home_tick = 0;                  // z 시점 모터 위치 = δ 0°
long     delta_cmd = 0;                  // 마지막 명령 δ (정수 도)
uint16_t phi_zero = 0, ank_zero = 0;
int      vel_unit = 30, acc_unit = 10;

bool     out_on   = true;                // s 로 토글 — 주기 출력 정지/재개
bool     csv_mode = false;               // m 로 토글 — false: 읽기용 4Hz / true: 100Hz D행
uint32_t t0 = 0, next_us = 0, next_mon = 0;

char     linebuf[24];
uint8_t  linelen = 0;
uint32_t last_rx_ms = 0;

// ---------------- AS5047P (SPI 모드1, ANGLECOM 0x3FFF) ----------------
uint16_t as5047_raw(uint8_t cs) {
  uint16_t v;
  SPI.beginTransaction(SPISettings(1000000, MSBFIRST, SPI_MODE1));
  digitalWrite(cs, LOW);  delayMicroseconds(1);
  SPI.transfer16(0xFFFF);                  // 각도 읽기 명령
  digitalWrite(cs, HIGH); delayMicroseconds(1);
  digitalWrite(cs, LOW);  delayMicroseconds(1);
  v = SPI.transfer16(0xFFFF);              // 이전 명령의 응답 = 각도
  digitalWrite(cs, HIGH);
  SPI.endTransaction();
  return v & 0x3FFF;                       // 14비트
}

float rawToDeg(uint16_t raw, uint16_t zero) {
  int16_t d = (int16_t)((raw - zero) & 0x3FFF);
  if (d > 8191) d -= 16384;                // ±180°로 감기
  return d * (360.0f / 16384.0f);
}

float phiDeg() { return rawToDeg(as5047_raw(PHI_CS), phi_zero); }
float ankDeg() { return rawToDeg(as5047_raw(ANK_CS), ank_zero); }

// ---------------- 모터 ----------------
float deltaNow() {                          // 서보 내장 엔코더가 보는 실제 δ
  if (!motor_ok) return 0;
  return MOTOR_DIR * (dxl.getPresentPosition(DXL_ID) - home_tick) / TICK_PER_DEG;
}

void torqueRestoreHere() {                  // 현재 자리를 목표로 잡고 토크 ON (급작 이동 방지)
  if (!motor_ok) return;
  dxl.setGoalPosition(DXL_ID, dxl.getPresentPosition(DXL_ID));
  dxl.torqueOn(DXL_ID);
}

void goToDelta(long deg) {
  if (!motor_ok) { Serial.println("# 모터 연결 안 됨 — 이동 불가"); return; }
  if (deg > DELTA_LIMIT_DEG || deg < -DELTA_LIMIT_DEG) {
    Serial.print("# 범위 초과 — ±"); Serial.print(DELTA_LIMIT_DEG);
    Serial.println("° 로 잘림");
    deg = (deg > 0) ? DELTA_LIMIT_DEG : -DELTA_LIMIT_DEG;
  }
  if (!dxl.getTorqueEnableStat(DXL_ID)) {   // x/u 이후 자동 복구
    torqueRestoreHere();
    Serial.println("# 토크 복구됨 (홈은 z 시점 그대로 — 크게 움직일 수 있으니 주의)");
  }
  delta_cmd = deg;
  float goal = home_tick + (float)(MOTOR_DIR * deg) * TICK_PER_DEG;
  dxl.setGoalPosition(DXL_ID, goal);
  Serial.print("E,"); Serial.print(millis() - t0);
  Serial.print(",MOVE,"); Serial.println(deg);
}

// ---------------- 출력 ----------------
void printSigned(float v, int nd) { if (v >= 0) Serial.print('+'); Serial.print(v, nd); }

void printState() {
  float phi = phiDeg();
  float ank = ankDeg();
  float alpha = ank + phi;                  // 문서 37 확정 규약
  float dn = deltaNow();

  Serial.print("dcmd="); printSigned((float)delta_cmd, 0);
  Serial.print("  d=");  printSigned(dn, 2);
  Serial.print(" | phi="); printSigned(phi, 2);
  Serial.print("  ank=");  printSigned(ank, 2);
  Serial.print("  alpha="); printSigned(alpha, 2);
  // ★명령(dcmd)이 아니라 실제 δ(d)로 나눈다 — 매달면 상체 무게가 허리를 처지게 하므로
  //   α 는 '명령한 각도'가 아니라 '실제로 접힌 각도'에 대응한다.
  if (dn > 0.5f || dn < -0.5f) {            // 그 자리에서 바로 읽는 기울기 (기대 −0.412)
    Serial.print(" | alpha/d=");
    Serial.print(alpha / dn, 3);
  }
  Serial.println();
}

void printStatus() {
  Serial.println("---- 상태 ----");
  Serial.print("모터: "); Serial.println(motor_ok ? "OK" : "응답 없음");
  if (motor_ok) {
    Serial.print("  baud="); Serial.print(dxl_baud);
    Serial.print("  torque="); Serial.println(dxl.getTorqueEnableStat(DXL_ID) ? "ON" : "OFF");
    Serial.print("  home_tick="); Serial.println(home_tick, 1);
  }
  Serial.print("프로파일: v="); Serial.print(vel_unit);
  Serial.print(" (~"); Serial.print(vel_unit * VEL_UNIT_DPS, 0); Serial.print(" deg/s)  a=");
  Serial.print(acc_unit);
  Serial.print(" (~"); Serial.print(acc_unit * ACC_UNIT_DPS2, 0); Serial.println(" deg/s^2)");
  Serial.print("엔코더 raw: phi="); Serial.print(as5047_raw(PHI_CS));
  Serial.print("  ank=");           Serial.println(as5047_raw(ANK_CS));
  Serial.print("출력="); Serial.print(out_on ? "ON" : "정지(s로 재개)");
  Serial.print("  형식="); Serial.println(csv_mode ? "100Hz CSV" : "읽기용 4Hz");
  Serial.println("--------------");
  printState();
}

void printHelp() {
  Serial.println("정수 입력 = 그 각도로 이동 (예: 20 / -20 / 0)");
  Serial.println("s 출력 정지/재개 | z 영점 | p 1회출력 | m 형식(4Hz<->CSV) | v<n> a<n> | u 토크해제 | k 토크복구 | x 비상정지 | t 상태");
}

// ---------------- 명령 파싱 ----------------
long argInt(const char* s, bool* found) {   // 첫 글자(명령) 뒤의 정수
  const char* q = s + 1;
  while (*q == ' ' || *q == '\t' || *q == '=') q++;
  if (*q == '\0') { *found = false; return 0; }
  *found = true;
  return atol(q);
}

void handleLine(char* s) {
  while (*s == ' ' || *s == '\t') s++;      // 앞 공백 제거
  if (*s == '\0') return;

  char c = *s;
  if ((c >= '0' && c <= '9') || c == '+' || c == '-') {
    bool digit = false;                     // "-" 만 친 오타로 0° 로 튀는 것 방지
    for (const char* q = s; *q; q++) if (*q >= '0' && *q <= '9') { digit = true; break; }
    if (!digit) { Serial.println("# 숫자가 없음 — 무시"); return; }
    goToDelta(atol(s));                     // ★정수 입력 = 절대 δ 명령
    return;
  }
  if (c >= 'A' && c <= 'Z') c += 32;        // 소문자화

  bool has; long n;
  switch (c) {
    case 'z':
      phi_zero = as5047_raw(PHI_CS);
      ank_zero = as5047_raw(ANK_CS);
      if (motor_ok) home_tick = dxl.getPresentPosition(DXL_ID);
      delta_cmd = 0;
      Serial.println("# ZERO — 엔코더 2개 영점 + 모터 홈(delta=0) 설정");
      printState();
      break;

    case 'p': printState(); break;

    case 's':                               // ★출력 정지 / 재개
      out_on = !out_on;
      next_mon = millis();
      next_us  = micros();
      if (out_on) Serial.println("# 출력 재개 (s 로 다시 정지)");
      else {
        printState();                       // 멈추기 직전 값을 한 줄 남겨둔다
        Serial.println("# 출력 정지 — s 로 재개 (명령은 계속 먹음)");
      }
      break;

    case 'm':                               // 출력 형식 전환
      csv_mode = !csv_mode;
      next_mon = millis();
      next_us  = micros();
      if (csv_mode) {
        Serial.println("# D,t_ms,phi_deg,ank_deg,alpha_deg,del_cmd_deg,del_now_deg");
        Serial.println("# 형식: 100Hz CSV (exp_logger 용)");
      } else {
        Serial.println("# 형식: 읽기용 4Hz");
      }
      break;

    case 'v':
      n = argInt(s, &has);
      if (has) {
        vel_unit = (int)constrain(n, 1, 200);
        if (motor_ok) dxl.writeControlTableItem(PROFILE_VELOCITY, DXL_ID, vel_unit);
      }
      Serial.print("# vel="); Serial.print(vel_unit);
      Serial.print(" (~"); Serial.print(vel_unit * VEL_UNIT_DPS, 0); Serial.println(" deg/s)");
      break;

    case 'a':
      n = argInt(s, &has);
      if (has) {
        acc_unit = (int)constrain(n, 1, 200);
        if (motor_ok) dxl.writeControlTableItem(PROFILE_ACCELERATION, DXL_ID, acc_unit);
      }
      Serial.print("# acc="); Serial.print(acc_unit);
      Serial.print(" (~"); Serial.print(acc_unit * ACC_UNIT_DPS2, 0); Serial.println(" deg/s^2)");
      break;

    case 'u':
      if (motor_ok) dxl.torqueOff(DXL_ID);
      Serial.println("# 토크 해제 — 손으로 돌려도 됨 (k 로 복구)");
      break;

    case 'k':
      torqueRestoreHere();
      Serial.println("# 토크 복구 (현재 자리 유지)");
      break;

    case 't': printStatus(); break;
    case '?': case 'h': printHelp(); break;

    default:
      Serial.print("# 모르는 명령: "); Serial.println(s);
      printHelp();
      break;
  }
}

void emergencyStop() {
  if (motor_ok) dxl.torqueOff(DXL_ID);
  linelen = 0;
  Serial.println(">>> EMERGENCY STOP (torque off) — k 로 복구");
}

void pollSerial() {
  while (Serial.available()) {
    char ch = (char)Serial.read();

    if (ch == 'x' || ch == 'X') { emergencyStop(); continue; }   // 즉시 실행

    if (ch == '\n' || ch == '\r') {
      if (linelen) { linebuf[linelen] = '\0'; linelen = 0; handleLine(linebuf); }
      continue;
    }
    if (ch == ' ' && linelen == 0) continue;                     // 앞 공백 무시
    if (linelen < sizeof(linebuf) - 1) linebuf[linelen++] = ch;
    else { linelen = 0; Serial.println("# 입력이 너무 김 — 버림"); }
    last_rx_ms = millis();
  }

  // 줄바꿈 설정이 'No line ending' 이어도 동작하게 — 조용해지면 실행
  if (linelen && (millis() - last_rx_ms) >= LINE_TIMEOUT_MS) {
    linebuf[linelen] = '\0'; linelen = 0; handleLine(linebuf);
  }
}

// ---------------- setup / loop ----------------
void setup() {
  Serial.begin(115200);
  delay(2000);

  pinMode(PHI_CS, OUTPUT); digitalWrite(PHI_CS, HIGH);
  pinMode(ANK_CS, OUTPUT); digitalWrite(ANK_CS, HIGH);
  SPI.begin();

  Serial.println("=== p2r_test (P2R: 매달고 delta 명령 -> 발목각) ===");

  dxl.setPortProtocolVersion(2.0);
  const uint32_t bauds[] = {1000000, 57600};
  for (int b = 0; b < 2 && !motor_ok; b++) {
    dxl.begin(bauds[b]);
    for (int i = 0; i < 3; i++) {
      if (dxl.ping(DXL_ID)) { motor_ok = true; dxl_baud = bauds[b]; break; }
      delay(200);
    }
  }

  if (motor_ok) {
    Serial.print("모터 OK @ "); Serial.println(dxl_baud);
    dxl.torqueOff(DXL_ID);
    delay(50);
    dxl.setOperatingMode(DXL_ID, OP_EXTENDED_POSITION);   // 0/360 경계 감김 없음
    delay(50);
    dxl.writeControlTableItem(PROFILE_VELOCITY,     DXL_ID, vel_unit);
    dxl.writeControlTableItem(PROFILE_ACCELERATION, DXL_ID, acc_unit);
    home_tick = dxl.getPresentPosition(DXL_ID);
    dxl.setGoalPosition(DXL_ID, home_tick);               // 제자리 목표 -> 토크 ON 시 안 튐
    delay(50);
    dxl.torqueOn(DXL_ID);
    Serial.print("프로파일 v="); Serial.print(vel_unit);
    Serial.print(" a="); Serial.println(acc_unit);
  } else {
    Serial.println("!!! 모터 응답 없음 (배터리/RS-485/보레이트 확인) — 엔코더만 동작");
  }

  uint16_t r1 = as5047_raw(PHI_CS), r2 = as5047_raw(ANK_CS);
  Serial.print("phi enc raw="); Serial.print(r1);
  Serial.print("  ank enc raw="); Serial.println(r2);
  Serial.println("(0 또는 16383 고정이면 배선 확인)");

  printHelp();
  Serial.println("순서: 발목축에 매달고 완전히 멎으면 z -> 10 -> 20 -> 30 -> 40 -> 30 -> 20 -> 10 -> 0");
  Serial.println("기대: alpha/d = -0.412 근처   (화면이 빠르면 s 로 정지)");

  t0 = millis();
  next_mon = millis();
  next_us  = micros();
}

void loop() {
  pollSerial();

  if (!out_on) return;                      // ★s 로 정지 — 명령은 위에서 이미 처리됨

  if (csv_mode) {
    uint32_t now = micros();
    if ((int32_t)(now - next_us) >= 0) {
      next_us += PERIOD_US;
      float phi = phiDeg(), ank = ankDeg();
      Serial.print("D,");
      Serial.print(millis() - t0);   Serial.print(",");
      Serial.print(phi, 3);          Serial.print(",");
      Serial.print(ank, 3);          Serial.print(",");
      Serial.print(ank + phi, 3);    Serial.print(",");
      Serial.print(delta_cmd);       Serial.print(",");
      Serial.println(deltaNow(), 3);
    }
  } else {
    uint32_t now = millis();
    if ((int32_t)(now - next_mon) >= 0) {
      next_mon += MON_MS;
      printState();
    }
  }
}
```
