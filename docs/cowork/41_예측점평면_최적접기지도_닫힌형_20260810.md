# 예측점 평면 (β_pred, φ_pred) 위의 최적접기 지도 — 닫힌형과 검증 (2026-08-10)

> Ⅸ장(예측점 평면)의 후속. 기존 그림들은 **궤적**(S1~S5)을 평면 위에 그렸다.
> 이번에는 궤적이 아니라 **필드(제어법칙 자체)** 를 그린다 — 평면의 모든 점에서
> "지금 얼마나 접어야 하는가"를 색과 등고선으로 만든 지도.
> 그림: `예측점평면_최적접기지도_R0.7.png`, 스크립트: `fold_map_plot.py` / `fold_map_verify.py`

## 1. 닫힌형 — 최적접기는 예측점의 선형함수

순간접기는 상태를 CoM 등고선 방향 e=(h/R, −1)로 평행이동시킨다. 접기각 δ_f와 이동량의 관계를
임펄스 적분(M₂₂Δq = −μδ_f·e₂)으로 풀면

**Δq = k · δ_f · e,  k = μM_tR² / det M₂₂ = 0.21748**  (접기 1°당 β를 0.2175° 되돌림)

속도는 보존되므로 예측점도 같은 양만큼 이동한다. 판정식 u₂ᵀq_pred = 2A = 0을 요구하면

$$\boxed{\;\delta_f^* = -\frac{u_2^{\mathsf T} q_{\text{pred}}}{k\,(u_2^{\mathsf T} e)} = -\frac{2A}{k\,(u_2^{\mathsf T} e)}\;}$$

R = 0.7, u₂ = (0.4718, 1) (β성분 정규화) 에서 수치로 펴 쓰면

**δ_f\*[deg] = 13.029 · β_pred + 6.148 · φ_pred**

즉 **최적접기는 예측점 평면 위의 평면(1차식)** 이고, 등고선은 전부 **안정모드선과 나란한 평행선**이다.
δ_f\*=0 등고선이 곧 안정모드선(φ = r·β, r = −2.119) 자신이다.
"평면 위 어디에 있느냐"만 알면 접기량이 곱셈 두 번으로 나온다 — 상태추정만 되면 F단계는 룩업이 필요 없다.

## 3. 지도가 새로 보여주는 것

**(1) 포획영역은 평면 위의 '띠'다.** 가동한계 δ_max를 넣으면 1회 접기로 잡을 수 있는 영역은
안정선을 중심으로 한 **평행 띠**이고, 그 폭은 안정선 수직 이탈거리 n = 2A/‖u₂‖ 기준으로

| | n_cap | φ_pred=0 단면의 \|β_pred\|max |
|---|---|---|
| 순간 접기 (γ=1) | 3.82° | 4.22° |
| T_f = 0.15 s (γ=1.296) | 2.95° | 3.26° |
| T_f = 0.25 s (γ=1.531) | 2.49° | 2.76° |

(δ_max = 55°, 사람 스케일 기준. 03번 문서의 반복 FEW 포획영역 β≈3°과 같은 자릿수 — 다만 저건 사이클 이득 기준이라 정의가 다르므로 서로의 증거로 쓰지 말 것.)
**유한시간이 포획영역을 직접 깎는다**는 것이 그림 (b)에서 한 장으로 보인다: γ가 커지면 같은 δ_max로 잡을 수 있는 위험이 1/γ로 줄어든다.

**(2) 제어변수는 비율 ε\*가 아니라 각도 δ_f\*여야 한다.** 같은 정보를 접기비율 ε\* = kδ_f\*/β − 1로 그리면
(그림 c) β_pred → 0에서 **발산**하고 등고선이 원점에서 부채꼴로 갈라지는 비선형 장이 된다.
ε\*는 "정지·단발"을 설명하는 **해설용 양**이고, 실기 제어기가 실어야 할 것은 δ_f\* 한 줄이다.
(자기일관성: 안정선 위에서 ε\* = −1 = '무개입' — 31번 문서 Ⅷ-6 표와 일치.)
