# 67. 실측 ② 2차 시도 — 펌웨어는 고쳐졌고, 이번엔 φ 엔코더가 죽었다 (2026-08-22)

> 원 파일: `0817_p2r_r2_3.raw.txt` (8711줄), `0817_p2r_r2_3.csv` (8418행), events (MOVE 1건).

> **가장 중요한 소득은 "1 바퀴" 라는 목표 자체가 물리적으로 불가능하다는 것을 확인한 것**이다.

## 2. 이번 고장 — φ 엔코더

| | |
|---|---|
| 마지막 정상 샘플 | t = **191,423 ms** (로그 시작 후 **65.3 초**) |
| 그 뒤 | φ = **10.811° 고정**, 연속 **7,683 샘플** |
| 비중 | 로그의 **91 %** |
| 원 카운트 | 처음엔 `raw=16383` (= 0x3FFF, MISO 고착 — 문서 52 가 "0 또는 16383 고정이면 배선 확인"<br>이라고 적어 둔 그 패턴), 이후엔 11324·11530·12110 처럼 값은 변하는데 φ 는 안 변함 |

φ 가 없으면 **α = ank + phi 도 못 만든다.** ank 는 살아 있지만 쓸 수 없다.
→ **쓸 수 있는 것은 앞의 65.3 초, 시행 5 개 (그중 1 개는 놓기 아님) = 놓기 4 회.**

> ⚠ 문서 64 §4-4 에서 **발목** 센서를 고쳤더니 이번엔 **φ** 가 죽었다.
> 같은 SPI 버스·같은 종류의 증상이다. 커넥터·케이블 쪽을 의심할 근거.

## 3. ★ "1 바퀴" 는 불가능한 목표다 — 이 로그가 스스로 증명한다

**필요한 두 숫자가 다 있다.**

| | 출처 | 값 |
|---|---|---|
| 진동 반주기 | **이 로그 실측** (시행 1~4 의 연속 극값 간격) | **600 ~ 890 ms** (평균 ~700 ms → 주기 1.4 s) |
| 발산율 λ | 문서 65 실측 | **5.44 /s** |

넘어지는 성분은 그 사이에도 e^{λt} 로 자란다:

| 버티는 시간 | 불안정 성분이 자라는 배수 |
|---|---|
| **반주기** (0.70 s) | **45 배** |
| **한 주기** (1.40 s) | **2,030 배** |

그러면 놓는 순간 A 를 얼마나 정확히 맞춰야 하는지가 나온다
(진폭 = 그 시행에서 흔들린 크기):

| 진폭 | 반주기를 보려면 | **한 주기를 보려면** |
|---|---|---|
| 25° | \|A\| < 0.56° | \|A\| < **0.012°** |
| 10° | \|A\| < 0.22° | \|A\| < **0.005°** |
| 5° | \|A\| < 0.11° | \|A\| < **0.003°** |

**Â 잡음 바닥은 0.106°** (문서 64 §4-4, 수리 후 값).

> **한 주기를 요구하는 것은 잡음 바닥의 1/10 ~ 1/40 안에 놓으라는 말이다.**
> 맞췄는지 **확인할 방법조차 없다.** 손이 아니라 어떤 장치로도 안 된다.
>
> 반주기는 \|A\| < 0.2~0.6° — **가능하다. 그래서 2 회가 됐다.**
> **성적이 나쁜 게 아니라 목표가 잘못 잡혀 있었다.**

### 이건 내 잘못이다 (정정)

문서 66 §5 가 문서 50 §2 Z2 의 표현 **"여러 φ 에서 흔들리는 β 를 찾아 직선 적합"** 을
그대로 옮겨 적었다. "흔들리는" 을 **"흔들리는 데 성공해야 한다"** 로 읽히게 둔 것이 잘못이다.
그 문장의 뜻은 **경계의 이상적 위치**를 가리킨 것이지 **달성 조건**이 아니다.

---

## 4. 흔들릴 필요가 없다 — 부호만 있으면 된다

정지 상태에서 놓으면 `A = −φ/r + β + c₀/r` 이고 **A 의 부호가 넘어지는 방향을 정한다.**
그러니 **넘어진 시행도 전부 데이터다** — 그 점이 선의 어느 쪽인지 말해 준다.

```
목표:  "흔들리게 만든다"          ← 불가능, 필요 없음
실제:  "놓은 자리 (φ, β) 와 넘어진 방향을 기록한다"   ← 매번 100% 성공한다
```

반주기까지 간 2 회는 **선에 가장 가까운 점**이라 값이 크지만, 없어도 된다.
나머지가 양쪽에서 브래킷하면 경계는 나온다.

## 5. 그래도 이 로그로는 안 되는 이유 (세 가지)

| # | 무엇 | 값 | 왜 문제인가 |
|---|---|---|---|
| 1 | **놓기가 4 회** | φ 사망 전 65 초 안에 5 시행, 1 개는 놓기 아님 | 선 하나 그리기엔 턱없이 적다 (필요 30~40) |
| 2 | **진폭이 너무 크다** | φ **±20 ~ 46°** | 문서 65 놓기(12~15°)의 2~3 배. 선형 영역 밖이라 A 자체가 정의를 잃는다 |
| 3 | **★ 발목이 거의 안 움직인다** | **dα/dφ = +1.0 ~ +1.7** | 아래 |

### 3번이 제일 중요하다

시행 3 에서 **φ 가 70° 도는 동안 ank 는 9° 밖에 안 움직였다.** dα/dφ ≈ +1 은
`ank = α − φ` 가 거의 상수라는 뜻 — **발목 관절이 사실상 굳은 채 통째로 돌고 있다.**

문서 65 가 잰 발산 모드는 **dα/dφ = −0.37** (발목이 반대로 돌며 몸이 버틴다).
**부호부터 다르다. 지금 보고 있는 것은 그 모드가 아니다.**

| | 문서 65 (발산 모드) | **이 로그 (4 시행)** |
|---|---|---|
| dα/dφ | −0.22 ~ −0.47 | **+0.99 ~ +1.70** |
| φ 진폭 | 12 ~ 15° | **20 ~ 46°** |
| 거동 | 지수 발산 | 반주기 진동 (시행 1·2 는 진폭 20→17, 25→20 으로 **감쇠**) |

**확인이 필요하다 — 발목이 자유롭게 도는 상태가 맞는가?**
문서 66 §6 이 권한 "δ 를 0 에 기구적으로 고정" 을 하면서 **발목까지 같이 잡히지 않았는지**
가장 먼저 볼 것. δ(허리)만 고정되어야 하고 **발목은 반드시 자유**여야 한다 —
매달림 평형도, 안정선도, 발목 자유회전을 전제로 정의된 것이다.

## 6. 다음 회차 — 바뀐 것만

문서 66 §6 의 체크리스트는 그대로 유효하다. **목표 문장 하나와 확인 항목 하나만 바꾼다.**

**바뀐 목표**

- [ ] ~~흔들리게 만든다~~ → **놓은 자리 (φ, β) 와 넘어진 방향을 기록한다.**
      흔들림은 보너스지 조건이 아니다. **넘어져도 그 시행은 성공이다**
- [ ] 진폭은 **±8~10° 이내**로 작게 (지금 ±20~46°). 크게 흔드는 게 목적이 아니다

**새로 추가**

- [ ] **발목이 자유롭게 도는지 손으로 확인**하고 시작 (§5). δ 고정이 발목을 물지 않았는지
- [ ] **φ 엔코더 배선·커넥터 점검** — `raw=16383` 고착은 MISO 문제 (문서 52)
- [ ] 로그 도중 `!` 가 뜨면 **거기서 세션을 끊고 고친다.** 이번엔 65 초 뒤에 떴는데
      284 초를 더 돌아서 91 % 를 버렸다

**펌웨어 보강 1건 추가 제안**
