> `p2r_logger.py` 형식의 CSV 로거를 얹었다. 문서 77(`fold_host.py`) 의 구조를 그대로 따랐다.

## 1. 두 모드 — 접속하면 알아서 고른다

| 보드에 올라간 것 | 모드 | 하는 일 |
|---|---|---|
| `fold_bridge.ino` (문서 77) | ★**제어 모드** | 보드는 R행(원값 2개+δ)만 올리고, 판정·상태기계·안전·로그는 전부 호스트 |
| `single_fold_gamma_cal.ino` | ★**모니터 모드** | p2r_logger 와 동일 — 친 글자는 그대로 보드로, D/R/E 행을 CSV 로 |

⚠ **접속 직후 한 글자도 먼저 보내지 않는다** (문서 77 §6 의 사고 재발 방지). 최대 8 초 듣고 고른다.
R 행은 양쪽에 다 있으므로 **열 수로 가른다** — 브리지 5 열 / 펌웨어 시행요약 16 열.
`--mode auto|host|monitor` 로 강제 가능.

## 2. 만드는 파일 (넷)

```
<이름>.csv          D행  t_ms,phi,ank,alpha,beta,dphi,dbeta,Ahat,hold,del_now,phase,cue,err
<이름>.trials.csv   ★R행 trial,t_ms,A_minus,dd_cmd,dd_act,d0,A_plus,lock_ms,prof_ms,
                          G_pred,g_est,gam_est,gam_set,clip,err        ← 회귀는 이 파일만
<이름>.events.csv   ARM·FOLD·LOCK_END·READY·STOP·파라미터 변경 시각
<이름>.raw.txt      화면에 뜬 것 전부
```

열·자릿수는 펌웨어와 **동일**하다(업로드본 기준, `goaln` 열 없음). 기존 해석 스크립트가 그대로 먹는다.
`goaln`(문서 76 §2 의 자기증명 계수기)은 열로 넣는 대신 **요약 화면에** 찍는다 —
`★모터 명령 1 회 = ★단일접기 확인`, 1 이 아니면 그 시행은 버리라고 말한다.

## 3. 이식하면서 달라진 것 — 다섯 (문서 77 과 같다)

1. **한 틱 = R 행 도착**. 호스트 타이머로 돌면 안 온 샘플로 판정한다.
2. **지연이 한 왕복 늘어난다.** 요약줄이 「명령 → δ 가 실제로 움직이기까지」를 ms 로 찍고,
   창의 25 % 를 넘으면 경고한다. `t` 에 R행 간격 평균·최대도 나온다.
3. **파이프라인은 '상수'가 아니라 '시간'을 지킨다.** 200 Hz 면 `VEL_N=5, EMA_A=0.15` 가
   글자 그대로 나온다(검산 통과). 주기가 다르면 25 ms 기저차분·τ 28 ms 를 지키도록 다시 만든다.
4. **보드 워치독 `wd`(300 ms)** — 호스트가 죽으면 목표를 지금 자리로 얼린다(토크는 안 끊는다).
5. **전압·전류는 P행, vmin 판정은 호스트.**

★**LOCK 창의 기준점은 '접기 명령을 보낸 틱'** 이다. 왕복 지연이 창 안에 포함되지만 시행마다
같으므로 G 에 흡수된다. 스윕 시작 전 `t` 로 지연이 10 ms 를 넘지 않는지 한 번 볼 것.

(켜짐 cue / 꺼짐 max(trig, cue×1.5)), 파라미터 잠금(제어 중 lock 변경 금지), 모니터 행 분류까지 86 항목.

## 5. `--fake` 가상로봇으로 밟아 본 것

`python single_fold_host.py sim1 --fake` — 1차 발산 + 프로파일 서보 + 실측 잡음뿐인 **장난감**.
`--fake-dadd`(기본 0.19, 문서 77 §4)로 dA/dδ 를 넣는다. **이걸로 sgn 이나 γ 를 고르면 안 된다.**

실제로 돌려 나온 것 (문턱 부근의 깨끗한 시행):

| 시행 | A⁻ | Δδ_act | A⁺ | g_est | 판정 |
|---:|---:|---:|---:|---:|---|
| 3 | +0.637 | +2.94 | +1.861 | **−0.206** | ★sgn 뒤집을 것 |
| 4 | +0.652 | +3.08 | +1.585 | **−0.098** | ★sgn 뒤집을 것 |

★넣은 dA/dδ = +0.19 가 g_est ≈ −0.19 로 되돌아 나온다 — **이식이 부호까지 맞다는 확인**이다.
(그리고 문서 77 §4 가 말한 대로, dA/dδ > 0 이면 sgn = −1 이어야 한다는 것을 화면이 스스로 말한다.)

## 6. 쓰는 순서 (실기)

```
python single_fold_host.py 0825_gam_r1        # 포트·모드 자동
z → n(잡음) → y+g(부호확인, dry-run) → h,y → m → gam 5 → z → g → 놓기
→ 자동 접기 1회 → LOCK 120 ms → 요약 R 줄 → h → 0 → gam 바꾸고 → g
```
`gam 5 / 9 / 14 / 20` 을 **섞어서** 각 6 시행 = 24 시행. `lock` 은 스윕 내 고정.
**첫 시행의 `g_est` 부호를 보고 sgn 을 정한 뒤 본 스윕을 시작할 것.**

## 7. 남은 것 / 확인 필요

- 브리지 명령 글자는 문서 77 의 `G/S/W/V` 에 `T`(토크) `K`(복구) `I`(전류제한) `B`(부하시험)
  을 더해 가정했다. **실제 `fold_bridge.ino` 와 다르면 파일 맨 위 `BRIDGE` 표 한 곳만 고치면 된다.**
- `z` 는 호스트가 자기 좌표(`del_off`)로 잡는다 — 보드에 영점 명령을 보내지 않는다.
  `k` 로 리부트가 걸리면 보드 영점이 새로 잡히므로 `z` 를 다시 누를 것(화면도 그렇게 말한다).
- 업로드본 `.ino` 에는 문서 76 §2 의 `goaln` 열과 「(이 시행의 유일한 접기)」 한 줄 합치기가
  아직 없다. 호스트는 **화면에는 둘 다** 넣고 **R 줄 열은 업로드본과 같게** 두었다.
