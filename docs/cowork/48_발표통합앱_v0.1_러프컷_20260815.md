## 1. 설계 한 줄 — 왜 이 구조인가

> **물리는 열 때 한 번만 계산(bake)하고, 화면은 그 결과를 시간축으로 훑는다(scrub).**

발표 요구가 "대부분의 구간에서 물리를 멈추고 우리가 설정하는 속도로 재생"이었으므로,
실시간 적분을 하지 않는 것이 정답이다. 그 결과:

- 어떤 속도로 재생하든 · 뒤로 감든 · 한 프레임씩 넘기든 **항상 같은 그림**
- 접기 60 ms 를 **118× 느리게** 펼쳐 7 초 동안 보여줄 수 있다
- 발표 중 아무 데서나 멈추고 되감을 수 있다 (심사위원 질문 대응)

앱이 노출하는 계약은 **`window.__seek(t)` 하나**다. 시각 `t` 하나가 카메라·기하·상태·평면·
자막·레이아웃을 전부 결정한다(누적 상태 없음). `render.mjs` 는 실시간 재생 대신
`t = n/fps` 를 직접 넣어 프레임을 뽑는다 — **발표 앱과 mp4 가 같은 코드에서 나온다.**

## 4. ★확인 2건

### (a) v19_state 의 평면 상수는 B_THETA = 0 에서만 재현된다

`params_v19.py` 기본값 `B_THETA = 0.01`(**미실측 placeholder**)로 계산하면:

| B_THETA | λ_u | A=0 선 기울기 |
|---|---:|---:|
| 0.01 (params 기본값) | 5.8338 | −1.6648 |
| **0 (v19_state 재현)** | **5.9219** | **−1.6451** |
| 무감쇠 모드 (λ_eff, r) | 5.9228 | −1.6445 |

즉 v19_state 화면의 판정선은 사실상 **무감쇠 값**과 같다 — 남은 감쇠는 c_φ 뿐이고
그 영향이 0.01% 수준이기 때문이다. README 본문의 "감쇠 포함 w_q 에서 나온 선"이라는
서술 자체는 맞지만, **감쇠가 실질적으로 0 인 설정**이라는 점은 드러나 있지 않다.

→ 결정 필요: `B_THETA` 를 0 으로 확정할지, 아니면 실측할지.
힙 점성감쇠는 서보 무전류 자유진동으로 잴 수 있고(params 의 `how` 항목),
0.01 이면 λ_u 가 1.5% 낮아진다 = γ 를 그만큼 낮게 잡게 된다.
(문서 42 의 `실측정본 λ_u = 5.813` 은 B_THETA≈0.01 계열이다.)

이 앱은 화면이 v19_state 와 같아야 하므로 **0** 을 채택했다.

### (b) 문서 42 §3 의 λ_u 불일치 — 아마 세대 차이가 아니라 세트 차이

문서 42 는 "실측정본 모델 λ_u = 5.813 인데 문서 38 은 '모델 ~6.4'" 를 미해결로 남겼다.
`v19_state/README_v19_state.md` 의 평면 상수 표를 보면:

| | 초록 버튼(**설계추정치**) | 빨강 버튼(실측) |
|---|---:|---:|
| λ_u | **6.4472** | 5.9219 |

**문서 38 의 "모델 6.4" 는 설계추정 세트의 6.4472 로 보인다.** 세대가 다른 I_r 을 쓴 것이
아니라 애초에 다른 파라미터 세트를 인용한 것. 문서 42 의 "확인 필요" 항목은 이것으로
설명되지만, 문서 38 원본에서 어느 세트를 썼는지 한 번 대조하고 닫는 것이 좋다.

## 5. 이상화 표시 — 정직하게 남긴 것

⑤·⑦ 앞부분의 deadbeat 접기는 **접기 종료 시 불안정 성분을 정확히 0 으로 투영**한다.
이 투영이 없으면 λ_u = 5.92 /s 아래에서 **수치 잔차가 6 초에 e³⁵ ≈ 2.6×10¹⁵ 배로 자라**
반드시 무너진다 — 물리가 아니라 적분 오차다.

(γ 는 문서 16 의 원칙대로 **실행 눈금(bake dt)에서 다시 잰다**. 이것만으로도 잔차가
크게 줄지만 6 초를 견디지는 못한다. 이론이 말하는 "한 번 접으면 유계"를 그림으로 보이려면
투영이 필요하다.)

**⑦ 뒤쪽의 증분 접기(`incr`)에는 투영이 없다** — 실기에 해당하는 정직한 궤적이다.
τ_return = 1.5 s, ρ = 0.9, 트리거 0.6°, 24 초에 |A|max ≈ 3.3°, |β|max ≈ 1.2°, 접기 46 회.

부수적으로 확인된 것: **ρ = 1.0 이면 δ 가 4.4° 안에 머물지만, ρ < 1 이면 잔차가 쌓여 δ 가
표류**한다(τ=1.5·ρ=0.9 에서 |δ|max 21.7°). 느린 복귀의 시정수가 너무 길면(τ ≥ 2.5, ρ ≤ 0.9)
δ 가 관절한계 55° 에 닿아 **낙하**한다 — 복귀 속도가 자유 변수가 아니라 안정성 제약이라는 뜻.
전물리에서 재확인할 값.
