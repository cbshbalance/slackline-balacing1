## 2. ★ 그러나 α 공식이 틀려 있었다

**문서 52 의 펌웨어 규약이 잘못됐다:**

| | |
|---|---|
| 문서 52 (문서 37 인용) | `α = ank + phi`  ("발목 s = +1, 즉 ank = α − φ 형") |
| **실측이 요구하는 것** | **`α = ank − phi`** |

`p2r_test.ino` 가 이 공식으로 `alpha_deg` 열을 만들고 있으므로 **로그의 alpha 열이 틀린 값이다.**
실기 펌웨어가 같은 규약을 쓴다면 **A 계산 전체가 틀린다.**

### 이 하나로 모든 것이 뒤집힌다

| α 정의 | R²(β̈) | **r** | w_φ | 판정 |
|---|---:|---:|---:|---|
| `ank + φ` (문서 52) | 0.571 | **+0.749** | −1.336 | 모델과 부호 반대 |
| **`ank − φ`** | **0.804** | **−1.506** | **+0.664** | **모델과 8 % 일치** |

**적합 품질도 같이 좋아진다** (R²(β̈) 0.571 → 0.804). 8/21~22 이틀 동안
"β 방정식이 왜 이렇게 안 맞나" 를 발목 마찰·표류·손 접촉으로 의심했던 것이
**전부 이 한 줄 때문**이었다.

### 어떻게 찾았나 — 사용자 지적 (8/22)

사용자가 **"φ = +4 일 때 β ≈ −2 에서 놓았다"** 고 기억했는데 로그는 `+5.3` 을 내놓았다.
α 정의를 바꾸자 같은 시행들의 β 가 **−1.5 ~ −3.5** 로 나왔다 — 기억과 일치.
사용자의 물리적 직관("φ 와 β 는 반대 부호, r 은 음수")도 함께 맞았다.

**교훈: 문서에 적힌 부호 규약을 받아쓰고 검산하지 않은 것이 이틀을 잡아먹었다.**

## 3. 검증 — 세 경로가 같은 답

| 경로 | 쓰는 것 | 결과 |

| **② 놓기점 경계** | 놓은 자리 (φ, β) 와 낙하 방향만. **미분·모델 미사용** | **r = −1.494** (0.8 % 차) |
| **③ Ȧ = λA 시험** | A 가 불안정 좌표인지 직접 검사 | r = −1.5 ~ −2.0 에서 R² 0.88~0.89 |

②는 놓기점이 β = **−0.670·φ** (상관 −0.976) 를 이룬다는 것이고, 1/기울기가 곧 r 이다.
**세 경로가 독립적으로 −1.5 를 가리킨다.**

(참고: ③ 에서 모델의 r = −1.6445 는 R² = 0.890 으로 잘 통과한다.
같은 시험이 **틀린 α 정의에서는 R² = 0.05** 였다 — 정정 전후 차이가 이만큼이다.)

## 5. ⚠ 모델 형태는 고쳐야 한다 — 속도항이 1.7 배

| | w = [w_φ, 1, w_φ̇, w_β̇] |
|---|---|
| **동정 결과** | [+0.6641, 1, **+0.1945**, **+0.3049**] |
| 무감쇠형 `[−1/r, 1, −1/(rλ), 1/λ]` | [+0.6641, 1, +0.1174, +0.1768] |
| 비 | — | **1.66** | **1.72** |

위치항은 맞는데 **속도항이 1.7 배**다. 그리고 안정 실수 고유값이 **−3.25** 로 −λ(−5.66)와
다르다 — **감쇠가 실재한다**는 뜻이고, 무감쇠 가정으로 유도된 w 식이 그만큼 어긋난다.

**→ w 를 감쇠 포함해 재유도해야 한다.** 재측정 없이 이론 쪽에서 지금 할 수 있는 일이다.

문서 50 §0 환율표 대조:

| 놓기 오차 | 문서 50 (모델) | **실측** | |
|---|---|---|---|
| 몸 기울기 β 1° | +1.00° | +1.00° | 기준 |
| 줄 각 φ 1° | +0.60° | **+0.66°** | 10 % |
| 몸 각속도 β̇ 1°/s | +0.17° | **+0.30°** | **1.8 배** |
| 줄 각속도 φ̇ 1°/s | +0.10° | **+0.19°** | **1.9 배** |

**속도를 지금보다 두 배 무겁게 봐야 한다.** "각도 1° = 각속도 6°/s" 는
실측으로는 **1° = 3.3°/s** 다.

## 6. ⚠ c₀ 는 아직 못 정했다

잭나이프 오차가 **±0.86** 으로 값(−1.11)과 같은 자릿수다. 부분표본별로 −0.85 ~ −2.12 로 흔들린다.

**원인은 놓기 자세의 분산 부족이다.** 같은 φ 에서 ank 가 **0.6° 밖에** 안 흩어져 있다
(φ 추세 제거 후 잔차). 기울기 r 은 φ 범위가 넓어 잘 잡히지만, **절편은 수직 분산이 필요하다.**

**보완 측정:** 같은 φ 에서 ank 를 자연값(≈ 0.33·φ)에서 **±3° 벗어나게** 두고 놓기.
각 φ 마다 3~4 점, 총 30~40 회. 그러면 c₀ 가 잡히고, 경계선(②)만으로도 r 이 재확인된다.

A 오프셋 = c₀/r = **+0.73°** 인데 오차가 커서 **±0.6° 수준**이다. 트리거 문턱 0.6° 와
같은 자릿수이므로 **무시할 수 없고, 그래서 보완 측정이 필요하다.**
