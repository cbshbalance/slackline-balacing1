## 3. 왜 3.3 Hz 가 치명적인가

문서 65 의 실측값 **λ = 5.44 /s (T₂ = 127 ms)** 를 그대로 대입하면:

| | |
|---|---|
| 샘플 간격 | **300 ms** |
| 그 사이에 지나가는 배가시간 | **2.36 회** |
| 그 사이에 φ 가 자라는 배수 | **5.1 배** |
| 놓기 한 번당 샘플 | 중앙값 **5 점** (상승부는 실질 2~3 점) |

## 5. ★ 실측 ② 가 실제로 요구하는 것

이번 실패에서 얻은 것이 하나 있다 — **무엇을 재야 하는지가 분명해졌다.**

정지 상태(φ̇ = β̇ = 0)에서 놓으면

```
A = −φ/r + β + c₀/r
```

이고 **A 의 부호가 넘어지는 방향을 정한다.** 그러니:

> **여러 (φ, β) 에서 놓고 낙하 방향을 기록하면, 그 경계선이 곧 A = 0 선이다.
> 기울기에서 r 이, 절편에서 c₀ 가 나온다.**

여기에 필요한 조건이 넷:

1. **영점** — c₀ 는 절편이므로 절대 기준 없이는 의미가 없다. 줄 위 균형 자세에서 `z`.
2. **100 Hz 유효 로깅** — 낙하 방향 판정과 놓기 순간 상태를 함께 뽑으려면 필요하다.
3. **작은 섭동** — |φ| 편위 10° 이내. 선형 영역을 벗어나면 A 자체가 정의를 잃는다.
4. **★ 놓기 자세를 벌려야 한다** — 이것이 이번 회차에 빠진 설계다.
   (φ, β) 가 좁은 덩어리에 뭉치면 **기울기가 안 나온다.** 일부러 흩어 놓아야 한다.

### ⚠ 정정 — δ 를 움직일 필요는 없다 (2026-08-22)

이 문서의 첫 판은 4번을 "**β 를 벌리려면 δ 를 여러 값으로 두어야 하므로 모터가 반드시
살아 있어야 한다**" 라고 적었다. **틀렸다.**

**문서 50 §2 가 이미 정리해 둔 그대로다** — "발목 자유회전의 평형 조건은 **'몸 CoM이 발 위'
하나뿐이고 δ 값과 무관**하다." δ 는 평형을 정하지 않는다.

그리고 δ = 0 으로 고정되면 **β = α** 이고, 발목은 무구동 자유관절이므로
**(φ, β) 평면은 손으로 그대로 열려 있다.** δ 는 β 를 옮기는 여러 방법 중 하나일 뿐이다.

**오히려 δ = 0 이 맞는 자리다.** 모델은 δ ≈ 0 에서 선형화돼 있고, 문서 50 §5 는
δ₀ 의존성(킥 커플링 cos δ)을 **δ₀ = 15° 에서 −3 %, 30° 에서 −13 %** 로 잡는다.
δ 를 크게 벌려 재면 그 오염이 r 안으로 들어온다.

### 단, 갈림길이 하나 있다 — "고정"이 무슨 뜻인가

| δ = 0 의 상태 | β 를 만들 수 있나 | 실측 ② |
|---|---|---|
| **기구적 고정**(핀·클램프) 또는 **토크 ON 유지** | β = α + P2R·0 = **α** — 만들 수 있다 | **가능** |
| **토크 OFF (모터가 죽어 자유)** | δ 가 제멋대로 흔들리는데 **읽을 수가 없다** | **불가능** |

이 로그는 후자인지 전자인지 모른다 — 부팅 때 ping 은 성공해 `torqueOn` 이 나갔지만
그 뒤 통신이 끊겼다. 서보가 마지막 목표를 붙들고 있었다면 δ ≈ 0 이겠지만 **확인할 방법이 없다.**
다음 회차에는 **δ 를 기구적으로 고정하거나, 토크가 살아 있음을 확인하고** 시작할 것.

### ★ 절차는 문서 50 이 이미 써 두었다

문서 50 §2 **Z2** — 영점의 "정식절차" 항목이 그대로 실측 ② 다:

> **여러 φ 에서 흔들리는 β 를 찾아 직선 적합 — 이 절편이 A 오프셋의 정본**

"흔들리는 β" = 발산하지 않고 흔들리다 잦아드는 β = **그 φ 에서의 균형 β.**
그 점들이 A = 0 선 위에 있다.

> ⚠ **정정 (문서 67, 2026-08-22): "흔들리는" 을 달성 조건으로 읽지 말 것.**
> 한 주기를 흔들리려면 놓는 순간 \|A\| < 0.012° 여야 하는데 Â 잡음 바닥이 0.106° 다 —
> **불가능하고, 필요도 없다.** 실제로 기록할 것은 **놓은 자리 (φ, β) 와 넘어진 방향**이고,
> **넘어진 시행도 전부 데이터다.** 자세한 계산은 문서 67 §3·§4.

```
β_bal = (1/r)·φ − c₀/r        →  기울기에서 r,  절편에서 c₀
모델 예측: 기울기 −0.608, 절편 0
```

문서 50 §6 도 같은 말을 한다 — **"이 절차 연습 = 실측②(안정모드선) 연습과 같은 동작이다."**
즉 놓기 프로토콜을 연습하는 것이 곧 실측 ② 이고, **모터 없이 하는 동작이다.**

**초기조건 장치는 문서 50 §4 의 실 릴리즈** — 프레임에서 실을 내려 로봇 머리에 걸고
일부러 실 쪽으로 기대게 세운 뒤 가위로 끊는다. 충격 0, 재현성 좋음.
문서 50 이 "실측 ②③의 초기조건 부여 장치로도 그대로 쓸 수 있다"고 적어 둔 그것이다.

### 참고 — 문서 65 로그에 재료가 조금 있다

λ 로그 19 회의 놓기 순간 (φ, α) 가 낙하 방향으로 갈린다
(+ 낙하 φ 1.45±0.34 / α 0.45±0.70, − 낙하 φ 0.74±0.46 / α 1.25±0.56).
**다만 놓기 자세를 일부러 벌리지 않아서 (φ, β) 가 1.5° 폭의 덩어리에 뭉쳐 있다** —
기울기를 내기엔 부족하고, 거칠게 그은 경계의 부호가 모델 예측 −0.608 과 반대로 나온다.
**원인은 δ 를 안 움직인 것이 아니라 자세를 안 흩은 것이다.**

문서 65 가 낸 **φ_eq = 1.40°** 는 그 덩어리 안에서 발산 부호가 뒤집히는 자리이므로,
**A = 0 선 위의 점 하나**에 가깝다. 그때 α ≈ 0.9° 였다. 예측선(c₀ = 0)이라면 그 φ 에서
β_bal = −0.608 × 1.4 = **−0.85°** 여야 하는데 관측은 **+0.9°** — 1.7° 어긋난다.
**c₀ ≠ 0, 즉 A 오프셋이 실재한다는 신호**일 수 있다. 점 하나라 단정할 수 없으니
**다음 측정의 예측 검증 항목으로 걸어 둔다.**
