> 문서 43의 조치목록 ③을 실험으로 닫기 위한 설계서.
> 대상은 **비동기 FWE가 실제로 쓰는 값만**이다. LQR·완전사이클 유산은 제외한다.
> 재현 스크립트: `lam_sens.py`(민감도·역산), `ident2.py`(w 오차 분해), `ident4.py`(권장 적합법 검증).

## 0. 이 설계의 원칙

1. **게이트를 먼저 못 박는다.** 각 실험은 측정 전에 합격/불합격 기준을 정한다. 측정 후에 기준을 만들면 그건 실험이 아니라 해석이다.
2. **각 양은 독립 경로 두 개로 잡는다.** 같은 원리의 두 번 측정은 한 번 측정이다.
3. **원시값만 기록하고 파생값은 오프라인에서 재계산한다** (문서 34 블랙박스 원칙). A를 저장하면 그때 쓴 w에 갇힌다.
4. **자기정합 검사를 게이트에 넣는다.** 문서 43 ①이 드러낸 교훈 — 결과가 그럴듯한지가 아니라, 결과가 **자기 자신과 모순 없는지**를 본다.

## 사전 작업 — 계산만으로 이미 좁혀진 것

실험을 설계하기 전에, 문서 40 §4-2의 실측 정본 세트로 모델을 다시 세워 확인했다.

**재현 확인 (모델이 문서 43과 같은 것을 말하는지)**

| | 계산값 | 문서 43 |
|---|---|---|
| p₁ / p₂ / h | 0.17510 / 0.12280 / 0.3972 | 동일 |
| λ_u | 5.836 /s | 5.813 |
| w | (0.6004, 1, 0.1029, 0.1679) | (0.6043, 1, 0.1040, 0.1686) |

차이는 S_r을 하단집중(S_r = I_r/R)으로 가정한 탓이며 0.4% 안. 이 모델로 아래를 계산했다.

### ★ 발견 1 — I_r은 용의자에서 제외된다

문서 43 ③은 원인을 "**I_r 또는 I₂_cm**의 세대"로 지목했다. 계산하면 **I_r은 불가능하다.**

| 파라미터 | +10% 시 λ_u 변화 | λ_u = 6.43을 단독으로 만들려면 |
|---|---:|---|
| I_r | **−0.18%** | **불가능** (I_r → 0 이어도 5.954) |
| I₁_cm | −0.08% | 불가능 |
| **I₂_cm** | −1.78% | 0.02116 → **0.01140 (−46%)** |
| **R** | +2.71% | 0.433 → **0.610 (+41%)** |
| m₂ | +2.48% | 0.6406 → **0.936 (+46%)** |
| ell₂ | −1.63% | 불가능 |
| L₁ | −2.21% | 불가능 |

줄 관성은 λ_u에 거의 영향이 없다. 세대가 어떻든 10% 갭을 못 만든다.
**따라서 "문서 38이 어떤 I_r을 썼는지 찾는" 작업은 할 필요가 없다.** 남는 후보는 셋뿐이고, m₂는 저울로 직접 잰 값이라 46% 틀릴 수 없다. **I₂_cm과 R 둘로 좁혀진다.**

### ★ 발견 2 — 유력 시나리오: I₂_cm이 균일막대 근사로 되돌아갔다

`params_v19.py`는 `I2_cm = None`이면 균일막대 근사 `m₂L₂²/12`로 대체한다. 그리고 문서 40 §4-2는 **8/6 저녁 push로 params가 placeholder로 되돌아갔다**고 기록한다 — 문서 38과 같은 날이다.

| 입력 가설 | λ_u | 배가 |
|---|---:|---:|
| 정본 (문서 40 §4-2) | 5.836 | 119 ms |
| **placeholder 전체** | **6.271** | 111 ms |
| **실측 질량표 + I₂_cm만 균일막대** | **6.744** | 103 ms |
| 실측 질량표 + I₁·I₂ 둘 다 균일막대 | 6.769 | 102 ms |
| ★ 문서 38 실측 (14시도 중앙값) | **6.43** | 108 ms |

문서 38의 "모델 ~6.4"는 두 placeholder 가설(6.27, 6.74) **사이에 정확히 들어간다.** 정본(5.84)에서는 나오지 않는다.

**여기서 서사가 뒤집힌다.** 문서 38은 "λ 실측 6.43 = 모델 6.4 → 질량표가 옳다는 첫 실물 검증"이라고 결론냈는데, 그 모델이 placeholder였다면 **실측이 맞춰진 상대가 틀린 모델**이다. 그런데 실측 6.43은 여전히 placeholder 쪽에 가깝다. 즉 둘 중 하나다:

- **H_A**: 정본 I₂_cm(2.116e-2)이 과대 → 모델 5.84가 틀렸고 실측 6.43이 옳다
- **H_B**: 정본이 옳고 → 실측 6.43이 편향됐다 (또는 R이 설계값보다 크다)

이 갈림이 **실험 1**이다.

**참고 — I₂_cm은 물리 상한에 가깝다 (그러나 결정적이진 않다)**

```
균일막대  m₂L₂²/12       = 0.00751
정본값                    = 0.02116   ← 아령한계의 94%
아령한계  m₂(L₂/2)²       = 0.02252   ← 물리 상한 (질량이 전부 양 끝)
회전반경 k = √(I/m)       = 0.1817 m  (막대라면 0.1083)
```

94%는 "질량이 사실상 전부 양 끝"이라는 뜻이라 보통은 의심스럽다. **다만 이 상체는 실제로 아령이다** — XM430이 힙축(아래 끝), OpenCR+배터리가 위쪽 끝. ell₂ = 0.1917이 L₂/2 = 0.1875와 거의 같은 것도 두 덩이가 대칭이라는 신호다. **그래서 값만 보고는 못 자른다. 재측정해야 한다.**

### ★ 발견 3 — 문서 38 w의 자기모순은 대부분 엔코더 양자화다

w가 좌고유벡터라면 `w_q = w_v(λI − D̂)`이므로 **두 행이 같은 λ를 함의**해야 한다 (β행만 B_θ 탓에 2%쯤 어긋남).

| | φ행 = w_φ/w_φ̇ | β행 = w_β/w_β̇ | 불일치 |
|---|---:|---:|---:|
| 모델 정본 | 5.832 | 5.955 | **2.1%** ← 정상 |
| 문서 38 실측 | 5.297 | 7.770 | **31.8%** |

원인을 수치실험으로 분해했다 (참 궤적 → 관측 파이프라인 통과 → 재적합):

| 관측 파이프라인 | w 오차 | 행 불일치 | φ행 / β행 |
|---|---:|---:|---|
| 이상적 (양자화 X, 필터 X) | 0.0% | 2.1% | 5.83 / 5.96 |
| **엔코더 양자화만 (0.022°)** | **39.9%** | **17.3%** | 8.20 / 9.92 |
| 25 ms 이동평균 미분만 | 1.9% | 2.1% | 5.94 / 6.07 |
| 양자화 + 필터 (실제) | 10.4% | 4.6% | 6.34 / 6.65 |

**양자화가 지배적이고, 방향까지 맞다** — 속도 성분을 체계적으로 축소시켜 함의 λ를 부풀린다. 시뮬의 w_β̇ = 0.1008~0.1293과 문서 38의 0.1287, 함의 β행 7.73~9.92와 문서 38의 7.77이 같은 자리에 있다.

**단, φ행은 설명되지 않는다.** 양자화는 두 행을 모두 **위로** 밀지만, 문서 38의 φ행은 5.30으로 **아래**다. 게다가 φ 두 성분의 **부호가 모델과 반대**다. 그래서 문서 38 w의 결함은 최소 둘이다:

- **β행** → 속도 추정 파이프라인 (양자화)
- **φ행** → 부호 규약 또는 φ 모드 미여기 (별도 원인)

이것이 **실험 2와 3**을 가른다.

# 실험 1 — I₂_cm 판별 (반나절)

## 1-0. 판정하려는 것

H_A(정본 과대) 대 H_B(정본 정확). 둘은 λ_u를 10% 다르게 예측하고, 그 10%는 γ 전체와 트리거·접기량으로 그대로 전파된다.

## 1-A. 복합진자 재측정 — 주된 판정 (30분)

**왜 이게 결정적인가:** 두 가설의 예측 주기가 20% 벌어진다. 스톱워치로도 갈린다.

**절차**

1. 상체를 힙축에서 **분리**한다. 장비 매립 상태 그대로(XM430·OpenCR·배터리 포함) — 이게 m₂의 정의다.
2. 힙축 구멍에 수평 축(가는 강선 또는 칼날)을 끼워 자유 회전하게 매단다. **축 마찰이 주기에 영향을 주면 안 되므로 베어링 또는 칼날받침 사용.**
3. m₂를 저울로 재확인 (게이트: 0.6406 ± 0.005 kg).
4. d = 힙축 → CoM 거리를 **균형점법**으로 잰다 (칼날 위에 얹어 균형점 찾기). 게이트: ell₂ = 0.1917 ± 0.003 m.
5. **미소진동**(±5° 이내, 소각 유지) 시켜 **10주기 시간**을 5회 측정 → T = 평균/10.
6. `I_cm = m·g·d·(T/2π)² − m·d²`  (= `calib_analysis.py pendulum --m --d --T`)

**사전 예측 (이게 게이트다)**

| 가설 | I₂_cm | I_pivot | **예측 주기 T** |
|---|---:|---:|---:|
| 정본 옳음 (H_B) | 0.02116 | 0.04470 | **1.210 s** |
| 균일막대 (H_A) | 0.00751 | 0.03105 | **1.009 s** |
| 아령 물리상한 | 0.02252 | 0.04606 | 1.229 s |

10주기 측정이면 T의 불확도는 ±0.005 s 수준 — **두 가설이 40배 여유로 갈린다.**

**함정**

- **소각 유지**: 진폭 15°면 주기가 +0.4% 길어진다. 5° 이내로.
- **축 마찰/스틱션**: 진폭이 몇 주기 만에 반으로 줄면 축을 의심. 앞쪽 5주기만 사용.
- **매단 지그가 같이 흔들리면 안 된다** — 문서 33 ③의 7 Hz 와인드업과 같은 함정. 무거운 받침에 물릴 것.
- **케이블**: 상체에서 나가는 하네스가 매달려 있으면 그 질량·강성이 들어간다. 분리하거나 축 근처에 묶을 것.

## 1-B. 부품표 독립 추정 — 교차검증 (30분, 책상)

복합진자와 **원리가 다른** 경로다.

1. 상체 구성품(XM430, OpenCR, 배터리, 프레임, 볼트류)을 각각 저울로 재고, 힙축 기준 위치를 자로 잰다.
2. `I_pivot = Σ mᵢ dᵢ² + Σ I_i,자체` (각 부품은 작으므로 자체 관성은 균일막대/원기둥 근사)
3. `I_cm = I_pivot − m d²`

**게이트: 1-A와 ±15% 안.** 벗어나면 둘 중 하나가 틀린 것이고, 그때는 1-A를 반복(측정 절차 오류가 흔하다).

## 1-C. R 실측 — 두 번째 후보 제거 (5분)

R은 지금 **MEASURED=False, "설계 예측 43.3cm"** 다. 그런데 λ_u 민감도 3위이고, 단독으로 6.43을 만들려면 0.610 m(+41%)가 필요하다.

**절차:** 상단 베어링 회전축 중심 → 발축 중심 거리를 자로. 조립 상태에서, 크랭크가 중립일 때.

**게이트:** 0.433 ± 0.01 m이면 R은 용의자에서 제외. 0.47 이상이면 λ 갭의 일부를 설명하므로 계산에 반영.

| R | λ_u |
|---:|---:|
| 0.400 | 5.711 |
| **0.433 (설계)** | **5.836** |
| 0.470 | 5.971 |
| 0.500 | 6.077 |
| 0.610 | 6.43 |

# 실험 2 — w와 λ_u 동시 재확정 (반나절)

## 2-0. 왜 다시 하는가

문서 38의 w는 **좌고유벡터가 아니다**(행 불일치 31.8%). 그리고 w는 A를 만드는 벡터 그 자체 — 이게 틀리면 트리거도 증분 크기도 전부 틀린다.

## 2-A. ★ 분석법을 먼저 바꾼다 — 미분하지 않는다

문서 38은 φ, β를 차분해 속도를 만들고 그 4차원 상태에 w를 적합했다. **양자화가 여기서 39.9%를 만든다.**

**대안: 위치 궤적만으로 2×2 부분계를 직접 적합하고, w는 그 행렬에서 해석적으로 뽑는다.**

```
(q_{k+1} − 2q_k + q_{k−1})/Δt²  =  A₂·q_k  +  D̂·(q_{k+1} − q_{k−1})/(2Δt)
                                    └ 미지수 8개, 최소제곱 ┘
F₄ = [[0, I],[A₂, D̂]]  →  좌고유벡터 = w,  최대 실고유값 = λ_u
```

명시적 미분이 없고, λ와 w가 **같은 적합에서 동시에** 나오므로 서로 정합할 수밖에 없다.

**검증 (수치실험, `ident4.py`)** — 실제 양자화 0.022°를 넣고 6시행 적합:

| 진폭 | 유효 샘플간격 | w 오차 | 행 불일치 | λ 추정 (참 5.836) |
|---|---:|---:|---:|---:|
| 기준 | 6.1 ms (원 샘플) | 55.5% | 18.4% | 5.542 |
| 기준 | **24.4 ms** | **4.8%** | **0.3%** | 5.791 |
| 기준 | 97.6 ms | 2.7% | 0.8% | 5.964 |
| **×3** | **24.4 ms** | **0.8%** | **2.0%** | **5.848** |

**설계 결론 두 가지**

- **원 샘플레이트로 2차차분하면 안 된다** (Δt²로 양자화가 증폭). **4~8샘플 데시메이션(≈25~50 ms)** 후 적합.
- **진폭을 키우면 선형으로 좋아진다** (양자화 상대오차 ∝ 1/진폭). 소각 한계(β ≲ 5~6°)까지 최대한 크게.

## 2-B. 프로토콜

**공통 조건**

- 로봇을 줄에 올리고 **모터 토크 OFF, δ를 기계적으로 고정**(δ = 0 유지 — 또는 서보를 위치유지로 두고 δ 로그로 확인). δ가 움직이면 2×2 가정이 깨진다.
- 200 Hz 로깅, **원시 엔코더 카운트로 기록**(각도 변환은 오프라인).
- 시도마다 **s 먼저 켜고** 마커 → 문서 38의 함정 1(앞 26개 마커에 D행 없음) 재발 방지.
- 발목 영점: **z 직전에 t로 ank 판독 정상 확인** → 문서 38 함정 2 방지.

**★핵심 개선 — 초기조건을 다양화한다 (문서 38에 없던 것)**

문서 38은 전부 "기울여 놓기"였다. φ 성분이 거의 안 실려 φ행이 잡음을 봤을 가능성이 크다. 4개 조건을 각 5시도:

| 조건 | 방법 | 실리는 성분 |
|---|---|---|
| **C1 β 단독** | 로봇을 기울여 잡고, 줄은 중립에서 정지 → 놓기 | β |
| **C2 φ 단독** | 로봇을 직립으로 잡은 채 **줄(크랭크)을 옆으로 밀어** 놓기 | φ |
| **C3 반대부호 혼합** | 줄은 왼쪽, 몸은 오른쪽으로 기울여 놓기 | φ, β 반대부호 |
| **C4 속도 부여** | 중립에서 **살짝 밀어** 놓기 (초기 각도 ≈ 0, 속도 ≠ 0) | φ̇, β̇ |

C3가 특히 중요하다 — 안정선 근처를 지나는 궤적이라 안정/불안정 성분이 둘 다 살아 있고, w가 여기서 가장 강하게 구속된다.

**시도당 기록 창:** 놓기 직전 0.5초(정지 확인) + 놓은 뒤 |β| 5~6° 도달까지.

**놓기 품질 게이트 (문서 38의 산포 43% 원인):** 놓기 전 **1초 이상 정지 유지**. 손 흔들림이 보이는 시도는 그 자리에서 버리고 다시. 창 길이 0.22~0.55 s 밖은 제외.

## 2-C. 게이트 (사전 등록)

| # | 게이트 | 통과 기준 | 불합격 시 |
|---|---|---|---|
| G1 | **행 자기정합** | φ행/β행 함의 λ 불일치 **< 5%** | 적합 실패 — 데시메이션·진폭·조건 다양성 점검 |

## 2-D. 이 실험이 동시에 주는 것

`D̂` 행렬이 함께 나오므로 **c_φ(줄 점성감쇠)와 B_θ가 실측된다.** 지금 c_φ = 3.3e-4는 문서 33의 갱신값이지만 조립·배선 후 재측정이 필요하다고 문서 34가 적어둔 항목이다. 별도 실험이 필요 없어진다.

말씀대로 "조절하면 되는" 것이지만, **w의 φ 부호 문제가 여기 걸려 있을 수 있으므로** 실험 2 앞에 둔다. 정적 시험만으로 끝난다.

# 실험 4 — γ_h 시험 접기 (반나절, 실험 1·2 이후)

## 4-0. 무엇을 재는 것인가 — 그리고 무엇을 안 재는가

`A⁺ = G·A⁻ − g·Δδ`를 회귀로 잡아 **γ_h = G/g**. 프로파일 형상인자 B(x), 도착 감속, 백래시, 기어 효율, 결합부 와인드업은 **전부 g 안에 흡수된다.** 하나씩 재려 들면 문서 43 ①의 재발이다 (이론으로 G와 g를 따로 계산하다 구간을 어긋나게 잡아 γ가 e^{λT_rest}배 부풀었던 사고).

**철칙: G와 g는 반드시 같은 구간의 같은 시행에서 나온다.**

## 4-1. 비동기에서는 재는 구간이 다르다

완전 사이클의 Gc/gc(접기→대기→펴기→휴지)가 아니라 **증분 1회 + LOCK 구간**이다:

```
A⁻ = 증분 명령 직전            (LOCK 시작)
A⁺ = LOCK 종료 시점 (120 ms)   ← 실행이 끝나고 A가 다시 읽히는 그 순간
```

이 정의가 곧 제어기가 실제로 겪는 맵이다.

## 4-2. ★ 탐침 모드 — 펌웨어 소폭 추가가 필요하다

폐루프로 돌면서 재면 Δδ가 A에 비례해 **공선성**이 생겨(문서 28 부록의 그 문제) G와 g가 분리되지 않는다. **Δδ를 A와 독립으로 주입해야 한다.**

**요청 기능 (`fwe_async_v19.ino`)**

- 키 `p` : 탐침 1회 — 현재 δ를 유지한 채 **미리 정한 Δδ를 트리거와 무관하게** 주입
- 파라미터: `PROBE_D0`(유지각), `PROBE_DD`(증분), 시행마다 시리얼로 변경 가능
- 로그: 주입 시각, A⁻, Δδ 명령, 실제 δ(t) 전체, LOCK 종료 시각, A⁺
- 안전: |A| > 2.0°면 탐침 거부하고 정상 제어로 복귀 (넘어지는 중에 탐침 금지)

## 4-3. 스윕 설계

**2인 작업.** 한 사람이 줄 위에 올리고 잡아주고, 한 사람이 시리얼.

| 축 | 값 | 왜 |
|---|---|---|
| 유지각 δ₀ | 0°, ±15°, ±30° | **문서 28: 유지 자세의 증분 킥은 이론과 크게 다르다** — δ₀ 의존성이 있는지가 핵심 질문 |
| 증분 Δδ | ±3, ±6, ±12, ±22° | **문서 26 ④: 캡 기준은 관절한계가 아니라 환산비의 유효범위** — g가 Δδ에 선형인 구간을 찾는 것 |
| 시행 | 각 조합 3회 | 5×8×3 = 120 시행 |

Δδ = 0 시행을 각 δ₀마다 5회 섞어 넣는다 — **그게 G 단독 측정**이다(A⁺ = G·A⁻).

## 4-4. 분석

1. δ₀별로 묶어 `A⁺ = G·A⁻ − g·Δδ` **2변수 최소제곱**. G와 g의 표준오차를 함께 낸다.
2. **g(δ₀) 곡선**을 그린다 — 평평하면 문서 28의 "유지 자세에서 다르다"가 δ₀ 의존이 아니라 상수 오프셋이라는 뜻이고, 기울어지면 유지각에 따라 환산비를 스케줄해야 한다.
3. **g(Δδ) 선형성**: Δδ 크기별로 나눠 g를 다시 잰다. g가 꺾이는 지점이 **STEP_CAP의 물리적 근거**다 (현재 22°는 r3에서 경험적으로 정한 값).
4. γ_h = G/g, ρ 여유는 `|G(1−ρ)| < 1`에서.

## 4-5. 게이트

| # | 게이트 | 기준 | 불합격 시 |
|---|---|---|---|
| H1 | **G 자기정합** | 회귀 G ≈ e^{λ_u·(실행+LOCK 시간)} **±20%** | λ_u(실험 2)나 시간 정의가 틀림 |
| H2 | 회귀 설명력 | R² > 0.7 | 산포가 신호를 덮음 — 진폭↑ 또는 시행↑ |
| H3 | 이론 눈금 | γ_h가 정정 공칭(실측정본 17.4)의 **0.5~2배** | 부호·규약 의심 (문서 43 ①처럼 배율 오류) |
| H4 | δ₀ 의존성 | g(δ₀) 변동 < 30%면 상수로 채택 | 크면 스케줄링 필요 — 펌웨어 설계 변경 |
| H5 | 선형 구간 | g가 ±10% 안에 머무는 Δδ 범위 확인 | 그 값이 새 STEP_CAP |

## 4-6. 위험

- 120 시행은 줄 위에서 넘어짐을 수반한다. **낙하 안전(매트·잡아주는 사람) 필수.**
- 결합부 7 Hz 진동(문서 32·33 미해결)이 큰 Δδ에서 여기된다. Δδ = 22° 조합은 마지막에.
- 문서 40 ①의 `PROF_ACC 250 → 600` 변경은 **이 실험 전에 결정**해야 한다. 프로파일이 바뀌면 g가 바뀌므로, 바꿀 거면 먼저 바꾸고 재야 한다.
