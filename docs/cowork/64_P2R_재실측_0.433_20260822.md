## 4. 읽히는 것 네 가지

### 4-1. 절편 −0.093° → 참영점 절차가 제대로 먹었다
매달아 `z` 를 눌렀으므로 절편은 **구조적으로 0** 이어야 하고, 실제로 0.09° 이내다
(α 잡음 표준편차 0.057° 의 1.6배). 문서 57 의 미결 항목 "어느 영점 절차였나" 는
이 측정에 한해 **참영점 취득 경로**로 확정. 따라서 이 로그로는 발목 엔코더의
기존 영점 오차는 잴 수 없다 — 그것을 원하면 별도 회차(기계 기준면 `z` → 매단 뒤 `z` 금지)가 필요.

### 4-2. 잔차는 곡률이 아니라 **히스테리시스**다
잔차 부호가 상행 전부 −, 하행 전부 + 로 깨끗이 갈린다. 2차항이 아니라 마찰 데드밴드다.

- 상행선 − 하행선 = **0.139°** (δ=20 기준, α 환산)
- 기울기 차는 0.4322 vs 0.4346 = **0.6 %** — 기울기에는 거의 안 실린다.
- → 문서 52 가 권한 **상·하행 평균(0.4334)** 이 데드밴드를 상쇄한 값이고,
  전체 적합 0.4328 과 0.0006 밖에 안 난다. 어느 쪽을 써도 같다.

## 6. 아래로 미치는 영향

P2R 은 **w 재계산과 무관**하다 — w = [−1/r, 1, −1/(r·λ), 1/λ] 에 P2R 이 들어가지 않는다.
들어가는 곳은 β 합성 한 군데뿐:

```
β = α + P2R·δ      →      Δβ = δ · ΔP2R
```

즉 **A(β환산 °) 오차 = 접힌 각도 × P2R 오차.** 정본을 0.417 로 두었을 때의 오차:

| 상황 | δ | Δβ = δ·0.0158 | 문턱 0.6° 대비 |
|---|---|---|---|
| 평시 접기량 (0.95·10·0.6) | 5.7° | 0.09° | 15 % |
| 중간 | 20° | 0.32° | 53 % |
| 큰 외란 | 38° | **0.60°** | **100 %** |

- **평시(δ≈6°)는 무차별**, 큰 접기에서만 문제.
- 문서 60 §3-4 **펴기 자기주입** 재계산: `W_βdot·P2R·vrel` = 0.189×0.4328×3 = **0.245°**
  (0.417 기준 0.236° → 펴기게이트 0.3° 의 79 % → **82 %**). 결론은 그대로 — 게이트를 펴기가 다 먹는다.
- 실기 반영은 재컴파일 불필요: 시리얼에서 **`p2r 0.433`** 한 줄 (문서 60 §4-1, 제어 정지 중).

## 7. ★ 0.417 은 폐기한다 — 고장난 발목 센서로 잰 값이다

**사용자 확인 (8/22): 8/17 이후 발목 센서를 실제로 수리했다.**
이것으로 0.417 과 0.433 의 차이가 설명된다.

**8/17 의 P2R 측정은 발목 채널이 고장난 상태에서 이루어졌다.**
그리고 P2R 은 **발목각 α 를 δ 로 나눈 기울기**이므로, 발목 채널의 오차가 그대로 답에 실린다.
문서 57 이 그때 예측값과의 일치를 근거로 판정을 내릴 수 있었던 것은 우연이다.

한 가지 구분이 필요하다:

| 고장의 성분 | 기울기에 미치는 영향 |
|---|---|
| **백색 잡음** (문서 54 가 잰 0.223°) | 평균이 0 이라 **기울기를 체계적으로 밀지 않는다.** 산포만 키운다 |
| **각도의존 오차** (자석 갭·편심·기울기가 만드는 1차 고조파) | **기울기를 그대로 민다.** 그리고 이건 문서 54 의 고주파 분석에 **안 잡힌다** |

문서 54 가 지목한 원인 후보 1번이 "자석 갭·정렬" 이었고 수리가 그것을 고쳤다면,
**같은 결함이 잡음과 각도의존 오차를 동시에 만들고 있었다**고 보는 것이 자연스럽다.
잡음만으로 3.8 % 를 설명하려면 δ=20 에서 0.33° 의 **한쪽으로 치우친** 오차가 필요한데,
백색 잡음은 그런 일을 하지 않는다.

**지금 채널이 깨끗하다는 증거** — 이번 적합의 잔차에 **곡률이 없다**.
자석 편심이 남아 있으면 α 가 0→−16° 로 도는 동안 사인꼴 잔차가 나타나야 하는데,
잔차는 상행 −/하행 + 로 깨끗이 갈리는 **순수 히스테리시스**다 (§4-2). R² = 0.99972.

### 그래서 바뀌는 것

| | 이전 | **지금** |
|---|---|---|
| 실기 정본 P2R | 0.417 (문서 57) | **0.4328** |
| 0.417 의 지위 | 실측 정본 | **폐기** — 수리 전 센서로 잰 값 |
| 문서 57 의 판정문 | "예측과 1.2 % 일치 → 교차검증됨" | **무효** — 근거가 된 실측이 폐기됐다 |

문서 57 이 남긴 "보강할 것" 세 줄(원 로그·적합표 / 절편 / 영점 절차)은 이 문서가 전부 채웠고,
그 결론은 뒤집혔다. **문서 57 은 이 문서로 대체된다.**

### 남은 자체검증 하나 — 배선 복원 토크

매달림 측정의 전제는 "평형에서 무게중심이 발목축 바로 아래" 다.
발목축을 **케이블이 가로지르면** δ 에 따라 복원 토크가 생겨 평형점을 밀 수 있고,
그건 기울기에 그대로 실린다. 이번 로그로는 못 가른다 (히스테리시스 0.139° 는 쟀지만
그 안의 배선 성분은 분리 안 됨).

**확인 방법:** 매단 상태에서 **발목 배선을 느슨하게 늘어뜨리고 같은 측정을 반복.**
기울기가 안 움직이면 0.4328 이 확정되고, 움직이면 그 차이가 배선 토크의 크기다.
10 분이면 되는 측정이고, 정본을 못 박기 전에 한 번 해 두면 이 값은 더 건드릴 일이 없다.

## 부록. 재현 절차 — `p2r_fit_0822.py`

```
python3 p2r_fit_0822.py 0822_p2r_test.csv 0822_p2r_test.events.csv
```

1. **구간 자르기** — `events.csv` 의 MOVE 시각을 경계로 100 Hz D행을 9구간으로 나눈다.
   로그 시작(313684 ms) 이전의 MOVE 2건은 4 Hz 예열 구간이라 CSV 에 없으므로 버린다.
2. **점 만들기** — 각 구간 **마지막 2 s = 201 샘플**의 `del_now_deg`·`alpha_deg` 평균.
   ★나누는 것은 **명령각이 아니라 실제 δ** (문서 52 의 경고, §4-3 에서 6.8% 로 확인).
3. **최소제곱** — α = a₀ + b·δ, `b = Sxy/Sxx`, `a₀ = ȳ − b·x̄`, **P2R = −b**.
   기울기 표준오차 `SE = √(SSE/(n−2)/Sxx)`.
4. **교차검산** — 상행만/하행만/상하행평균/원점강제/인접차분/평균창 0.5~3 s (§3, §5).
