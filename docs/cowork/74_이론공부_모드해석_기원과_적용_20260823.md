# 74. 이론 공부 ① — 우리가 말하는 "모드 분석"은 어디서 왔는가 (2026-08-23)

> 전람회 질의응답 대비 학습 문서. 짝꿍 문서: 75(제어 기호 사전).
> 전제 지식: 문서 05 「모드분석 첫걸음」(행렬·고유벡터·모드 좌표)을 마친 상태.
> 이 문서는 **개념의 족보**를 다룬다 — "여러분이 하신 게 모달 해석인가요?"라는 질문에
> 정확하게, 자신 있게 답하기 위한 문서다.

---

## 0. 세 줄 요약 (질문에 대한 직답)

1. **맞다. 우리가 "모드 분석"이라 부르는 것의 영어 명칭이 Modal analysis다.**
   더 정확히는, 기계공학 진동학(vibration theory)의 모달 해석이 쓰는 **수학적 핵심 —
   고유값 문제(eigenvalue problem)와 모드 좌표 변환** — 을 그대로 쓴 것이다.

2. **"모달 해석 기법을 같은 진동계에 응용했다"는 이해는 거의 맞고, 한 군데만 고치면 완벽하다.**
   고전 모달 해석은 **안정한 구조물**(모든 모드가 진동)을 전제한다. 우리 계는 중력이
   음(−)의 강성으로 작용하는 **불안정 평형** 주변이라 **고유값 하나가 양수**로 나오고,
   그 모드는 진동(cos)이 아니라 **지수 발산(cosh)** 한다. 즉 우리는
   "모달 해석의 수학을, 진동 모드와 발산 모드가 섞인 계로 확장 적용"한 것이다.

3. 이 확장은 우리가 발명한 것이 아니라 **제어이론·동역학계 이론에서 표준적으로 쓰는
   '선형계의 모드 분해(modal decomposition)'** 다. 그러니까 우리 연구는
   구조진동의 모달 해석과 제어이론의 모드 분해가 **같은 수학의 두 얼굴**임을 보여 주는
   자리에 서 있다.

## 1. 용어부터 정확히 — mode, modal, 모드 해석

| 용어 | 영어 | 뜻 |
|---|---|---|
| 모드 | (normal) mode, eigenmode | 계가 "모양을 유지한 채" 하나의 시간법칙으로 움직이는 특별한 운동 |
| 고유진동수 | natural frequency, ωₙ | 각 진동 모드가 갖는 고유한 진동수 |
| 모드 형상 | mode shape | 그 모드에서 각 좌표가 움직이는 **비율**(= 고유벡터) |
| 모달 해석 | modal analysis | 계의 운동을 모드들로 분해해 해석하는 방법론 전체 |
| 모드 좌표 | modal coordinates | 상태를 고유벡터 축으로 읽은 좌표 (방정식이 분리됨) |
| 모달 중첩(법) | modal superposition | 임의의 운동 = 모드들의 합으로 재구성 |

주의할 어감 하나: 공학 현장에서 "모달 해석(modal analysis)"이라고만 말하면
보통 **구조물의 고유진동수·모드 형상을 구하는 일**(해석적이든 실험적이든)을 가리킨다.
우리처럼 **불안정 모드까지 포함해 상태를 분해하는 일**은 현장에서는
"모드 분해(modal decomposition)" 또는 "고유모드 해석(eigenmode analysis)"이라고
부르는 경우가 많다. 발표에서는 "모달 해석의 수학을 확장 적용했다"고 말하면
두 진영 모두에게 정확하게 들린다.

## 2. 기계공학에서의 족보 — 이 개념은 어디서 시작했나

모드라는 개념의 역사는 "복잡한 진동을 단순한 진동의 합으로 볼 수 있는가"라는
질문의 역사다.

**(1) 출발점: 현(줄)의 진동 논쟁 (18세기).**
바이올린 줄이 어떻게 우는가를 두고 다니엘 베르누이(Daniel Bernoulli),
달랑베르(d'Alembert), 오일러(Euler)가 논쟁했다. 베르누이가 내놓은 답이
모드 개념의 원형이다 — "줄의 임의의 진동은 **정상파(배음)들의 중첩**이다."
기본음, 2배음, 3배음… 각각이 '모양(사인 곡선의 마디 수)을 유지한 채 자기
진동수로 흔들리는 운동', 즉 모드다. 우리가 쓰는 '모달 중첩'이 여기서 태어났다.

**(2) 수학적 정식화: 라그랑주 → 레일리 (18~19세기).**
라그랑주 역학이 다자유도 계의 운동방정식을 **M q̈ + K q = 0** 꼴로 쓰는 길을 열었고
(우리가 운동방정식을 세운 바로 그 방법이다), 레일리(Rayleigh)가 『소리의 이론
(The Theory of Sound, 1877)』에서 다자유도 진동의 일반 이론 — 고유진동수,
모드의 직교성, 감쇠 근사(레일리 감쇠) — 을 집대성했다. 오늘날 기계진동
교과서(Rao, Inman 등)의 뼈대가 이 책이다.

**(3) 공학 도구화: 구조동역학과 FEM (20세기 중반).**
항공기 날개의 플러터, 건물의 지진 응답, 회전 기계의 위험 속도 같은 문제를 풀기
위해 모달 해석이 구조동역학(structural dynamics)의 핵심 도구가 됐다. 1960년대
유한요소법(FEM)이 등장하면서 "CAD 모델 → 질량행렬 M·강성행렬 K → 고유값 문제
→ 고유진동수와 모드 형상" 파이프라인이 표준이 됐다. 오늘날 ANSYS나 Abaqus에서
'modal analysis'를 돌린다는 말이 정확히 이것이다.

**(4) 실험 모달 해석 EMA (1970년대~).**
컴퓨터와 FFT의 보급으로, 실물을 **두드려 보고**(임팩트 해머) 응답을 재서
주파수응답함수(FRF)로부터 고유진동수·감쇠비·모드 형상을 **측정**하는
실험 모달 해석(Experimental Modal Analysis)이 산업 표준이 됐다.
"모델 없이, 거동에서 모드를 읽어낸다"는 발상 — 우리의 놓기 실험(실측 ②·③)이
정신적으로 여기에 속한다(§5).

**(5) 제어이론으로의 확장 (20세기 중반~).**
상태공간 이론이 ẋ = Ax 꼴의 선형계를 다루면서, A의 고유값·고유벡터로 계를
분해하는 **모드 분해**가 표준 도구가 됐다. 여기서는 고유값이 음수일 이유가 없다 —
**양수 고유값 = 불안정 모드**라는 개념이 자연스럽게 들어오고, "안정 부분공간 /
불안정 부분공간"이라는 언어가 생긴다. 우리 연구의 '안정모드선'이 정확히
이 언어다(안정 부분공간을 속도-0 평면으로 자른 단면).

한 줄로 족보를 정리하면:

> **베르누이의 배음(모드의 발견) → 라그랑주·레일리(수학 정식화) →
> 구조동역학·FEM(공학 도구화) → EMA(실험으로 모드 측정) →
> 제어이론(불안정 모드까지 일반화) → 우리 연구.**

## 3. 표준 모달 해석의 수학 — 교과서가 하는 일

기계진동 교과서의 모달 해석은 다음 절차다. 우리 연구와 한 단계씩 비교하기 위해
표준형을 먼저 적는다.

무감쇠 다자유도 진동계:

```
M q̈ + K q = 0          (M: 질량행렬, K: 강성행렬, 둘 다 대칭·양정치)
```

조화해 q = v·cos(ωt) 를 대입하면 **일반화 고유값 문제**가 된다:

```
K v = ω² M v      ⇔      det(K − ω²M) = 0
```

- 해 ω₁ < ω₂ < … 가 **고유진동수**, 각각의 v가 **모드 형상**.
- K, M이 양정치이므로 **ω²이 전부 양수** — 모든 모드가 진동한다. (★여기가
  우리와 갈라지는 지점이다.)
- 모드 형상들은 M-직교(vᵢᵀMvⱼ = 0)라서, 모드 좌표로 갈아타면 방정식이
  1자유도 진동으로 완전히 분리된다 (문서 05의 6장에서 한 그 일).
- 임의의 초기조건 응답 = 모드 응답의 합 (모달 중첩).

우리의 Wait 단계 방정식 M₂₂q̈ = G₂₂q 는 K = −G₂₂로 읽으면 정확히 이 틀이다.
차이는 딱 하나 — **G₂₂에 중력의 '넘어뜨리는' 항이 있어서 K가 양정치가 아니다.**

## 4. 우리 계에서 무엇이 달라지는가 — 음의 강성과 발산 모드

강성 K의 물리적 의미는 "변위를 되돌리는 힘의 계수"다. 용수철은 늘 되돌리니
K > 0. 그런데 **역진자에서 중력은 기울수록 더 넘어뜨린다** — 복원이 아니라
반(反)복원, 즉 **음의 강성**이다. 우리 계의 G 행렬(문서 01)을 보면:

```
G = diag(−M_t gR,  p₁g,  p₂g)
```

φ 성분(−M_t gR)은 음수 = 줄 진자는 복원(안정), α·θ 성분(+p₁g, +p₂g)은
양수 = 몸 기울기는 반복원(불안정). 이 부호 혼합 때문에 고유값 문제
det(A₂ − λI) = 0의 해가 **한쪽은 λ = −ω_eff² < 0 (진동), 한쪽은
λ = +λ_eff² > 0 (발산)** 으로 갈라진다.

수학적으로 무슨 일이 벌어지는지는 단진동 방정식 하나로 요약된다:

| 모드 방정식 | 해 | 이름 |
|---|---|---|
| s̈ = −ω² s | cos(ωt), sin(ωt) | 진동 모드 (구조진동의 모드) |
| s̈ = +λ² s | cosh(λt), sinh(λt) = e^{±λt}의 조합 | **발산 모드** (우리의 불안정 모드) |

여기서 중요한 관찰: **고유값 문제를 푸는 절차는 한 글자도 안 바뀐다.**
특성방정식을 세우고, 근을 구하고, 고유벡터를 구하고, 모드 좌표로 분해한다 —
문서 05에서 배운 그대로다. 바뀌는 것은 **해석**뿐이다. 근의 부호가 섞여 나오고,
양수 근의 모드는 e^{λt}로 자란다. 그래서 "모달 해석 기법을 응용했다"는 서술이
성립하는 것이다.

참고로 이런 "복원력이 음이 되어 진동 대신 단조 발산하는 불안정"을 공학에서는
**발산 불안정(divergence instability)** 이라 부른다(항공탄성학에서 날개가
비틀려 나가는 정적 발산, 구조공학의 좌굴이 친척 개념이다). 진동하며 자라는
플러터(flutter)와 구별된다 — 우리의 불안정 모드는 진동 없이 자라는 순수
발산형이다(실측 고유값 +5.66이 실수라는 것이 그 증거다).

## 5. 우리 연구 ↔ 표준 모달 해석 — 무엇을 가져왔고 무엇을 바꿨나

### 5-1. 그대로 가져온 것

| 표준 모달 해석 | 우리 연구 |
|---|---|
| M q̈ + K q = 0 (라그랑주로 유도) | M₂₂ q̈ = G₂₂ q (라그랑주로 유도, K = −G₂₂) |
| 고유값 문제 det(K − ω²M) = 0 | det(A₂ − λI) = 0, A₂ = M₂₂⁻¹G₂₂ |
| 고유진동수 ωₙ | 안정모드 진동수 ω_eff |
| 모드 형상 (진폭 비율) | r = v₁의 φ성분/β성분 (안정모드선의 기울기) |
| 모드 좌표 변환 s = V⁻¹q | 모드 성분 분해 — 좌고유벡터 사영 s₂ ∝ u₂ᵀq |
| 모달 중첩: 운동 = Σ 모드 | q = s₁v₁ + s₂v₂ (진동 + 발산의 중첩) |
| 커플링은 좌표의 성질 (대각화로 소멸) | 관성 커플링(M의 비대각)이 모드 좌표에서 소멸 |

### 5-2. 확장·변형한 것

**① 고유값의 부호 혼합.** §4. 이것이 개념적으로 유일한 본질적 차이다.
구조 모달 해석의 목적은 "공진을 피하자"(고유진동수를 알아내 가진 주파수와
떨어뜨리기)이고, 우리의 목적은 "발산을 죽이자"(불안정 모드 성분을 0으로)다.
같은 수학, 다른 사용 목적.

**② 2차식(위치만) → 상태공간 4차원.** 교과서 모달 해석은 M q̈ + K q = 0의
위치 공간에서 논다. 우리는 속도까지 넣은 상태 x = (φ, β, φ̇, β̇)의
ẋ = Ax 꼴로 확장했고, 그 위에서 불안정 고유값 λ의 **좌고유벡터 w**로
위험도 A = w·x를 정의했다(문서 54). 좌고유벡터 사영은 표준 모달 해석에서도
모드 좌표를 꺼내는 정식 도구다(V⁻¹의 행들) — 우리는 그중 **불안정 모드의 행
하나만** 꺼내 쓰는 셈이다.

**③ 감쇠·비대칭의 현실.** 교과서 기본형은 무감쇠·대칭 행렬이라 고유벡터가
직교하고 만사가 깨끗하다. 실물 동정(실측 ②)에서 나온 4×4 행렬은 비대칭이고
감쇠 항 C가 붙는다. 그러면 좌고유벡터 ≠ 우고유벡터(전치)가 되고, 속도항이
단순한 1/λ 할인이 아니게 된다 — 문서 70 §7의 w_v = w_q(λI − C)⁻¹ 이 그
일반형이다. "감쇠가 있으면 좌·우 고유벡터를 구별해야 한다"는 것도
일반화 모달 해석(비고전 감쇠, non-classically damped systems)의 표준 주제다.

**④ 실험 모달 해석과의 평행 — 그리고 세 실측의 서로 다른 신분.**

> ⚠ **약자 주의 — 이 프로젝트에는 EMA가 두 개 있다.**
> 문서 54의 EMA는 **지수이동평균**(exponential moving average, 속도 필터 τ≈28 ms)이고,
> 이 절의 EMA는 **실험 모달 해석**(experimental modal analysis)이다.
> 펌웨어와 코드가 이미 전자로 굳어 있으므로 규약을 정한다 —
> **약자 EMA는 지수이동평균에만 쓰고, 실험 모달 해석은 항상 풀어 쓴다.**
> (발표 슬라이드·질의응답에서도 마찬가지. 아래부터 풀어 쓴다.)

우리 실측 세 개는 실험 모달 해석과 **같은 지위가 아니다.** 상태공간으로 가르면 깨끗하다:

| 실측 | 어느 행렬에서 나오나 | 실험 모달 해석과의 관계 |
|---|---|---|
| **P2R** | **C (관측식)** — β = α + P2R·δ | **관계 없다.** 정적 질량특성 측정(현수법) |
| **λ** | **A (동역학)** — 고유값 | **매우 가깝다.** 로그 감쇠법의 부호를 뒤집은 것 |
| **r** | **A (동역학)** — 고유벡터 | **가깝다.** 시간영역 모드 추출(ITD·ERA) 계열 |

즉 **λ와 r을 함께 재면, 불안정 모드 하나에 대해 실험 모달 해석이 주는 것과 정확히
같은 것 — 고유값 + 모드 형상 — 을 얻는다.** P2R은 그 바깥이다. 센서 값에서 상태 β를
만들어 내는 상수라서 동역학(A)이 아니라 관측식(C)에 속한다. 실험 모달 해석은
A 행렬 쪽의 이야기이므로, P2R을 여기 끼워 넣으면 틀린다.

**기법별로 짚으면:**

| 표준 기법 | 우리가 한 것 | 같은가 |
|---|---|---|
| 임팩트 해머 가진 + FRF 곡선적합 | — | ✗ 안 했다 (아래 이유) |
| **로그 감쇠법** (자유응답 포락선을 log에서 직선적합) | ln\|ψ\| 대 t 직선적합 → λ (실측 ③) | ○ **부호만 반대** |
| **시간영역 모드 추출** (ITD, ERA — 자유응답에서 모드) | (φ̈,β̈) 회귀 → 4×4 → 고유분해 → r (실측 ②) | ○ 같은 계열의 간략판 |
| **출력만 쓰는 동정** (OMA) | 입력 힘을 안 잰다 — 놓기만 한다 | ○ 정신이 같다 |
| 모델 업데이트 (FEM 값과 대조) | 예측(λ 5.92, r −1.6445) vs 실측(5.44~5.66, −1.506) 대조 → **부호 버그 검출** | ○ 그대로 |
| 현수법 무게중심 측정 | 발목축 매달기 → P2R (실측 ①) | 모달과 무관한 별개 기법 |

### ★ 우리가 FRF를 못 쓰는 근본 이유

실험 모달 해석의 뼈대는 주파수응답함수(FRF)다. 그런데 **FRF는 정상상태가 존재해야
정의된다** — 일정 주파수로 계속 흔들면 일정 진폭으로 응답한다는 전제 위에 서 있다.
우리 계는 **122 ms마다 2배로 발산**하므로 정상상태가 아예 없다. 주파수 스윕을
시작하는 순간 로봇이 넘어진다. 그래서 우리는 선택이 아니라 **필연적으로 시간영역**
으로 갔다. "왜 FRF를 안 썼나"는 게으름이 아니라 계의 성질이다.

이건 우리만의 사정이 아니다. 항공기 **비행 플러터 시험**이 정확히 같은 문제를 안고
있어서, 속도를 올려 가며 모드 감쇠가 0을 향해 가는지를 **시간영역 자유응답**으로
추적한다. "불안정해질 수 있는 계의 모달 시험"이라는 분야가 따로 있고, 우리는 그
분야가 다루는 상황 — **감쇠가 이미 음수인 모드** — 에 서 있는 셈이다.

### 오히려 우리 쪽이 쉬운 점 하나

ITD·ERA 같은 알고리즘이 복잡한 이유는 **상태를 직접 못 보기 때문**이다. 가속도계
몇 개의 출력만으로 내부 상태공간을 재구성(realization)해야 한다. 우리는 엔코더가
φ·α·δ를 직접 주고 차분으로 속도까지 만들 수 있어서, **운동방정식을 그대로 회귀**
하면 4×4 행렬이 바로 나온다. 그래서 고등학생이 numpy 몇 줄로 할 수 있었다.
자유도가 2개뿐이라 "모드 형상"이 공간 분포가 아니라 **비율 하나(r)**로 끝나는 것도
같은 이유의 축복이다.

### 5-3. 제어이론 쪽에서 본 같은 그림

제어이론은 ẋ = Ax의 고유값을 **극점(pole)** 이라 부르고, Re(λ) > 0인 극점이
하나라도 있으면 불안정하다고 판정한다. 그 관점에서 우리 연구를 다시 말하면:

- 우리의 λ(= +5.66)는 **우반평면 극점**이고,
- 안정모드선은 **안정 부분공간(stable subspace)** 의 단면이고,
- FWE의 접기는 "상태를 안정 부분공간 위로 사영시키는 임펄스 제어"이고,
- A = w·x는 "불안정 모드 좌표" — 제어가 감시해야 할 단 하나의 숫자다.

구조진동의 언어(모드, 고유진동수)와 제어의 언어(극점, 부분공간)가 같은
수학을 다르게 부르는 것뿐이라는 사실 — 이것을 알고 있으면 심사위원이 어느
분야 사람이든 같은 내용을 그쪽 언어로 답할 수 있다.

## 6. 흔한 오해 정리 (스스로 점검용)

- **"모드 = 진동"이 아니다.** 모드는 "모양을 유지하는 운동"이고, 시간법칙은
  고유값 부호에 따라 진동(cos)일 수도 발산(cosh)일 수도 있다. 우리 계에는 둘 다 있다.
- **"모달 해석은 구조물에만 쓴다"가 아니다.** 고유값 문제가 서는 모든 선형계 —
  회로, 화학 반응망, 생태계 모형, 로봇 — 에 같은 분해가 선다. 구조진동은
  그 중 가장 오래되고 큰 응용처일 뿐이다.
- **"커플링이 세면 모드 분석이 안 된다"가 아니다.** 오히려 반대다 — 커플링이
  세든 약하든 모드 좌표에서는 완전히 분리된다(대각화). 커플링의 세기는
  모드 형상(r)에 반영될 뿐이다. 우리 계의 커플링(대각 대비 81%)이 바로
  분리 모델을 죽이고 결합 모드 분석을 강제한 범인이었다(문서 02 §2).
- **줄(φ)이 불안정한 게 아니다.** 줄 진자는 안정 요소다. 불안정한 것은
  가중 무게중심 기울기 β 쪽이고, 정확히는 "φ와 β가 같은 쪽으로 협력하는
  결합 모드"가 불안정한 것이다(문서 01 Ⅱ-1 정정 참조).

## 7. 전람회 예상 질문 & 모범 답변

**Q1. "모드 분석이라고 하셨는데, 기계공학의 모달 해석과 같은 건가요?"**
A. 수학적 핵심은 같습니다. 라그랑주로 세운 운동방정식을 고유값 문제로 풀어
모드로 분해하는 절차가 구조물 모달 해석과 동일합니다. 다른 점은 저희 계가
불안정 평형 주변이라 고유값 하나가 양수로 나온다는 것이고, 그 모드는 진동
대신 지수적으로 발산합니다. 그래서 저희는 고유진동수를 구하는 데서 멈추지 않고
"불안정 모드 성분을 0으로 만드는 것"을 제어 목표로 삼았습니다.

**Q2. "고유값이 양수라는 게 물리적으로 무슨 뜻인가요?"**
A. 복원력의 부호가 반대라는 뜻입니다. 용수철은 밀면 되돌아오지만(음의 고유값,
진동), 역진자는 기울수록 중력이 더 넘어뜨립니다(양의 고유값, 발산). 실측으로
저희 로봇은 λ ≈ 5.7/s, 즉 **약 0.12초마다 기울기가 2배**가 됩니다. 모든 제어는
이 시간 안에서 작동해야 합니다.

**Q3. "모드 형상은 어떻게 측정했나요?"**
A. 줄 위에서 로봇을 여러 자세로 놓아 보는 실험을 64회 했습니다. 자유 거동
데이터에서 시스템 행렬을 동정해 불안정 모드의 고유벡터를 뽑는 방법,
"넘어지느냐 흔들리느냐"의 경계선을 직접 찾는 방법 등 서로 독립인 세 경로로
쟀는데, 셋이 1% 이내로 같은 기울기 r ≈ −1.5를 줬습니다. 모델 예측 −1.64와는
8% 차이입니다.

**Q3-1. "그럼 실험 모달 해석을 하신 건가요?"** (★ §5-2 ④)
A. λ와 r 두 개는 같은 계열이 맞습니다. 자유 응답에서 고유값과 모드 형상을 뽑는
일이고, λ를 재는 방법은 진동학의 **로그 감쇠법의 부호를 뒤집은 것**, r을 재는
방법은 **시간영역 모드 추출(ITD·ERA)의 간략판**입니다. 다만 표준 실험 모달 해석의
뼈대인 주파수응답함수는 쓸 수 없었습니다 — 주파수응답은 정상상태가 있어야 정의되는데
저희 계는 0.12초마다 2배로 발산해서, 흔들기 시작하면 넘어지기 때문입니다.
같은 처지의 분야가 항공기 비행 플러터 시험이고, 거기서도 시간영역 자유응답을 씁니다.
참고로 P2R은 이 계열이 아닙니다 — 동역학이 아니라 센서에서 상태를 만드는
관측식의 상수라, 무게중심을 현수법으로 재는 것과 같은 종류의 측정입니다.

**Q4. "FEM 모달 해석 같은 소프트웨어를 쓰지 않은 이유는요?"**
A. FEM 모달 해석은 구조물의 탄성 진동(수백 Hz대의 부재 떨림)을 구할 때
필요합니다. 저희 문제는 강체 3링크의 저주파 거동(수 rad/s)이라 자유도가 3개뿐이고,
라그랑주로 행렬을 직접 유도해 고유값 문제를 손과 numpy로 푸는 것이 더 투명합니다.
대신 검증은 MuJoCo 전물리 시뮬과 실물 실측으로 했습니다.

**Q5. "감쇠는 어떻게 처리했나요?"**
A. 이론은 무감쇠로 세웠고, 실물 동정에서 나온 속도 의존 항은 좌고유벡터의
일반형 w_v = w_q(λI − C)⁻¹로 반영했습니다. 흥미로운 건 동정된 C의 고유값
하나가 양수라서 순수한 수동 감쇠로는 해석이 안 된다는 점입니다 — 측정하지 않는
자유도(줄 자체의 동역학 등)가 속도항으로 새어 나오는 것으로 보고, 물리적 해석은
열린 문제로 남겨 두었습니다. 값 자체는 조건을 바꿔도 안정적이라 제어에는
실측값을 그대로 씁니다.

**Q6. "이 방법이 다른 데도 쓰이나요?"**
A. 네. 진동 모드 해석은 건물 내진 설계, 항공기 플러터 해석, 회전기계 진단의
표준 도구이고, 불안정 모드 분해는 로켓 자세제어나 휴머노이드 보행(캡처 포인트)
등 넘어질 수 있는 모든 시스템의 제어에 쓰입니다. 저희는 그 두 전통이 같은
수학이라는 걸 줄타기 하나에서 보여 준 셈입니다.
