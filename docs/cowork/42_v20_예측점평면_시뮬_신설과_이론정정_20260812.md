**설계 원칙**: 평면 자체는 상태 4개(β, φ, β̇, φ̇)만으로 성립한다. 파라미터가 필요한 것은
배경선(안정선·등고선·δ_f* 필드·포획 띠)뿐이므로, 실측 여부와 무관하게 그릴 수 있고
추정치 세트에는 화면에 `추정치` 배지가 붙는다. 파생값(r, w, k, μ, ε*, γ, δ_f* 계수)은
전부 런타임 계산 — 하드코딩 없음.

**원호 개념을 두 뷰로 분리** (이번 요청):
- **스윙 평면 뷰**: 회전축이 **점**으로 보이고, 줄의 두 토막은 **겹쳐 보여** 길이 R의 막대
  하나가 된다. 점선 원호는 발이 지나갈 수 있는 자리.
- **축 방향 뷰**: 여기서만 V자(사다리꼴)가 보이고 R = √((L/2)² − (D/2)²) 이 치수선으로 유도된다.
- 두 뷰 모두에 "줄 자체는 언제나 직선 두 토막 — 휘는 것은 발의 자취뿐"을 명시.

색 규약(이번 요청): 흰 배경 / 안정선 **초록** / 무게중심 등고선 **회색** /
궤적은 기존 그림 규약(접기 빨강 · 대기 파랑 · 펴기 금색 · 자유 보라). 글씨 대폭 확대(심사위원 가독성).

## 2. 이론 정정·일반화 3건 ★

### (a) 감쇠 포함 예측점 — 문서 41 '남은 일 ②'의 답

좌고유벡터 관계 `w_q = w_v(λI − D)` 에서 곧바로

$$A \;=\; w_q^{\mathsf T}\Big[\, q + (\lambda_u I - D)^{-1}\dot q \,\Big]$$

가 **정확히** 성립한다. 즉 감쇠가 있어도 예측점 평면의 구조는 그대로이고,
바뀌는 것은 $\dot q/\lambda \rightarrow (\lambda I - D)^{-1}\dot q$ 하나뿐이다
(c_φ = B_θ = 0 이면 기존 식으로 환원). 문서 41의 예상("계수만 바뀔 것")이 맞았다.

이것이 왜 필요했나: 실측 세트의 w는 (0.6043, 1, 0.1040, 0.1686)인데 1/λ_u = 0.1720 ≠ 0.1686 이다.
B_θ 가 β행에 감쇠를 넣기 때문에 단순 q + q̇/λ 로는 A가 예측점만의 함수가 되지 않는다.

### (b) 접기 이동의 줄-관성 일반형

$$\Delta q = k\,\delta_f\,e,\qquad e=(s,-1),\quad s=\frac{M_2[\varphi\beta]}{M_2[\varphi\varphi]},\quad k=\frac{\mu\,M_2[\varphi\varphi]}{\det M_2}$$

I_r = 0 이면 s = h/R, k = μM_tR²/detM₂ 로 문서 41의 식이 정확히 복원된다.
⚠ **문서 41의 `k = μM_tR²/detM₂` 를 로봇 세트에 그대로 쓰면 틀린다** — M₂[φφ] = M_tR² + I_r 이므로
설계추정 세트에서 10.7% 오차.

### (c) ★ `model_v19.fwe_map_constants` 의 γ_cyc 이 e^{λT_rest} 배 과대

`G_cyc = exp(λ(T_f+T_w+T_e+T_rest))` 로 **휴지까지** 넣으면서 `g_cyc` 은 휴지를 뺀 구간만
적분한다. 휴지는 자유 전개이므로 g에도 같은 e^{λT_rest} 가 붙어야 짝이 맞는다.

| 세트 | v19 γ_cyc | 정정값 | 비 = e^{λT_rest} |
|---|---|---|---|
| 로봇 · 설계추정 (T_rest=60 ms) | 39.382 | **26.875** | 1.465 |
| 로봇 · 실측정본 (T_rest=60 ms) | 24.693 | **17.423** | 1.417 |
| 사람 스케일 (T_rest=0) | — | — | 1.000 |

정정 후 δ_f = γ_cyc·A 가 사이클 끝에서 A를 **1e-11°** 로 지운다(deadbeat 검증 통과).
실기는 γ* 를 실측 캘리브레이션하므로 곧바로 사고가 나지는 않지만,
**이론값 28.9 / 실측값 18.6 을 비교해 온 서사(문서 08·31 Ⅹ-1)는 이 정정을 반영해 재검토가 필요하다.**
(정정 이론값을 쓰면 이론↔실측 갭이 지금까지 알려진 것보다 작아진다.)

### (d) 적분 정확도 — 조각상수 δ̈ 의 함정 (구현 주의)

삼각 가감속의 δ̈ 는 ±a 의 조각상수다. 좌단점 샘플 + `t<=0 → 0` 예외로 RK4를 돌리면
접기 킥 g 가 **최대 17% 깎인다**(dt = 0.5 ms). 해법: **스텝 수를 짝수로 양자화하고
각 스텝의 중점에서 δ̈ 를 샘플** → 스텝 안에서 δ̈ 가 상수가 되어 RK4가 4차 정확도를 회복한다.
dt를 2e-5 ~ 1e-3 로 바꿔도 g가 소수점 8자리까지 같음을 확인했다.

## 3. ⚠ 확인이 필요한 불일치 1건

**실측정본 세트의 모델 λ_u = 5.813 /s** 인데 **문서 38은 "모델 ~6.4"** 라고 적고 있다.

- 질량표는 문서 38과 완전히 일치한다(p₁ = 0.17510, p₂ = 0.12280, h = 0.3972 재현 확인).
- 문서 26(8/1)은 같은 실측 줄 관성으로 **5.8 /s(배가 119 ms)** 라고 적었다.
- 실측은 중앙값 6.43 · 평균 6.68.

→ 문서 38의 "모델 6.4" 가 어느 세대의 I_r / I₂_cm 을 쓴 것인지 확인이 필요하다.
이 차이는 **모델이 실측보다 10% 느리게 넘어진다**는 뜻이고, γ 를 그만큼 낮게 잡게 된다.
