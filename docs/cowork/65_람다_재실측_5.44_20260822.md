| 시행 | 길이 | 무엇인가 | 판정 |
|---|---|---|---|

남은 19 회 중 시행 16 만 적합 불량(R² = 0.94)으로 빠져 **18 회**가 결과에 들어갔다.

## 3. ★ 핵심 — 평형은 φ = 0 이 아니라 **φ = +1.40°** 다

문서 53 의 방법(ln\|φ\| 대 t 직선적합)을 **그대로** 쓰면 이번 로그는 답이 두 개로 갈린다:

| 낙하 방향 | n | λ | T₂ |
|---|---|---|---|
| + 낙하 | 10 | **3.94** | 176 ms |
| − 낙하 | 8 | **7.53** | 92 ms |

**1.9 배.** 같은 로봇 같은 줄인데 넘어지는 방향에 따라 발산율이 두 배 차이날 수는 없다.

원인은 **평형점**이다. 문서 53 의 식은 φ 가 0 에서 지수적으로 자란다고 가정하지만,
실제 발산하는 것은 φ 가 아니라 **ψ = φ − φ_eq** 다. 로봇은 φ ≈ +1.4° 에서 균형을 잡고
거기서 어느 쪽으로든 넘어진다. φ_eq 를 빼지 않으면:

- **+ 낙하**는 \|φ\| 가 1.4 에서 출발하므로 배가가 **느려 보인다** (λ 과소)
- **− 낙하**는 φ 가 0 을 **가로질러** 음수로 가므로 \|φ\| 가 0 근처에서 출발한다 →
  배가가 **빨라 보인다** (λ 과대)

φ_eq 를 0 부터 2.6° 까지 훑으면서 두 방향의 λ 가 같아지는 값을 찾으면:

| φ_eq | λ(+) | λ(−) | 차이 |
|---:|---:|---:|---:|
| 0.00 | 3.94 | 7.53 | 3.59 |
| 0.80 | 4.79 | 6.49 | 1.70 |
| **1.40** | **5.33** | **5.54** | **0.21** ← 최소 |
| 2.00 | 5.86 | 4.83 | 1.03 |
| 2.60 | 6.33 | 3.89 | 2.44 |

**φ_eq = 1.40° 에서 두 방향이 만난다.** 그리고 그때의 λ = 5.44 가 문서 53 과 일치한다.
두 개의 독립 조건(방향 일치 / 문서 53 재현)이 같은 값을 가리킨다.

### 문서 53 은 왜 이걸 못 봤나

**4 회를 전부 같은 방향으로 놓았기 때문이다.** 한 방향만 있으면 φ_eq 는 적합 안에
흡수되어 보이지 않는다. 이번에 양쪽으로 놓으면서 드러났다 — **회차를 늘린 것보다
방향을 섞은 것이 더 중요한 개선이었다.**

## 4. φ_eq = 1.4° 를 어떻게 읽을 것인가

**측정 자체는 단단하다** — 발산의 부호가 뒤집히는 φ 값이고, 두 방향 19 회가 그것을 가른다.
정적인 눈금 읽기가 아니라 **동역학이 알려준 균형점**이다.

**그런데 이것이 무엇인지는 이 로그로 안 갈린다.** 둘 중 하나다:

1. **φ 엔코더 영점 오차 1.4°** — 참 균형은 φ=0 인데 계기가 +1.4 로 읽는다
2. **진짜 기울어짐** — 줄이 수평이 아니거나 질량이 한쪽으로 치우쳐 실제로 +1.4° 에서 균형

문서 54 §6 이 "정적 관측은 (가)측정오프셋과 (나)진짜기울어짐을 못 가른다"고 한 그 갈림이다.
**어느 쪽이든 제어에는 같은 영향**이 온다 — 상태를 φ=0 이 아니라 **φ=+1.4° 기준으로**
읽어야 한다. 그러지 않으면 A 가 계속 한쪽으로 밀린 채로 판정한다.

⚠ 다만 **A 오프셋을 φ_eq 하나로 계산하면 안 된다.** A = w·(φ, β, φ̇, β̇) 이고
평형은 (φ, β) 두 축의 조합이다. β_eq 를 같이 알아야 A 오프셋이 나오고,
그것이 바로 **실측 ②의 절편 c₀** 다.

## 6. 아래로 미치는 영향

`w = [−1/r, 1, −1/(r·λ), 1/λ]` — **λ 는 속도항 두 개에만 들어간다.**

| | λ = 5.3 (현 펌웨어) | **λ = 5.44 (실측)** |
|---|---|---|
| w₃ = −1/(r·λ) | 0.11473 | **0.11178** |
| w₄ = 1/λ | 0.18868 | **0.18382** |
| 환율 β̇ 1°/s | 0.189° | 0.184° |

**2.6 % — 실용 무차별.** 문서 60 펌웨어에 `lam 5.44` 한 줄이면 w 가 자동 재계산된다.

- 문서 60 §3-4 **펴기 자기주입** 재계산: `W_βdot·P2R·vrel` = 0.18382 × 0.4328 × 3 = **0.239°**
  (펴기게이트 0.3° 의 **80 %**). 문서 64 에서 0.245° 였던 것이 λ 보정으로 조금 내려왔다.
- **트리거 자연유예**(Â 0.3 → 0.6°): ln2/λ = **127 ms.**

## 부록. 방법

문서 53 을 따르되 한 곳을 고쳤다.

```
1. 로그 끊김(>100 ms)으로 시행을 나눈다              → 21 블록
2. |φ|max < 3° 또는 |φ|min > 3° 이면 놓기가 아니다   → 2 건 자동 배제
3. ★ψ = φ − φ_eq 로 바꾼다  (문서 53 은 이 단계가 없다)
4. ln|ψ| 대 t 직선적합, 밴드 |ψ| 2~9°, 마지막 연속 상승부만
5. φ_eq 는 두 낙하 방향의 λ 가 일치하는 값으로 정한다 → 1.40°
6. 밴드 5 종((2,9)(1.5,6)(2,6)(3,10)(2.5,8))으로 민감도 확인
```

관측 채널은 **φ 하나**다 — 문서 53 §2 의 이유(β 는 진폭 2~3° 에 잡음이 커서 λ 가 흩어진다)
그대로이고, 이번 로그에서도 같다.
