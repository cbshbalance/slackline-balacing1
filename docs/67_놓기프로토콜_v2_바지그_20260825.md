# 67. 놓기 프로토콜 v2 — 2단 바 지그 (2026-08-25) ★실물 확인: 바 없이 손으로 충분 (§추기)

> 문제: 손 놓기는 놓는 순간 속도가 주입된다(신호를 받아도 그대로 놓기 어려움).
> 해법(사용자 제안): 프레임 고정 바 2개(크랭크·머리)로 초기상태를 만들고 **순서대로 제거**.
> 바의 가치는 정밀도가 아니라 **재현성** — 실제 초기상태는 엔코더가 기록한다(E1 재생으로 확인).

## 표준 놓기 (예: φ=−0.1°, β=+0.1°)

1. 크랭크 바(−φ 쪽 스토퍼)와 머리 바로 초기 자세 설정, 제어 ON 상태로 정지 확인.
2. **머리 바 제거** (y축 = 줄 방향으로 미끄러뜨려 — 평면 안 충격 방지). φ는 바에 고정된 채 β만 성장.
3. 문턱 도달 → 첫 접기. **부호 사슬**: β↑ → (CoM 보존) 발이 −φ 쪽으로 바에 눌림 → 접기는 발을
   +φ 로 던짐 → 크랭크가 바에서 스스로 이탈 — 한쪽 스토퍼라 접기를 방해하지 않음. ※정역학 추론 — 실물 1회 확인 요
4. **첫 접기 직후 크랭크 바 제거** (WAIT 국면에 φ̇ 이 −로 돌아오면 재접촉하므로).
   펌웨어에 "첫 접기 부저" 추가 권장 — 삑 → 빼기, 사람 타이밍 일정화.

## 같은 지그로 실측 ②·③

- **실측 ③ (λ)**: 크랭크 바 φ=0 고정 + 머리 바 β 오프셋 → 머리 바만 제거 → 알려진 상태에서
  깨끗한 지수 발산. 배가시간 측정의 재현성이 가장 크게 개선.
- **실측 ② (안정모드선)**: 바 두 개를 목표 (β, φ)에 맞춤 → **거의 동시 제거**(둘 다 자유 필요).
  v21 평면 집기로 예행한 지점들을 실물에서 재현. 로그를 E1에 얹어 즉석 확인.

## 전제·순서

**매달림 영점(문서 66) → 부호 정적 체크(문서 65) → 본 지그.**
바 재질: 단면 둥글게·접촉면 매끈하게. 제거 방향은 항상 y축.

## ★추기 (2026-08-25 당일, 실물 확인) — 바는 불필요, 원리는 유효

실물에서 시험한 결과 **바 없이 손으로도 충분히 안정적으로 놓아진다.** 단, 위 절차 그대로
**손을 바처럼 "대고" 있다가 순서대로 빼는 방식**이어야 한다. 물건(바)은 만들 필요 없음.

- 유효했던 것은 바가 아니라 **원리 두 가지**: ① 한방향 접촉("대기") ② 순서대로 제거(머리 먼저 →
  첫 접기 후 크랭크).
- 물리 한 줄: "대기"는 밀기만 하는 한방향 접촉이라 몸이 스스로 기울며 접촉력이 연속적으로 0이 된
  뒤에 손이 떠난다 — 충격 주입이 없다. 반면 **"잡기"(양방향 구속)** 는 놓는 순간 손가락 마찰·쥔 힘이
  알 수 없는 초기 속도를 심는다. **기존 손 놓기 실패의 원인은 잡고 있다가 놓은 것**으로 추정
  (사용자 실물 관찰과 정합).
- 손 놓기 규칙: 손끝/손등을 스토퍼처럼 **한쪽 면만** 대기, 빼는 방향은 y축(줄 방향), 첫 접기 후
  크랭크 쪽 손 즉시 빼기(재접촉 방지)는 동일하게 적용.
- 실측 ②·③ 겸용(§위)도 손으로 동일하게 수행 가능. 재현성이 더 필요해지면 그때 바를 만들면 된다.
