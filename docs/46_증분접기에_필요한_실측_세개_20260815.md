# 증분접기에 필요한 실측은 세 개뿐 (2026-08-15)

> 이 문서가 정본이다. 문서 44의 실험 설계(부품 관성·복합진자·w 직접적합)는
> **완전사이클 시절의 요구사항**이며, 증분접기에는 필요 없다.
> 문서 45는 잡종 조건에서 나온 결론이라 철회했다(해당 문서 상단 경고 참조).
>
> **연구의 성격**: 고등학생이 정성적 추론으로 AI의 도움을 받아 역학 문제를 풀고
> 로봇을 제어하는 연구다. 대학원 수준의 제어이론·수식은 목표가 아니다.
> 모드분석까지는 필요해서 했고, 그 이후는 **상태공간과 예측점 평면**이라는 도구 위에서

## 0. 한 문단 요약

지금까지의 이론과 시뮬레이션은 전부 **"이렇게 간단한 실측 몇 개로 줄타기를 세울 수 있다"**는
틀을 만든 것이었다. 그 틀이 완성된 지금, 실제 제어에 필요한 측정은 **세 개**다.

| # | 재는 것 | 방법 | 얻는 것 |
|---|---|---|---|
| **①** | **P2R** | 매달고 δ 명령 → 발목각 | **β 를 만드는 법** |
| **②** | **r 과 절편** | 놓았을 때 흔들리나 넘어지나 | **안정모드선** |
| **③** | **λ** | 놓았을 때 배가시간 | **발산율** |

여기에 **노브 하나**(접기량)를 줄 위에서 시행착오로 맞추면 끝난다.

질량·관성·감쇠·기어효율·서보상수는 **하나도 필요 없다.** 전부 위 세 값 안에 이미 녹아 있고,
남는 어긋남은 노브가 흡수한다.

## 1. 왜 세 개면 되는가 — 평면 그림으로

### A = 0 은 "예측점이 안정모드선 위에 있다"는 뜻이다

두 평면에 그린 초록 선이 사실 **같은 선**이었다.

| | 기울기 |
|---|---:|
| 안정모드선 (원위치 평면) `modes.r` | −1.644528 |
| A=0 선 (예측점 평면) `slopeA0` | −1.645104 |

0.04% 차이. 같은 선이다.

**예측점**은 지금 상태를 λ 시간만큼 직선으로 내다본 점이다:

```
예측점 = ( β + β̇/λ ,  φ + φ̇/λ )
A      = w₀·(φ + φ̇/λ) + w₁·(β + β̇/λ)
```

**괄호 안이 예측점이고, A=0 은 그 점이 기울기 r 인 선 위에 있다는 것.**
그래서 제어는 한 문장이다 — **"예측점이 안정모드선에서 일정량 벗어나면 다시 보낸다."**

### w 는 따로 잴 필요가 없다

w 를 좌고유벡터로 직접 적합하려 했던 것(문서 44 실험 2)은 **불필요하다.**

```
w = [ −1/r ,  1 ,  −1/(rλ) ,  1/λ ]
```

**검증 (실측 파라미터 세트):**

| | w₀ | w₁ | w₂ | w₃ |
|---|---:|---:|---:|---:|
| 모델이 준 w | 0.60786 | 1.00000 | 0.10271 | 0.16886 |
| −1/r, 1, −1/(rλ), 1/λ | 0.60808 | 1.00000 | 0.10268 | 0.16886 |

**최대 차이 0.035%.** (r = −1.64453, λ = 5.92192)
속도항은 위치항을 λ 로 나눈 것뿐 — 우연이 아니라 **좌고유벡터의 구조**다.

### 접는 양은 매번 같다

항상 |Â| = 0.6°(문턱)에서 발동하므로 ρ·γ·A 도 항상 같은 값이다.
**부호만 바뀌고 크기는 고정.** γ=10, ρ=0.95 면 매번 **5.7°**.

시뮬 측정으로도 확인된다 — 조건을 어떻게 바꿔도
**트리거 순간 |Â| 중앙값이 0.58~0.59° 로 못 박혀** 있었다.

그래서 "얼마나 접을까" 안에 들어가는 질량·감쇠·기어·서보지연은
**전부 하나의 상수로 뭉쳐지고, 그건 줄 위에서 노브 하나로 맞추면 된다.**

코드에 `fwe_async_fixed_deg` 옵션이 이미 있다 — 켜면 A 비례 대신 고정 증분으로 접는다.

### ★ 큰 접기와 작은 접기에 γ 를 따로 둘 필요는 없다 (8/15 측정)

"큰 접기는 선형영역을 벗어나니 γ 를 따로 재야 하지 않나" 라는 질문을 시뮬로 확인했다.
Δδ 를 트리거와 무관하게 주입하고, **모든 Δδ 에 같은 관측창(250 ms)** 을 써서 G 를 고정한 뒤
`A⁺ = G·A⁻ − g·Δδ` 로 g 를 뽑았다 (δ₀ = 0, 참 A, 제어 봉쇄).

| Δδ | g | γ = G/g | 선형 대비 |
|---:|---:|---:|---:|
| 3° | 0.5506 | 7.06 | 100% |
| 6° | 0.5614 | 6.92 | 102% |
| 12° | 0.5230 | 7.43 | 95% |
| 22° | 0.5066 | 7.67 | 92% |
| 40° | 0.4975 | 7.81 | 90% |
| **55°** | 0.4605 | **8.44** | **84%** |

**비선형은 실재하지만 작다.** 55° 큰 접기는 1도당 효력이 작은 접기의 84%, γ 로는 +20%.

**그런데 작동 고원이 γ = 4~12(3배 범위)이므로 20% 는 그 안에 묻힌다.**
γ 하나면 충분하다. 게다가 증분접기에서 큰 접기는 거의 안 일어난다 —
항상 |A| = 0.6° 에서 발동하니 Δδ ≈ 5.7° 로 표의 맨 윗줄 근처다.
55° 짜리는 큰 외란을 한 번 크게 되돌릴 때뿐이고, 그때 16% 덜 접는 것은
노브를 조금 크게 잡아두면 흡수된다 (현재 γ=10 이 측정값 7~8 보다 이미 크다).

**측정법 검산:** 작은 Δδ 에서 γ = 7.06, 이론 `GAMMA_FOLD` = 7.385 — **4% 일치.**

⚠ **δ₀(유지각) 의존성은 아직 못 쟀다.** δ₀ = 15·30° 를 초기조건으로 던져 넣으면
정적 평형이 아니라서 놓자마자 가속해 A⁻ 가 5~9° 로 선형영역을 벗어난다.
**설정 실패지 물리적 발견이 아니다.** 제대로 하려면 폐루프로 그 유지각에 안착시킨 뒤
주입해야 한다. 문서 44 실험 4 의 핵심 질문이 여기인데 **시뮬에서도 미해결**이다.

## 2. 실측 ① — P2R (매달고 δ 명령 → 발목각)

### 무엇을 재는가

β 는 **무게중심 각도**다. β = P1R·α + P2R·θ 인데, 이 비율을 모르면
엔코더 값에서 β 를 만들 수 없다. **A 를 계산할 수가 없다.**

### 왜 매달면 나오는가

매달린 상태의 평형은 **무게중심이 축 바로 아래**다. 그게 정확히 **β = 0** 이다.

```
β = P1R·α + P2R·θ = 0,   θ = α + δ
→  α = −P2R · δ          (P1R + P2R = 1 이므로)
```

**δ 를 명령하고 발목각이 얼마나 따라오는지 — 그 기울기가 −P2R 이다.**

### 예측값 (실측 파라미터 기준) — **기울기 = −0.4122**

| δ 명령 | 예상 발목각 α |
|---:|---:|
| 10° | −4.12° |
| 20° | −8.24° |
| 30° | −12.37° |
| 40° | −16.49° |

허리를 접으면 하체가 **반대로** 돌아간다. 무게중심이 제자리에 있으려는 것 — '그림자' 직관 그대로다.

### 절차

1. 로봇을 **발목축에서 매단다** (줄에서 내려서, 발목이 자유롭게 도는 상태로).
2. δ 를 10·20·30·40° 로 명령하고 각각 **완전히 멎을 때까지** 기다린다.
3. 각 δ 에서 발목 엔코더를 읽는다.
4. α 대 δ 로 직선을 맞춘다. **기울기 = −P2R.**

**보너스 — 절편이 발목 엔코더 영점 오차다.** δ=0 에서 α 가 0 이 아니면 그만큼 틀어져 있다.

### 주의

- **마찰로 멈춘 자리는 평형이 아니다.** 각 δ 에서 살짝 흔든 뒤 멎는 자리를 본다.
  좌우 양방향에서 접근해 두 값의 중간을 쓰면 마찰 데드밴드가 상쇄된다.
- 저울도 자도 필요 없다. **비율만 나오면 된다.**

## 3. 실측 ② — 안정모드선 (기울기 r + 절편)

### 왜 놓아 보면 알 수 있는가

원위치 평면에서 **속도 0 인 상태**는 가로·세로축 평면 위의 점이다.
거기서 (β, φ) 비율을 바꿔가며 놓으면:

- 초록 선에서 **벗어나 있으면** → 불안정 성분이 있어서 **한쪽으로 발산**
- 초록 선 **위에 있으면** → 불안정 성분이 0 → **발산 없이 흔들리다 잦아든다**

**넘어지느냐 흔들리느냐 — 눈으로 갈린다.** 계측기도 수식도 필요 없다.

### ★ 절편까지 잡으려면 여러 φ 에서 반복한다

**한 φ 에 대해 안정이 되는 β 는 딱 하나다** (4차원에서 안정부분공간이 3차원,
속도 0 평면과 자르면 1차원 직선). 그러니 φ 를 바꿔가며 점을 여러 개 찍고
직선을 맞추면 **기울기와 절편이 함께** 나온다.

**그 절편이 곧 A 의 오프셋이다.** A = −(1/r)·(φ − r·β) 이므로,
선이 φ = r·β + c 로 밀려 있으면 A 에서 상수 하나를 빼면 된다.
그 상수가 엔코더 바이어스·장착 틀어짐·질량 비대칭을 **전부 합친** 값이다.

> **펌웨어의 `A_trim` 이 하려던 것이 정확히 이것이다.**
> 발상은 맞았고 방법이 틀렸다 — 잡고 있는 자세 한 점으로 **추측**하는 대신,
> 놓아 보고 **거동으로 재면** 된다. 정적 관측은 '측정 오프셋'과 '진짜 기울어짐'을
> 절대 못 가르지만, 동적 관측은 가른다 (8절 참조).

### 절차

줄 위, 토크 OFF(또는 δ 고정). φ 를 몇 단계로 두고, 각 φ 에서 β 를 바꿔가며
**속도 0 으로** 놓는다. 여러 번 진동하는 β 를 찾는다. (φ, β) 점들로 직선 적합.

**예측값: r = −1.6445** — φ 와 β 가 부호가 반대이고 φ 쪽이 1.64 배 크다.
(문서 44 실험 2 의 C3 "반대부호 혼합" 조건이 이 근처다.)

### 주의

- **놓기 전 1초 이상 정지.** 손 흔들림이 속도를 주면 속도 0 평면을 벗어나 기준이 달라진다.
- "몇 번 흔들리면 합격"인지 미리 정해둘 것 (예: 3회 이상 진동).

## 4. 실측 ③ — λ (발산율)

초록 선에서 **일부러 벗어나게** 놓고 얼마나 빨리 커지는지 본다.

**예측값: λ = 5.92 /s → 배가시간 117 ms.** 각도가 두 배 되는 시간을 재면 된다.

②와 ③은 **같은 장비, 같은 자세, 같은 로그**로 된다. 놓고 보는 것뿐이다.

"시뮬의 펴기 조건(|Â| < 0.3°)이 지나치게 좁은 것 아닌가" 를 확인했다. **결과는 반대였다.**

먼저 구조적인 사실 하나 — **게이트를 문턱(0.6°) 이상으로 두면 게이트가 없는 것과 같다.**
if/elif 구조라 접기가 발동 안 했다는 건 이미 |Â| ≤ 0.6° 라는 뜻이기 때문이다.
그래서 선택지는 **0.3°(현행) 아니면 게이트 없음** 둘뿐이다.

60 s, 초기조건 4종, 200 Hz 실측:

| | 접기 | φ스윙 rms | \|유지각\|최대 | 말미 평균 |
|---|---:|---:|---:|---:|
| **현행 0.3° · 3°/s** | 181 | **1.13°** | 8.43° | 2.84° |
| 현행 0.3° · 1°/s | 191 | 1.06° | 8.22° | 2.89° |
| 게이트 없음 · 3°/s | 134 | **1.87°** | 8.89° | 2.53° |
| 게이트 없음 · 6°/s | 148 | 1.17° | 9.25° | 3.31° |

전부 4/4 생존. 그러나 **게이트를 없애면 스윙이 커진다** (1.13 → 1.87°).
코드 주석의 경고 그대로다 — **펴기 자체가 불안정 성분을 주입한다.**
위험할 때도 펴면 그 펴기가 다시 위험을 만든다. "안전할 때만 편다"가 맞았다.

그리고 **유지각 누적도 없다.** 최대 8.4°, 말미 평균 2.8° — 기구한계 55° 근처에도 안 간다.
(앞서 "펴는 시간이 1.9% 뿐이라 δ 가 누적된다"고 본 것은 **잡종 조건에서 잰 값**이었다.
200 Hz 에서는 19% 시간 동안 편다.)

### 미해결 — 실물의 좌우 스윙

실물 시험에서 관측된 큰 스윙은 **원인 미상**이다.
문서 45 의 설명(늦은트리거·과접기)은 잡종 조건의 성질이었으므로 철회.

## 8. 기존 펌웨어에 대한 방침

`fwe_async_v19.ino` 는 **급하게 만든 임시 테스트**로 취급한다.
**거기에 시뮬을 맞추지 않는다.** 모든 것은 v19_state 논의에서 다시 세운다.

다만 임시 테스트에서 드러난 문제는 시뮬에 미리 반영해 볼 가치가 있다.

### ★ 자동 트림(`A_trim`)은 폐기해야 한다

```c
A_trim = constrain(A_avg, -8.0f, 8.0f);   // 손 떼는 순간의 A 를 기준점으로
```

**성립하지 않는다.** 잡고 있을 때 A ≠ 0 인 이유는 둘인데 구별이 불가능하다:

- **(가) 측정 오프셋** — 실제로는 똑바른데 엔코더가 틀림 → 빼는 게 맞음
- **(나) 진짜 기울어짐** — 실제로 기울어져 있음 → **빼면 안 됨.** 그 자세를 목표로 삼게 되어
  한 방향으로 δ 가 누적되다 레일에 붙는다

펌웨어의 검사는 `fabs(A_f - A_avg) < 0.7f` — **"흔들리지 않는가"만 본다.
"0 인가"는 안 본다.** 기울어진 채 가만히 있으면 통과한다.
게다가 허용폭이 **±8°** 로 트리거 문턱 0.6° 의 **13배**다.

**대체안은 실측 ②의 절편이다** (3절). 정적 관측 하나로는 (가)와 (나)를 절대 못 가르지만,
놓아 보는 동적 관측은 가른다.

### 그 외 펌웨어-시뮬 차이 (참고용, 맞추지 않음)

| | 펌웨어 | 시뮬 |
|---|---|---|
| A 자체 LPF | `A_f = 0.85·A_f + 0.15·A` (τ≈28 ms) | **없음** |
| 접기 후 잠금 | `FOLD_LOCK_MS = 120` | T_REST 60 |
| 증분 계수 | `K_FOLD = 12` (ρ 없음) | ρ·γ = 9.5 |
| δ 상한 | `DCMD_CAP = 40°` | 55° |
| 재평가 조건 | 잠금 AND \|dcmd−del\| < 4° | 도착 tol 0.5° |
| 펴기 조건 | 잠금 풀리면 **무조건** | \|Â\|<0.3° AND \|hold\|>1° |
| w | (−0.3655, 1, −0.0690, 0.1287) | (0.6079, 1, 0.1027, 0.1689) |

**w 가 1.3~1.7 배 다르다** (부호는 φ 규약 차이로 설명 가능). 펌웨어 값의 출처 미확인.
새 펌웨어에서는 실측 ①②③ 으로 다시 세운다.

**펴기 조건은 시뮬 쪽이 맞다** (7절 검증). 펌웨어의 무조건 펴기는 채택하지 않는다.

## 9. 도구 상태 (v19_state, 8/15 기준)

- 두 평면에 **추정점 표시** — 회색/흰점=참, 하늘색 점선/링=추정. **판정은 링 기준.**
  (트리거는 참값이 아니라 추정값으로 일어난다는 것을 눈으로 보여준다)
- 「★ 실기 파이프라인」 체크박스 — 200 Hz + 25 ms + τ30 ms 를 **함께** 전환. 기본 켜짐.
- 「★ T_REST」 슬라이더 40~200 ms
- 빨간 버튼 `★★ 비동기 FWE — 실측 파라미터`: MEASURED_SET + RHO 0.95 + γ 10 + 200 Hz
- 한 장 전진/뒤로 = **5 ms** (200 Hz 일 때) / 2 ms (500 Hz 일 때)

### 측정 시 주의 (재발 방지)

- **A 는 `control_step` 이전 값을 봐야 한다.** 접기가 시작되면 δ 가 곧바로 β 를 바꿔
  A 가 한 스텝만에 떨어진다. 이후 값으로 보면 전부 헛트리거로 오판된다.
- **'힙 가동률'을 `phase != IDLE` 로 세지 말 것.** REST 대기가 포함되어 모터 활동을 과대평가한다.
- **단발 외란 시험으로 순위를 매기지 말 것.** 킥이 접기 사이클의 어느 위상에 떨어지느냐에
  좌우되어 비단조적인 결과가 나온다. 위상을 흩어 여러 번 돌려야 한다.
- **g 를 잴 때는 모든 Δδ 에 같은 관측창을 쓸 것.** 창이 다르면 G = e^{λT} 가 섞여 g 가 오염된다.
- **접힌 자세를 초기조건으로 던져 넣지 말 것.** 정적 평형이 아니라서 놓자마자 가속해
  A 가 선형영역을 벗어난다. 폐루프로 안착시킨 뒤 측정해야 한다.
  (⚠ 8/17 정정 — 문서 50: 이 경고는 시뮬에서 α 를 안 맞추고 δ 만 던진 **설정 실패**에 대한 것.
  β 를 명세대로 유지하며 넣으면 접힌 자세도 유효하다.)
