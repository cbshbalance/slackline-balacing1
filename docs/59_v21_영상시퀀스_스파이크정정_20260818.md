# 59. v21 — 영상 시퀀스 도입 + '참값 부호반전' 정정 (2026-08-18)

## 1. "참값 β 부호반전" 문의의 답 — 부호 오류 아님 (계측으로 확정)

사용자 관측: 평면에서 참값이 −a→+a 로 튀고 추정값은 안정 진동. "단순 부호 오류인 듯."

**계측 결과** (빨간 프리셋 8 s 헤드리스, 규칙 3):

| 항목 | 결과 |
|---|---|
| 원위치 평면 β 참값 점프성 부호반전 | **0건** |
| 예측점 평면 β_pred 참값 부호반전 | **79건 — 전부 fold·REST 위상에서** (예: 1스텝에 +1.03→−2.58°) |
| fold 스텝의 \|Δβ_pred\| 중앙값 | **참 3.51° vs 추정 0.83°** (idle 스텝은 0.02°/0.03°) |
| v19_state ↔ v21_pres 물리 동일성 | 동일 시나리오 2400스텝 궤적 **MD5 완전 일치** — v21 수정은 물리 무변 |

**결론**: 접기 중 δ̇(최대 420°/s)가 β̇ = P2R·δ̇ 로 들어가고, 예측점 (λI−D̂)⁻¹ 통과 시
속도항이 위치로 환산되며 **참값 예측점이 실제로 반대편으로 튕긴다.** 추정값이 안정해 보이는 것은
실기 파이프라인(25 ms 차분 + EMA)이 스파이크를 걸러서다 — 코드 오류가 아니라 **접기 킥의 물리가
예측점 평면에 그대로 보이는 것**이다.

**조치 (표시만, 판정·물리 불변)**: 체크박스 「접기 스파이크 정리」(기본 ON) — fold·REST 위상의
참값 점·궤적을 예측점 평면에서 숨기고 축 범위 산정에서도 제외. 서버 hist 에 19번 열(위상코드
0 idle/1 fold/2 rest) 추가. 추정(판정) 표시는 그대로.

## 2. 영상 시퀀스 (사용자 요청 사양 그대로)

소재: 49 s 세로 실사 영상 (1080×1920, 청와대 개방 공연). 기존 정합 사진은 이 영상
**t*=6.30 s 프레임의 y 607~1407 전폭 밴드**임을 NCC 템플릿 매칭으로 확인 (6.1~6.5 s 클러스터).
→ 영상을 그 밴드로 잘라 표시하면 **사진 정합 카메라(잔차 ~2 px)를 그대로 재사용**할 수 있다.

**▶ 영상 시퀀스** = 영상 재생 → t* 자동 정지 → 모델 오버랩 진입(0.7 s, 불투명도 1→0.55)
→ **3 s 겹친 채 모델이 증분접기로 진동**(시퀀스 시작 시 ★★실측 프리셋 자동 재생)
→ 실사 페이드아웃(1.5 s) → 기둥 60 cm 축소 모프(5 s, 카메라 동시 트윈) → v19 로봇 화면.
t* 는 슬라이더로 조정 가능.
