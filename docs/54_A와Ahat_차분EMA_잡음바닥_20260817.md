## 1. A — 참 위험도

4차원 상태 `x = (φ, β, φ̇, β̇)`를 **숫자 하나**로 접은 것이다.

$$A \;=\; w\cdot x \;=\; w_q\!\cdot\! q + w_v\!\cdot\!\dot q,
\qquad w = (0.6043,\; 1,\; 0.1040,\; 0.1686)$$

w는 불안정 고유값 λ_u의 **좌고유벡터**다. 왜 하필 이것인가 — 이 방향으로 사영하면
나머지 모드가 전부 죽고 **e^{λt}로 자라는 성분의 계수만** 남기 때문이다.
다른 세 모드는 진동하거나 잦아들 뿐 넘어뜨리지 못한다. **A는 "넘어지는 쪽 성분"의 크기**이고,
단위는 β환산 도(°) — β가 1° 기울어진 것과 같은 위험이라는 뜻이다.

**환율** (문서 50): β 1° → 1.00° / φ 1° → 0.60° / β̇ 1°/s → 0.17° / φ̇ 1°/s → 0.10°.
속도는 대략 **1/λ로 할인**된다 — 각도 1°가 각속도 5.5°/s와 맞먹는다.

동등한 형태 하나 (문서 42·43) — **예측점**:

$$A \;=\; w_q^{\mathsf T}\Big[\, q + (\lambda I - \hat D)^{-1}\dot q \,\Big]$$

즉 A는 "지금 상태를 **속도만큼 앞으로 밀어 본 자리**"를 불안정 방향으로 읽은 값이다.
감쇠가 없으면 `q + q̇/λ`로 환원된다. **A = 0인 자리가 안정선(초록선)**이고,
거기 있으면 흔들리다 잦아든다.

## 3. 그 사이 — 차분과 EMA

φ와 α는 엔코더가 직접 준다. **속도는 아무도 안 준다.** 만들어야 한다.

### 3-1. 차분 (finite difference)

```c
dphi_raw = (phi - phi_hist[old_i]) / (5*dt);   // dt = 0.005 s → 기저 25 ms
```

두 시점의 각도 차를 시간으로 나눈다. 끝. 문제는 **얼마나 떨어진 두 점을 쓰느냐**이고,
여기에 피할 수 없는 맞바꿈이 있다.

| | 짧은 차분 (5 ms) | 긴 차분 (25 ms) |
|---|---|---|
| 잡음 | **σ√2/Δt 로 폭발** | 1/Δt 로 줄어듦 |
| 지연 | Δt/2 = 2.5 ms | Δt/2 = **12.5 ms** |

각도 잡음 σ가 같아도 **Δt로 나누기 때문에** 짧을수록 잡음이 커진다.
반대로 길게 잡으면 그 값은 **구간 중앙의 속도**라서 Δt/2만큼 과거를 말한다.

양자화(0.022°, σ = 0.0064°)만 있을 때의 φ̇ 잡음:

| 기저차분 | σ(φ̇) | 지연 |
|---:|---:|---:|
| 5 ms | 1.80 °/s | 2.5 ms |
| **25 ms (현행)** | **0.36 °/s** | **12.5 ms** |
| 50 ms | 0.18 °/s | 25 ms |

⚠ 이건 **양자화만** 있을 때다. 실제 센서 잡음은 이보다 크고, 그게 5절의 이야기다.

### 3-2. EMA (지수이동평균, exponential moving average)

```c
dphi = 0.85*dphi + 0.15*dphi_raw;              // a = 0.15, 200 Hz
```

새 값을 15%만 섞고 과거를 85% 유지한다. **이름은 거창하지만 1차 저역통과 필터**이고,
과거 값을 지수적으로 잊는다 — 그래서 '지수'이동평균이다.

| | 값 |
|---|---|
| **시정수** τ = dt(1−a)/a | 0.005 × 0.85/0.15 = **28.3 ms** |
| **잡음 감소** √(a/(2−a)) (백색 입력) | 0.285배 (−71%) |
| **대가** | 출력이 τ만큼 늦다 |

**왜 이동평균(N점 평균)이 아니라 EMA인가** — 메모리가 **하나**면 된다.
N점 이동평균은 N개를 들고 있어야 하고 링버퍼가 필요하다. 임베디드에서 한 줄로
같은 효과를 내는 것이 EMA다. 대신 차단 특성이 완만해서(−20 dB/dec) 고주파가 조금 샌다.

### 3-3. 셋은 한 묶음이다 (★문서 45의 교훈)

| 항목 | 값 |
|---|---|
| 제어주기 | **200 Hz** (dt = 5 ms) |
| 기저차분 | **25 ms** = 5샘플 |
| EMA | **a = 0.15**, τ ≈ 28 ms |

**따로 바꾸면 안 된다.** 500 Hz에 25 ms 차분만 얹으면 13스텝 차분이라는 **잡종**이 되고,

## 4. 대가의 계산 — 발산에 이 파이프라인을 걸면

넘어지는 중에는 모든 신호가 e^{λt}로 자란다. 지수함수에 대한 두 단계의 이득은 닫힌형으로 나온다.

$$G_{\text{차분}}=\frac{1-e^{-\lambda \Delta}}{\lambda\Delta},
\qquad G_{\text{EMA}}=\frac{a}{1-(1-a)e^{-\lambda\,dt}}$$

| λ | 차분 이득 | EMA 이득 | 합 | 과소 | 등가지연 |
|---:|---:|---:|---:|---:|---:|
| 5.30 (오늘 실측) | 0.937 | 0.871 | **0.816** | 18.4% | 38.4 ms |
| 5.813 (모델 정본) | 0.931 | 0.860 | **0.801** | 19.9% | 38.2 ms |
| 5.92 (문서 46 예측) | 0.930 | 0.858 | **0.798** | 20.2% | 38.2 ms |

**오늘 로그로 확인** — 발산 구간(|φ| 2~8°)에서 파이프라인 φ̇를 참값 λφ와 나눈 값:

| 회차 | 1회 | 2회 | 3회 | 4회 |
|---|---:|---:|---:|---:|
| 파이프라인 / 참값 | 0.786 | 0.817 | 0.827 | 0.806 |

**17~21% 과소 — 계산과 일치한다.** (로그가 100 Hz라 30 ms 차분으로 근사)

### 그래서 Â는 A보다 작다

불안정 모드 위에서는 q̇ = λq이므로 A의 두 항 비중이 계산된다
(실측 방향 β/φ ≈ −0.30 기준):

| | 위치항 | 속도항 |
|---|---:|---:|
| A에서 차지하는 몫 | 49~52% | **48~51%** |

**속도가 A의 절반이다.** 그 절반이 18~20% 깎이므로

$$\hat A / A \;\approx\; 0.90$$

**문턱 0.6°는 실제로는 참 A ≈ 0.66°에서 걸린다.** 약 10% 늦게 접는다.
문서 45가 200 Hz에서 관측한 값(판정시 |A참| 0.69° vs |Â| 0.59°, 비 0.855)과
**방향이 같고 크기도 같은 자리**다.

> 늦게 접는 것 자체는 치명적이지 않다 — 회복 천장이 2.8~4.0°이므로 0.66°는 한참 아래다.
> 다만 **γ(접기량 노브)를 실측으로 맞출 때 이 10%가 노브 안에 흡수되어 있다**는 점은
> 기억해 둘 것. 파이프라인을 바꾸면 γ도 다시 잡아야 한다.
