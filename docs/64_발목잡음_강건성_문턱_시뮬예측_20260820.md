# 64. 발목잡음 강건성 문턱 — 시뮬 예측 (2026-08-20)

> 사용자 질문: "실측 발목잡음을 주입해도 균형에 큰 차이가 없어 보이는데 잘 반영된 건가?"
> 답: 반영은 정상이고, **증분접기 모드에서는 차이가 커야 정상**이다(수 초 내 낙하).
> 차이가 없어 보였다면 그때 칼만(LQR·기본 부팅) 경로였을 것 — **칼만 측정 z=[θ_acc, θ̇_gyro, δ, δ̇]에는
> 발목 엔코더가 없어서** 발목잡음이 제어에 전혀 안 들어간다. 발목 엔코더는 enc 추정기(증분접기)만 쓴다.

## 2. 결론

1. **현재 잡음 바닥(0.223°)에서는 증분접기 장기 균형이 어렵다** — 문서 54의 "잡음이 문턱 자리를
   차지한다" 경고의 정량판. 실기에서 원인불명 낙하가 보이면 1순위 용의자.
2. **안전 문턱은 σ ≤ 0.10°, 베어링 교체 목표 0.05°는 여유 2배** — 문서 56의 교체 권고를 시뮬이 뒷받침.
   교체 후 재측정값을 UI 입력칸에 넣어 재검하면 된다.
3. 부수 관찰: 작은 잡음(0.05~0.10°)에서 접기 횟수가 ~3배로 늘어도 생존은 유지 — "매 사이클 다시
   재서 다시 잡는" 증분접기의 강건성이 그대로 보인다. 낙하 메커니즘은 접기 실패가 아니라
   **유지각(hold)의 잡음 랜덤워크 + 저속복귀 마비 → 관절한계 포화**다.
