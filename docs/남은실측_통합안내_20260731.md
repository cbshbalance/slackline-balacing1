## 2. M2 — 허리 유효관성 I_δ (실험 ③, 30분) ★핵심

### 2.1 무엇을, 왜 재는가

**I_δ = 허리 관절이 "돌리기 싫어하는 정도"**. 두 부분으로 이루어집니다.

1. **상체 링크의 힙축 관성** — 질량표에서 계산 가능: I₂ + m₂ℓ₂² = **0.0447 kg·m²**
2. **회전자(armature) 반영 관성** — 모터 로터 관성이 212.6:1 기어비의 **제곱(≈45,200배)**으로
   증폭되어 보이는 성분. 로터 관성은 비공개 스펙이라 **오직 실측으로만** 알 수 있습니다.

FWE 제어는 **60 ms 안에 허리를 접고** 90 ms에 폅니다. 가능 여부는
`최대 각가속도 = 가용 토크 ÷ I_δ` 로 결정됩니다.

| 항목 | 예상 |
|---|---|
| 상체 링크만 | 0.0447 kg·m² |
| + armature | ? (이걸 재는 것) |
| CUR_SAFE 600u(1.61 A, τ=2.10 N·m) 기준 최대 각가속도 | ~2,700 °/s² |
| Profile Acceleration 환산 | acc_unit ≈ 126 |

**현재 스케치 기본값 acc_unit = 20 (429 °/s²)은 예상 가용량의 1/6**입니다. 이 실험의 실질적
산출물은 "안전하게 올릴 수 있는 가속도 상한"입니다.

### 2.2 원리 — 왜 이 방법이 맞는가

관절을 자유롭게 두고 **알려진 토크**(전류제어: τ = Kt·I)를 걸면

> **I_δ · δ̈ = τ_명령 − m₂ g ℓ₂ sin δ − τ_마찰**

- δ̈: 100 Hz 각도 로그를 2차식 적합
- 중력항: 상체가 힙축 아래로 매달린 자세면 계산으로 정확히 제거 (m₂, ℓ₂ 기지)
- 마찰: **토크를 여러 단계로 바꿔 α vs τ 직선적합** — 기울기가 1/I_δ, **x절편이 마찰토크**로
  분리됩니다. 이게 이 방법의 핵심입니다.

⚠ **하면 안 되는 방법**: "상체를 힙에 매달아 진자로 흔들기". XM430은 212.6:1 감속기라
역구동 마찰이 중력 토크를 먹어 자유진동이 안 생기거나 마찰 지배로 왜곡됩니다.
**반드시 모터로 능동 구동**해야 합니다.

### 2.3 준비

필요한 것: 로봇(하체+상체+모터 조립), 하체를 물릴 **지그**(만력기·클램프·목재 프레임),
**12 V 배터리**(USB만으론 모터가 안 움직임), OpenCR + RS-485 4핀 + PC,
`motor_inertia_test.ino`, `serial_logger.py`.

**자세 세팅 ★가장 중요**

1. 하체를 지그에 **단단히 고정** — 흔들리면 그 반동이 전부 오차
2. **발(발목)이 바닥·줄에서 완전히 떠 있을 것** — 닿으면 반력이 섞여 무효
3. **상체가 힙축 아래로 매달리도록 로봇을 거꾸로**(발목 위, 머리 아래) 물립니다.
   δ=0에서 안정하므로 안전하고, 중력항도 정확히 계산됩니다
4. 힙 회전축이 **수평**인지 확인 (스윙 평면이 연직면)

> 대안: 힙축을 **연직**으로 세울 지그가 있으면 중력 토크가 0이라 더 좋습니다(분석 시
> `--nograv`). 단 상체 640 g을 관절이 옆으로 받으니 베어링 부담 확인.

설치: `v19_bringup/firmware/motor_inertia_test/motor_inertia_test.ino` 업로드
(엔코더 미장착이면 스케치 상단 `USE_ENCODERS = false`) → 시리얼 115200 → `모터 OK @ 1000000` 확인.

### 2.4 절차

1. **영점**: 상체가 완전히 멈춘 뒤 `z` → `# zero set` 확인, `p`로 δ≈0 확인
2. **(선택) 마찰 감 잡기**: `c 30` → `c 50` → `c 70` … 움직이기 시작하는 전류를 확인(움직이면 `r`).
   그 값이 대략 정지마찰+중력. 본 시험 토크 단계를 그 **2~5배**로
3. **본 시험 — 자동 펄스**: `python calib/serial_logger.py <포트> itest.csv` 기록 시작
   (시리얼 모니터는 닫을 것). **매번 상체가 멈춘 뒤** 다음 명령:

```
i 60      (τ ≈ 0.21 N·m)  → 멈추면 손으로 매달린 자세로 되돌리고, 필요하면 z
i 90      (τ ≈ 0.32)
i 120     (τ ≈ 0.42)
i 160     (τ ≈ 0.56)
i 200     (τ ≈ 0.70)
```

   각 펄스는 |δ|>25° 또는 1.2 s에서 자동 차단. 시간 되면 `i -60`…`i -200`으로 음방향도
   (마찰·중력 부호 교차 확인). 끝나면 `r` → `x`, 로거 종료
4. **(선택) 자유 감쇠**: `k` 후 손으로 20°쯤 밀었다 놓기 — 전류 0 감쇠 로그 (`BODY.B_THETA` 근거)

### 2.5 분석

```bash
python v19_bringup/calib/inertia_analysis.py itest.csv
# 힙축 연직 지그였다면 --nograv, 적합 구간 조정은 --win 0.15
```

출력에서 **I_δ, 마찰토크, 권장 Profile Acceleration**이 나옵니다
(합성 로그 검증에서 참값 3% 이내 복원 확인됨).

### 2.6 게이트

| 확인 | 기준 | 벗어나면 |
|---|---|---|
| 직선적합 R² | ≥ 0.98 | 지그 흔들림/미정지 상태 시작 → 재실험 |
| I_δ | 0.045 ~ 0.070 kg·m² | 0.045 미만은 물리적으로 불가능(질량표 재검), 0.10 초과면 armature 과대 |
| 마찰토크 | 가용 토크의 ~10% 이하 | 초과 시 기어·베어링 예압 점검 |
| 권장 가속도 vs 현 설정(20u) | ±20% 밖 | `a <새값>`으로 스케치 기본값 갱신 (거의 확실히 올려야 함) |
| 방향 대칭 | ±시험 I 차이 5% 이내 | 크면 지그 기울어짐 → 힙축 수평 재확인 |

### 2.7 안전 (꼭)

- 상체 640 g, 가속도를 지금의 6배까지 올림 → **지그 확실히 고정**, 스윙 반경에 손·얼굴 금지
- **`x`(비상정지)에 손을 올려두고** 진행. 스케치가 |δ|>45° 자동 차단 + 전류 ±600 unit 제한
  (이 한계를 임의로 올리지 말 것)
- `x` 후 재시작은 **매달린 정지 자세에서 `z`부터** — 홈이 어긋난 채 큰 토크를 주면 급격히 움직임
- **배터리 충전 상태에서** — 전압 낮으면 토크가 명령보다 작아 I_δ 과대평가

### 2.8 잘 안 될 때

| 증상 | 조치 |
|---|---|
| `i` 쳐도 안 움직임 | 토크 < 정지마찰+중력. 2.4-2로 문턱 찾아 그 위에서 시작 |
| α 들쭉날쭉, R² 낮음 | 시작 시 상체가 흔들리고 있었음. 완전히 멈춘 뒤 다음 펄스 |
| 1.2 s 안에 25° 못 감 | 토크 단계 올리기 |
| 순식간에 45° 한계 | 단계 낮추고 `--win 0.10~0.15` |
| I_δ < 0.0447 | 물리적으로 불가능 → 자세·중력 보정·Kt 확인 |
| ±방향 결과 상이 | 지그 기울어짐 → 힙축 수평 재확인 |

### 2.9 결과 반영

I_δ → `model_v19.py` 허리 관성 항 / 시뮬 v20. 마찰 → `BODY.B_THETA`(점성)·시뮬 쿨롱 모델.
권장 Profile Acceleration → `motor_profile_test`·`motor_triangle_test` 기본 `a`, FWE 펌웨어.

> 참고: 도구를 못 쓰는 상황이면 어제 커밋한 `motor_triangle_test`로도 대체 가능합니다
> (삼각 프로파일 T = 2√(d/a) 예측 대비 실제 시간이 갈라지는 a를 찾아 I_δ = τ_max/a_max,
> 예상 분기점 acc_unit 120~130). 정식 방법(위)이 마찰 분리가 되므로 우선입니다.

## 3. M3 — 검증진자 A-2 : 하체 조각 (10분)

### 왜 — 해석 하나를 확정한다

어제 하체에 대해 받은 두 값의 조건이 서로 달랐습니다:

- **CoM 84 mm**(아래 사각창 아래 변) = 모터 **없는** 구조물의 값 (190 g 조각의 CoM이 84 mm면
  구조물 CoM이 발축보다 56 mm 아래여야 해서 불가능)
- **2줄 매달기 T=7.620 s** = 모터 **붙은** 190 g 조각의 값**으로 추정** ← 이걸 확인하는 실험

추정 근거: 모터 뺀 109.4 g으로 해석하면 회전반경 114 mm(질량이 양 끝단에만 몰린 기하학적
한계값)라 비현실적. 모터 포함이면 구조물 I_cm = 8.85×10⁻⁴(회전반경 90 mm)이고 덩어리 모형
(캐리어 65 g@20 + 스파인 25 g@130 + H101 20 g@240 → 8.06×10⁻⁴)과 9% 이내 일치.

### 판별력

| 가설 | 예상 주기 | 10왕복 총시간 |
|---|---|---|
| **H1: 2줄 매달기에 모터 포함** (채택) | **0.988 s** | **9.88 s** |
| H2: 모터 없이 측정 | 1.023 s | 10.23 s |

차이 0.35 s — 스톱워치로 충분히 구분됩니다.

### 절차

1. 하체를 **어제 잰 그대로**(모터 붙은 190 g 상태)로 준비
2. 발목 캐리어의 **608 베어링 두 개에 8 mm 봉(또는 M8 볼트)을 관통**, 봉 양 끝을 책상 사이나
   블록 두 개에 얹기 → 로봇 자기 베어링이 그대로 저마찰 피벗 (개조 0)
3. 하체가 봉 아래로 매달린 상태에서 **5~10°만** 기울였다 놓기 (크면 주기가 진폭 의존으로 왜곡)
4. **10왕복 총시간 ÷ 10**, 3세트 평균
5. 줄(크랭크)은 떼어 두거나, 붙어 있으면 하단 소켓을 고정해 로봇만 흔들리게

### 게이트

0.988 ± 0.03 s → H1 확정, `I1_cm = 8.85×10⁻⁴` 유지.
1.023 근처 → 알려주세요, I₁을 3.02×10⁻³ 계열로 재계산.
둘 다 아니면(±5% 밖) 2줄 매달기 자체 재검.

## 4. M4 — 검증진자 B : 조립 로봇 (10분)

### 무엇을 검증하나 (한계 포함)

조립 로봇을 발축에 매달면 **총질량·총 CoM·총관성의 합**이 검산됩니다 — 10배 자릿수 실수나
링크 통째 누락을 잡는 용도. 정밀도는 기대하지 말 것(ℓ₂ ±10 mm → 주기 ∓0.8%,
m₂ ±20 g → ∓0.2%, I₂ ±10% → ±0.7%). 또 허리를 일자로 고정하면 모터가 어느 링크에 있든
결과가 같아 **링크 분배는 검증 못 합니다**(그건 CAD/조립 사실).

### 절차

1. 허리 δ=0(일자)로 **확실히 고정** — 모터 토크 ON보다 **막대 대고 케이블타이·테이프**가 확실
   (기어 백래시 배제)
2. M3와 같은 8 mm 봉을 발목 608에 관통 → 로봇 전체를 봉 아래로 거꾸로 매달기
3. 5~10°로 놓고 10왕복 총시간, 3세트

### 예상값

**T = 1.437 s** (전체 CoM 발축 위 397 mm, 총 750 g). 10왕복 = **14.37 s**.
게이트 ±3% (1.394 ~ 1.480 s).

## 5. M7 — 서보 상수 Kt · 무부하속도 (20분)

시뮬이 "설 수 있다"고 해도 실제 토크가 부족하면 소용없습니다. 지금 둘 다 **공칭값**입니다.

**Kt (토크상수, 공칭 1.304 N·m/A)** — `opencr_test/torque_cal` 사용.
모터 혼에 팔길이 r 막대를 물리고 끝에 질량 m 추를 매달아, 그 토크(mgr)를 버티는 전류 i를
읽어 **Kt = mgr / i**. 공칭 대비 ±15% 안이면 공칭 유지.

**W_NOLOAD (무부하 속도, 공칭 462 °/s)** — 부하 없이 최대 속도 회전 → 로그에서 실측.
FWE 시간표(60/20/90/60 ms)가 이 값 전제로 스윕된 것이라, 실제가 크게 낮으면 시간표 재산정 필요.

기록: `SERVO.KT`(MEASURED=True로), `SERVO.W_NOLOAD_DPS`.

## 6. 자잘한 것 — M5 · M8 · M9 · (선택) M6

**M5 — ℓ₁ 직접 확인 (1분)**: 하체 CoM 84 mm는 "아래 사각창 아래 변"이라는 CAD 형상 참조를

**M6 — 검증 C: 상체 2줄 매달기 재실행 (선택, 10분)**: I₂ 독립 재검의 가장 예리한 방법.

쉬운 값). 조건: 상체를 어제와 같은 구성(모터 없이, 수평으로 눕혀), 줄 길이 315 mm 유지.
**예상 주기 5.47 s**(d 두 배 → 주기 절반), 게이트 ±3%. 벗어나면 d 또는 L 측정 재검.

## 9. 함정 모음

1. 값은 `params_v19.py` 한 곳에만. `gains_v19.h` 직접 수정 금지
2. **CoM 기준점**: ℓ₁은 발축, ℓ₂는 힙축 — 헷갈리면 게인이 통째로 틀어짐
3. 진자·자유진동은 **작은 각도(5~10°)에서만** 공식 성립
4. 주기는 **10왕복 총시간 ÷ 10** — 1주기 직접 측정은 반응시간 오차가 지배
5. **모터를 베어링처럼 쓰지 말 것** — 212.6:1 역구동 마찰이 진동을 죽임
6. M2는 **발이 완전히 뜬 상태**에서 — 바닥·줄에 닿으면 무효
7. 측정 대상은 **현행 출력물**(bracket v5.2 / carrier v5.3)
8. 실측 전 게인(GAINS_MEASURED=0 경고) 상태로 로봇을 줄에 올리지 말 것
9. **"어떤 구성으로 쟀는지"를 값과 함께 기록**할 것
