# 실험② 재실험 절차서 — 새 PC 세팅부터 데이터 전달까지 (2026-08-05)

> 대상: 어름이 실험②(기울여 놓기 → 넘어짐 속도 λ_u·위험가중치 w) 담당 학생.
> 배경: 8/5 1차 실험 데이터는 φ·발목 엔코더가 죽은 채 기록되어 **전량 사용 불가** 판정
> (r3는 φ·발목이 전 구간 0, r1은 발목 고정). 절차와 마커 운용은 완벽했으므로,
> **배선 수리 → 점검 통과 → 같은 절차로 재실험**만 하면 된다.
>
> ⚠ 파일 구분 (헷갈리기 쉬움):
> - `tilt_release_test.ino` → **아두이노(OpenCR)에 업로드하는 펌웨어**
> - `wiring_check.py`, `exp_logger.py` → **PC의 cmd에서 실행하는 파이썬** (아두이노 업로드 금지!)

## 1. 펌웨어 업로드

1. Arduino IDE로 리포의 `v19_bringup/firmware/tilt_release_test/tilt_release_test.ino` 열기
2. 툴 > 보드: **OpenCR** / 툴 > 포트: COM 번호 확인 (PC마다 다름 — 이하 COM6으로 표기, 본인 번호로 바꿔 쓸 것)
3. 업로드 → 시리얼 모니터(115200) 열어 부팅 메시지 확인:
   - `phi raw=…  ank raw=…` 에 **0이 있으면 그 엔코더 배선이 죽은 것** → 커넥터부터 손볼 것
   - `DXL 1Mbps OK` 가 아니라 "응답없음"이면 배터리/RS-485 확인
4. ★확인 후 **시리얼 모니터를 반드시 닫는다** (열려 있으면 파이썬이 포트를 못 잡아 데이터가 저장 안 됨 — 8/5 r2가 0바이트였던 원인 부류)

## 2. 배선 점검 ★필수 (여기를 통과 못 하면 실험 무효)

φ·발목 커넥터 **재삽입 + 케이블타이 고정** 후:

```bat
cd "C:\Users\<유저이름>\Desktop\ereumi"
python wiring_check.py COM6
```

- 자동 점검(정지 5초) → 안내에 따라 로봇을 살짝 흔들기(8초)
- **각도 3개(φ, 발목, δ) 전부 [OK]** 가 떠야 본 실험 진행. "값 고정 / 전부 0 / 점프" 뜨면 배선 재점검 후 재실행
- 시간이 되면 부호 점검까지: `python wiring_check.py COM6 --sign`
  (줄 밀기 / 몸 기울이기 / 허리 접기 3동작 — 출력된 Δphi·Δank·Δdelta 부호를 기록해 전달.
  분석 `--alpha` 확정에 필요)

## 3. 본 실험 — 기울여 놓기 (약 20분)

```bat
python exp_logger.py COM6 0806_exp2_tilt_r1.csv
```

(날짜는 실험일로, 재실험 시 `r1`→`r2, r3…`만 바꿔 새 파일)

실행된 창에 순서대로 입력:

| 순서 | 입력 | 의미 |
|---|---|---|
| 1 | `k` | 허리 잠금 (상·하체 강체화) ★측정 전 필수 |
| 2 | `z` | 영점 — 로봇을 줄 위 **직립 정지** 상태로 잡고 누를 것 |
| 3 | `s` | 200Hz 스트리밍 시작 |
| 4 | `m` → 손 떼기 → (0.3~0.5초 뒤) 잡고 → `m` | 마커 쌍 = 시도 1회. **좌우 번갈아 10회 이상** |
| 5 | `s` | 스트리밍 정지 |
| 6 | `quit` | 종료 — "데이터/이벤트 N행 저장"이 뜨면 성공 |

요령·주의:

- 놓는 순간 손이 **밀고 있지 않도록** (시도 간 λ_u 산포 ±10% 게이트의 주범)
- 기울임은 0.5° 이내에서 시작 — 크게 기울이고 시작하면 소각 구간을 벗어남
- 넘어질 때 잡을 사람 1명 상시 배치 (또는 느슨한 안전끈)
- 중간에 이상하면 그냥 `quit` 하고 새 파일(r 숫자 올려서)로 다시 — 원시 CSV는 지우지 않는다

## 4. 데이터 전달

- CSV 전부(실패 회차 포함)를 zip으로 지도교사 대화에 업로드, 또는 리포 `exp_data/<YYMMDD><요일>/` 폴더에 넣어 git push
- 이후 분석: `python v19_bringup/calib/exp_analysis_v19.py exp2 <csv> --params v19_bringup --alpha <확정값>`
  → λ_u(게이트: 모델 ~6.4/s ±15%, 시도 간 ±10%)·w 4성분·실험④용 인자 줄 출력
- 결과 기입처: `docs/어름이_조립후_실험절차서_완전판_v19.docx` 기록란 + `v19_bringup/params_v19.py`

## 문제 해결 빠른 표

| 증상 | 원인/조치 |
|---|---|
| Arduino IDE에서 `.py` 컴파일 에러 (`invalid preprocessing directive #`) | 파이썬 파일을 스케치에 붙여넣은 것 — .py는 cmd에서 실행 |
| `포트 열기 실패` | IDE 시리얼 모니터 닫기 / COM 번호 확인 / USB·전원 |
| CSV가 0바이트 | 포트를 다른 프로그램이 점유한 채 실행됨 — 모니터 닫고 재실행 |
| 부팅 `raw=0` 경고 | 그 엔코더 배선 사망 — 커넥터 재삽입·고정 후 재부팅 |
| 각도가 한 값에 고정 | 배선 헐거움(8/5 발목 증상) — wiring_check 재실행으로 확인 |
