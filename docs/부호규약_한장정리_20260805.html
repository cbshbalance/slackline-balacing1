어름이 부호 규약 — 한 장 정리

출처: CLAUDE.md §2·§9(권위), 실험절차서 v19, exp_analysis_v19.py · 2026-08-05 정합점검 반영 · 대원칙: 모든 각도는 연직(수직선) 기준, "+방향(오른쪽)으로 기운 것"이 +
그림 1. 좌표 3개(φ, α, θ)는 전부 연직 기준 절대각이고, +방향으로 기울면 +. δ만 상대각(θ−α).
그림 2. ⚠δ 해석 함정 — δ>0은 "상체가 오른쪽으로 평행이동"이 아니라, 머리·발이 +쪽, 엉덩이가 −쪽으로 빠지며 힙을 꼭짓점으로 V자 접힘 (사람이 오른쪽 보고 허리 숙인 자세). 8/5 확인: +방향 접기 → Δδ=+58.1° → MOTOR_DIR=+1 확정. 위치모드 킥의 부호 = 기울어진 쪽.

정합점검 3동작 — 무엇이 어떤 부호로 나와야 하나

동작 (모두 +방향으로)기대8/5 실측·상태
(a) 로봇 세운 채 줄만 밀기Δφ > 0+7.56° → φ+ 방향 확정
(b) 줄 가운데 두고 몸 전체 기울이기α > 0, 그리고 분석 β > 0
(Δank 부호로 --alpha 확정)		+5.60° (2차, 일자 잠금·직립 영점) → 부호 s=+1, ank = α−φ 형 → --alpha = ank+phi 확정
※1차 −178°는 영점 뒤집힘으로 폐기. (b)는 φ≈0이라 조합 구분이 안 되므로 조합은 기하(발목각=α−φ)+부호로 결정
(c) 토크 끄고 상체를 +쪽으로 접기Δδ > 0 (앞접기)+58.10° (1차) → MOTOR_DIR=+1 확정 (torque_cal 확정값과 일치)
※2차 −81.04°는 동작 실수로 폐기
판정의 최종 목표는 단 하나: "몸을 φ+ 쪽으로 기울였을 때 분석 스크립트의 β가 +로 나오게" --alpha를 고르는 것 (절차서 v19 §0 정합점검). λ_u 크기는 부호에 둔감하지만 w·위험도 A는 부호가 틀리면 무너진다.

수식 규약 (분석·시뮬과 일치해야 하는 것들)

δ = θ − α β = (p₁α + p₂θ)/(p₁+p₂) x_CoM = R·φ + h·β τ 입력: E = [0, −1, +1] (α에 −τ, θ에 +τ)
항목규칙 / 주의
발목 엔코더 → α발목 엔코더는 상대각: ank = s·(α−φ). 8/5 실측 s=+1 → α = ank + φ, 분석 옵션 --alpha ank+phi 확정 (기본값 ank-phi 아님에 주의!)
펌웨어 δδ = MOTOR_DIR × (서보각 − 잠금각) × 360/4096, MOTOR_DIR=+1 확정(8/5). +전류 = 앞접기(torque_cal 규약)
영점(z)로봇 직립·정지 상태에서만 누른다. 뒤집힌 자세에서 z → 모든 발목 읽기가 ±180° 근처로 이동(8/5 1차 (b)의 원인)
