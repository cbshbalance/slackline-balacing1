# v22 측정 앱 — 조작 가이드 (무엇을 누르고, 로봇을 어떻게 잡았다 놓고, 앱이 무엇을 계산해 무엇을 보여주나)

> 펌웨어 `v22_raw` 기준. hangcal_fold 를 쓰면 「명령」탭 프로파일만 바꾸면 되고 버튼 이름은 같은 글자다.
> 화면 위치: 왼쪽 3D · 가운데 평면 두 장 · 오른쪽 탭(데이터/명령/기록·파일/파이프라인) + 콘솔 · 아래 차트 + 분석 패널.

## 0. 화면을 읽는 법 (한 번만)

| 곳 | 보이는 것 | 뜻 |
|---|---|---|
| 3D 왼쪽 위 판독 | t, [phase], φ, ank, α, θ, δ, β, Â(펌), \|Â\|/trig, φ̇, β̇ | 현재 커서(라이브면 최신 행)의 값. Â 는 **앱이 다시 계산한 값**, 괄호가 펌웨어 값 |
| 원위치 평면 (β, φ) | 초록 점선 = 모델 안정모드선 φ=r·β · 주황 점선 = 실측선 φ=r·β+c₀(파이프라인 r, c0) · 회색 사선 = 무게중심 등고선 · **금색 궤적/마름모 = 앱 인과값**(로봇이 실시간에 볼 수 있는 값) · 흰 점선/원 = 비인과 평활(사후 준참값) | 놓은 자리가 선 위인지, 어느 쪽으로 넘어가는지 |
| 예측점 평면 (β_pred, φ_pred) | q + P·q̇. 초록 = A=0 선, 노랑 띠 = 트리거 ±0.6° | 점이 띠 안이면 "무개입", 밖이면 발산 중. 판정의 평면 |
| 데이터 탭 원본값 | 펌웨어가 보낸 열 그대로 (phi, ank, del_now, phi_raw, ank_raw …) | 2 s 동안 안 변하는 엔코더 열은 **빨강 ⚠고착** |
| 데이터 탭 앱 파생값 | u_phi(언랩), α=ank−φ, θ, β, φ̇, β̇, Â, ψ, 예측점, 평활 + `펌 … Δ…` | Δ = 앱 − 펌웨어. 정지 상태에서 α·β·Â 의 Δ≈0 이어야 같은 식 |
| 차트 3레인 | 각도 / 속도·Â / phase·hold·err. 세로 점선 = 이벤트·마크(ZERO, MOVE, MARK, RELEASE …). 색 띠 = phase 나 분석 결과 | 아래 체크박스로 채널 켜고 끔 |
| 분석 패널 | 도구 → 구간 → 파라미터 → 실행 → **절차(번호) → 숫자 → 표 → 보조 곡선**, 맨 아래 「결과 기록」 | 결과의 각 줄이 "무엇을 어떻게 했다"다. 차트·평면에 쓴 점·선이 겹쳐진다 |

조작 요약: 차트 휠=줌 · 드래그=이동 · **Shift+드래그=분석 구간** · 클릭=커서 · 더블클릭=라이브 복귀 · Space=재생 · ←→=한 칸 · M=마크 · Enter=분석 실행 · H=패널 숨김.

## 1. 공통 시작 (매번)

1. `run_v22.bat` (또는 `python server.py`) → 브라우저 `http://localhost:8220/`. 헤더 왼쪽 「서버 OK」.
2. 로봇 USB·배터리 ON. 아두이노 시리얼 모니터는 닫는다.
3. 헤더 오른쪽 포트 **↻** → COM 선택 → **연결**. 「● REC …_auto」칩이 켜지면 이미 기록 중이다.
4. 「명령」탭 → 프로파일 `v22_raw`. 콘솔에 `# D,…` 헤더와 D행이 흐르고 헤더 칩이 `… · 100 Hz` 면 정상. 안 오면 **hdr 헤더** 버튼.
5. 「데이터」탭에서 로봇을 흔들어 phi·ank·del_now 가 따라오는지, 빨강 ⚠고착이 없는지.
6. 측정 항목마다 「기록·파일」탭 → 새 파일 이름(예 `0903_zero`) → **새 파일**. 파일이 `logs/이름.csv .events.csv .raw.txt` 로 나뉜다.

## 2. 매달림 영점 (문서 66) — 모든 절편·평형점의 기준

| 단계 | 로봇 | 앱에서 누름 | 앱이 하는 일 / 보이는 것 |
|---|---|---|---|
| 1 | 줄에 매달아 완전히 늘어뜨린다 | 「명령」**u 토크해제** | 콘솔 `# 토크 해제` |
| 2 | **왼쪽에서** 접근시켜 완전히 멎게 둔다 (30 s) | **z 영점** | 콘솔 `# ZERO 1차 기록`, 차트에 ZERO 세로선. 이 순간 phi·ank 원본값이 0 근처가 된다 |
| 3 | **오른쪽에서** 접근시켜 멎게 둔다 | **z 영점** | `# ZERO 완성 — 데드밴드 x.xx deg`. 펌웨어가 두 원각의 원형 평균을 영점으로 잡는다. 데드밴드 = 베어링 건마찰 폭 |
| 4 | 세운다 (줄 위 또는 지그) | 「데이터」탭 | 원본값 phi 가 ±180 근처(φ 채널이 도는 것, 정상). ank 는 0 근처 |
| 5 | | 「파이프라인」탭 **phi_off = 180** → **적용** | 앱이 φ 에 180 을 더해 언랩 → 앱 파생값 u_phi ≈ 0. (매달림 측정으로 돌아갈 땐 0 으로) |
| 6 | 직립에서 손을 뗀 채 잠깐 멎힘 | 「기록·파일」 마크 `직립` → **M** | u_phi·u_ank·α 가 ±1° 안이면 영점 OK. 이 값이 c₀·φ_eq 의 기준 — 재조립하면 다시 |

앱 계산: 없음(영점은 펌웨어). 앱은 ZERO 이벤트와 원각(phi_raw/ank_raw)을 기록해 두어 나중에 영점을 사후 검토할 수 있다.

## 4. P2R (실측①, 문서 64) — δ 를 계단으로 올리며 α 기울기

⚠ α = ank − φ 이므로 **발목 엔코더가 정상이어야** 의미가 있다.

| 단계 | 로봇 | 앱 | 앱이 하는 일 / 보이는 것 |
|---|---|---|---|
| 1 | **발목축**에서 매달기(하체를 잡고, 몸이 아래로). 힙을 곧게 | 새 파일 `p2r` → 「명령」**k 토크ON** | 콘솔 `# 토크 ON (현재 위치 유지, δ=0 재정의)` |
| 2 | 살짝 흔들고 멎힘 | (2 s 기다림) | 원본값 del_now ≈ 0, ank 안정 |
| 3 | | δ 수동 이동 칸 **10** → **보내기** | 콘솔 `E,…,MOVE,10`, 차트 MOVE 세로선, 서보가 10° 로 |
| 4 | 살짝 흔들고 **2 s 이상** 멎힐 때까지 | | 각도 레인 δ(노랑)가 계단, ank(초록)가 따라 내려감 |
| 5 | | 20 → 30 → 40 → 30 → 20 → 10 → 0 반복 | 각 점 2 s 이상 |
| 6 | | 도구 **P2R** · 구간 나누기 auto · 구간 끝 평균 2 s · y 열 a_alpha · 구간 「전체」 · **실행** | ① hold(=명령 δ) 평탄구간으로 자르기(없으면 MOVE 이벤트) ② 각 구간 마지막 2 s 표본 평균 → (δ̄, ᾱ) 9 점 ③ α = a₀ + b·δ 최소제곱, P2R = −b, SE ④ 상행만/하행만/원점강제/인접차분/히스테리시스. 차트에 초록 밴드 = 쓴 2 s 구간. 표 = 구간별 hold·t0·t1·δ̄·ᾱ·표준편차·잔차. 곡선 = ᾱ vs δ̄ 점 + 적합선. 숫자 P2R, se, r2, P2R_up/down, hysteresis |

정본: 0.4285 ± 0.0011, R² 0.99996, 절편 +0.14° (문서 70 §3). 절편이 1° 넘으면 영점(k 누른 자세)이 틀린 것.

## 5. 놓기 시행 (실측②③) — λ, φ_eq, c₀ — 앱의 본 무대

준비: 줄 위, 파이프라인 phi_off = 180, phi_eq = 0(처음), **k 토크ON**(δ 고정, 힙 곧게). 새 파일 `release`.

### 5-1. 한 시행 (문서 67 놓기 프로토콜)
| 단계 | 로봇 | 앱에서 보이는 것 |
|---|---|---|
| 1 | 두 손을 **스토퍼처럼 한쪽 면만** 대고 균형 근처에 세운다. 잡지 않는다 | 원위치 평면 금색 마름모가 초록/주황 선 근처, 예측점 평면 점이 노랑 띠 안 |
| 2 | 손을 **y 축(줄 방향)으로** 뺀다. 머리쪽 손 먼저 | 판독 phase 는 v22_raw 에서 0 고정(제어 없음). 예측점 평면의 점이 띠 밖으로 빠져나가며 한쪽으로 달아난다 |
| 3 | \|φ\| 8~9° 가 되면 잡는다 | 차트 φ 가 지수적으로 커지다 꺾인다 |
| 4 | 반대 방향으로도 놓는다 (섞기). 같은 φ 에서 몸통을 더 세우거나 눕혀 **ank ±3°** 흩는다 (c₀ 용) | |

마크는 필요 없다 — 앱이 놓기를 자동으로 찾는다. 단 손 접촉이 길었으면 `손접촉` 마크를 남겨 두면 표 검토가 쉽다.

### 5-2. 시행 나누기 (5회쯤 한 뒤, 이후 수시로)
도구 **시행 나누기** · 모드 auto · φ_eq 빈칸 · reldet 1.0 · fcatch 8.5 · **실행**.
- 앱: \|ψ\|<1° 가 0.4 s 이상 이어진 뒤 1° 를 넘는 순간 = 놓기, \|ψ\|≥8.5° 또는 되돌아오면 = 종료. 놓기점 = 놓기 직전 표본의 (φ₀, ank₀, β₀, Â₀). 시행마다 λ(2~9° 상승부 ln\|ψ\| 적합). 유효 판정: 2 s 안에 상승 · 최대 \|ψ\| ≥ 4° · R² ≥ 0.9, 아니면 표에 남기되 평균 제외(why 열에 이유).
- 보이는 것: 차트에 시행 띠(분홍 = + 낙하, 파랑 = − 낙하, 회색 = 무효), 표(k, t0, t1, dir, valid, why, phi0, ank0, beta0, A0, lam, r2, peak), 숫자 n_trials·n_valid·lam_plus·lam_minus·**dir_split_pct**, 원위치 평면에 놓기점(분홍/파랑 점), 분석 패널 「시행…」 목록.

### 5-3. 한 시행 자세히 (λ)
「시행…」에서 시행 k 선택 → 차트가 그 구간으로 줌, REPLAY 모드, 커서가 놓기 시각 → 도구 **λ** · φ_eq 빈칸 · lo 2 · hi 9 · **실행**.
- 앱: ψ = φ − φ_eq, \|ψ\| 가 2° 를 위로 지나 봉우리(또는 9°)까지의 상승 표본만 → ln\|ψ\| = a + λt 직선, SE, R², T₂ = ln2/λ. 비교용 lam24 = ln2/(t₄−t₂), lam48(펌웨어 R행 방식).
- 보이는 것: 차트에 분홍 점(쓴 표본)·분홍 지수 곡선·\|ψ\|=2/9 수평선·φ_eq 선·2°/4°/8° 통과 세로선. 숫자 lam, se, T2_ms, r2, n, dir. 곡선 = ln\|ψ\| vs t (직선 위에 점이 올라앉아야 한다). **Space** 를 누르면 3D 로봇이 그 시행을 재생한다.

### 5-4. φ_eq (양방향 10회 이상 뒤)
도구 **φ_eq 훑기** · 격자 −3~4° · **실행** (수십 초).
- 앱: φ_eq 를 0.05° 씩 바꿔가며 모든 유효 시행의 λ 를 다시 적합, 방향별 평균 λ+(φ_eq), λ−(φ_eq) 곡선의 교점.
- 보이는 것: 곡선 λ+(분홍)·λ−(파랑) vs φ_eq, 교점 노랑 세로선. 숫자 phi_eq_best, lam_at_best.
- 그 값을 「파이프라인」phi_eq 에 넣고 **적용** → 5-2 를 다시 → dir_split_pct 가 20 % 아래면 φ_eq 확정 (문서 70: 1.40°, 갈림 3.9 %).

### 5-5. c₀ (놓기 경계)
도구 **놓기 경계** · r 고정 빈칸(=파이프라인 −1.506) · **실행**.
- 앱: 놓기점 (φ₀, β₀)와 낙하 방향만 사용. 각 점의 절편 c_i = φ₀ − r·β₀ 를 정렬해 방향이 갈리는 문턱 = c₀, 오분류 수, 여유(margin). r 격자를 훑어 최적 r 도.
- 보이는 것: 원위치 평면에 놓기점(방향색)과 **주황 경계선** φ = r·β + c₀. 숫자 c0, errors, margin, r_grid_best. 표 = 점별 c_i.
- **다음 시행 결정**: 경계선에 가까운 쪽(여유가 큰 쪽)에 점을 채우도록 같은 φ 에서 ank 를 반대로 흩어 놓는다. margin 이 줄고 errors 0 을 유지하면 c₀ 확정. 이것이 "한 시행 보고 다음 시행 변인을 정하는" 루프다.
- 확정한 c₀ 를 「파이프라인」c0 에 넣으면 주황 실측선과 앱 Â 가 그 절편을 쓴다 (펌웨어에는 `c0 값` 명령으로).

### 5-6. (30회 이상 뒤) 시스템 동정
도구 **시스템 동정** · \|φ\| 상한 5 · SG 창 120 ms · **실행**. (φ̈, β̈) 회귀 → 고유값 λ, 좌고유벡터 → r, wf, wb, c₀. R² 와 고유값 4개를 같이 본다 — 표본이 적으면 흔들린다.

## 6. Â 잡음 바닥 (문서 54)
줄 위에서 로봇을 손으로 완전히 고정(또는 매달아 멎힘) 20 s → Shift+드래그 → 도구 **구간 통계** → 표의 **hp_rms** 열: u_phi, u_ank, a_beta, a_Ahat. Â 의 hp_rms 가 트리거 0.6° 의 1/4 아래면 합격(문서 54: 0.41~0.59 → 수리 후 0.035).

## 7. 사후 재분석
「끊기」 → 「기록·파일」탭 파일 목록 ↻ → 파일 선택 → **불러오기** → 위 도구들 그대로. 슬라이더·Space 로 재생하면 3D 가 그때 자세를 따라간다. 파이프라인 값을 바꾸면 파생열이 전부 다시 계산된다(원시 열은 그대로).

## 8. 자주 헷갈리는 것
- 라이브 중 차트를 드래그하면 「REPLAY」로 바뀐다 — 「따라가기」(F) 로 돌아온다.
- 분석 구간칸이 비어 있으면 전체 버퍼로 계산한다. 「선택구간」은 Shift+드래그한 것을 넣는다.
- 결과 기록의 항목을 누르면 그때 결과와 오버레이가 되살아난다. 오버레이 체크박스로 끌 수 있다.
- phi_off: 매달림 측정 0, 직립 측정 180. 바꾸면 u_phi 만 바뀌고 원본 phi 는 그대로다.
