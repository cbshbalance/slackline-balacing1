# v21_pres — Claude Code 작업 규칙

발표 시뮬레이터 (v19_state 확장 사본, 포트 8210). **먼저 `../docs/00_v21_클로드코드_시작안내_20260819.md` 를 읽을 것.**

## 절대 규칙 (프로젝트 문서 55 §6)

1. **코드를 고치기 전에 변경안을 사용자에게 보이고 확인받는다.**
2. `v19_state/`, `v19_sim/`, `v19_bringup/` 등 **원본 폴더는 절대 수정하지 않는다.** 작업은 이 폴더 안에서만.
3. **주장하기 전에 잰다** — 수정 후 `python tests_v21.py` 통과 확인. 물리에 닿는 변경이면 v19_state 와 동일 시나리오 궤적 일치(결정론)까지 확인.
4. 틀린 결론은 문서에 철회 기록을 남긴다.

## 물리 불변 원칙

`sim_engine.py` 의 물리·제어·추정 경로는 발표 도구 목적상 건드리지 않는다 (표시·UI·서버 명령만 확장).
v19_state 대비 허용된 변경(이미 반영): `set_pose` / `reset` 초기 qvel(x0 속도 키) / 서버 명령 `pose`·`pose_begin/end`·`scene_save/load`·`x0` 속도 확장 / hist 19번 열(FWE 위상코드).

## UI 개발 함정 (문서 58·59에서)

- `const` 상태 선언은 `frame();` 첫 호출 이전(스크립트 상단 상태 구역)에 — TDZ 로 스크립트 전체가 침묵 사망한 전례.
- 예측점 평면 참값의 fold 중 부호반전은 **물리**다(β̇ 킥) — 「접기 스파이크 정리」 체크박스로 표시만 정리. 다시 "버그"로 오인하지 말 것.
- 서버 프로세스 정리는 이름 패턴 pkill 대신 포트 기준(`fuser -k <port>/tcp` 또는 netstat→taskkill).
