## v19_state 대비 추가된 것 (계획 문서 56 기준)

### 1A — 평면 마우스 집기 (원위치 평면)
- **hover** = 그 상태의 자세 미리보기 (δ=0·속도0 놓기라 β=α). 정지 중에만. 훑고 나가면 원상복귀(스냅샷).
- **클릭** = 그 상태에서 즉시 물리 시작 (러닝 중에도 = 그 자리 재시작). '리셋'은 같은 판 리플레이.
- **Shift** = 안정모드선 위로 구속 / **Alt** = 누른 순간의 선위 점을 지나는 수직(불안정 방향) 구속.
- 십자선 옆에 그 점의 (β, φ, A) 실시간 표시 — 트리거 띠 안이면 초록, 밖이면 노랑.
- 체크박스 "🖱 평면 집기" 로 on/off (발표 중 오클릭 방지).

### 1B — 정확 상태 입력 (예측점 평면 = 숫자의 평면)
- β·φ·β̇·φ̇(+선택 δ) 입력 → α=β−P2R·δ, θ=α+δ 환산 → **속도 포함 x0** 로 설정.
- 서버 `x0` 명령이 phid0/alphad0/thetad0 (deg/s) 를 받는다. 속도 키가 없으면 0 (하위호환).
- 수용시험: 입력 ↔ plane_pt 왕복 기계정밀도 일치 (`tests_v21.py`).

### 1C — 연출 시연 (키네마틱·이상화 — 라벨 명시)
- **천천히 접기 (CoM 불변)**: 상태점이 회색 CoM 등고선을 정확히 따라간다 (E2E 검증: 기울기 == −sCoM 소수 4자리).
- **접고-기다리고-펴기**: 초기 메커니즘 F·W·E 3단계 재생 + 단계 라벨.
- **ε*·δ_f* 작도** (예측점 평면): 현재 예측점 → 접기방향(등고선) → A=0 선 교점 화살표 + δf*·ε* 수치.

### 4단계 — 실측 반영 (8/20)
- **실측선 오버레이**: 입력칸 r·절편 c(φ)·λ(기본 5.3, 문서 53) + 「실측선 표시」 → 두 평면에 주황 점선
  (예측점 평면엔 실측 트리거 띠 폭 = A_trig·|r| 포함) + **실측 w = [−1/r, 1, −1/(rλ), 1/λ] 자동 표시**.
  실측 ②(안정모드선) 수행 시 여기 기입하면 "모델 초록선 vs 실물 주황선" 한 화면 (문서 56 §3G).
- **실측 발목잡음 프리셋**: 체크박스 + σ 입력(기본 0.223°, 문서 54 — 베어링 교체 후 갱신).
  `sim_engine._measure` 발목 채널에 양자화 이전 백색잡음 주입. **σ=0 이면 RNG 미호출 — 궤적 MD5 완전 동일(결정론 보존, 검증됨)**.
  프리셋 버튼이 real 을 초기화해도 체크되어 있으면 자동 재적용.
- ★검증: σ=0.223° 주입 시 시뮬 Â 고주파 rms = **0.438°** — 문서 54 실측 잡음 바닥 0.41~0.59° 안. "발목 92%" 진단의 독립 재현.

### D1 — 평면 확대·별도 창·예측점 평면 직접 조작 (8/19 — D2 로 대체됨, 기록용)
- **전체화면**: 각 평면 제목줄의 ⛶ 버튼 (예측점 평면은 **F 키**). Esc 로 복귀.
- **별도 창**: ↗ 버튼 — 팝업 창에 같은 평면을 실시간 미러 (표시 전용 — 조작·집기는 본창에서).
  두 번째 모니터에 예측점 평면만 크게 띄우는 용도. 창을 닫으면 자동 해제.
- **예측점 평면 줌·이동**: 휠 = 마우스 지점 기준 줌, 우클릭 드래그 = 이동(팬),
  더블클릭 = 자동 범위로 복귀. 수동 뷰 중에는 좌상단에 🔍 표시. 별도 창도 같은 뷰를 공유.
- **예측점 평면 집기 (속도 0)**: 좌클릭 = 그 (β_pred, φ_pred) 위치의 **속도 0·δ=0 자세**로
  로봇 표시(물리 정지, 러닝 중이면 자동 일시정지), 드래그 = 계속 훑기, 놓으면 x0 로 확정
  (리셋 버튼이 같은 판 리플레이). **실행(Space)** 을 누르면 그 상태에서 물리 시작.
  속도 0 이면 예측점 = 원위치이므로 클릭 좌표가 그대로 (β, φ) 가 된다 (화면에 "속도0 설정" 명시).
  속도까지 정확히 넣으려면 기존 4D 입력칸. 집기 스위치(🖱 체크박스)가 꺼져 있으면 무시.

  집기 좌표 왕복 일치(0.01° 미만)·pred==pos(속도0)·Space 후 물리 진행, PLSCALE.pl1 회귀 무결). JS 오류 0
  (미디어 404 는 .gitignore 로 제외된 영상 — 실기 PC 에는 존재).

### 접기 스파이크 정리 (8/18 — β 부호반전 문의의 답)
예측점 평면에서 **참값**이 접기 순간 ±로 튀는 것은 부호 오류가 아니라 **접기 β̇ 킥이 (λI−D̂)⁻¹ 를 통과하며 예측점을 튕기는 실제 물리**다 (fold 스텝 참 |Δβ_pred| 중앙값 3.5° vs 추정 0.83° — 추정은 실기 파이프라인 필터가 스파이크를 걸러 안정). 원위치 평면 β 반전은 0건. v19↔v21 물리 MD5 완전 일치 확인.
→ 체크박스 「접기 스파이크 정리」(기본 ON): fold·REST 중 참값 점·궤적을 예측점 평면에서 숨기고 범위 산정에서도 제외. **판정·물리 불변, 표시만 정리.** (서버 hist 19번 열 = 위상코드)

## ★ 물리 발견 — 놓기 시연의 정직한 한계 (시험 중 발견, 문서 58)
완벽히 안정모드선 **위**에 놓아도 비선형 씨딩(진폭² 비례)이 λ≈5.9/s 로 증폭되어 **~1.5-2 s 뒤 넘어진다** (수치 씨딩만으로도 ~3 s 상한). 실물도 같은 물리다 — 문서 46 이 실측② 합격을 "3회 이상 진동"으로 정한 이유.
- 시연 대조는: 선 위 = 왕복 2-3회 후 낙하(버팀 1.5-2.0 s) vs 선 밖 = 왕복 없이 즉시 한쪽 낙하(0.8 s), **그리고 제어 ON 이면 어디를 클릭해도 잡는다** (10점 전부 8 s+ 생존, 접기 21-28회).
- 발표 멘트도 이 구조가 좋다: "선 위 = 오래 버틴다, 선 밖 = 곧장 넘어진다, 우리 제어 = 다 잡는다."
