## 2. 명명법 (naming convention)

**형식:** `<대분류>_<소분류>_v<세대>.<파트리비전>.scad`

- **대분류(5종):** `frame` · `lower`(하체) · `upper`(상체) · `axle`(축) · `encoder`(엔코더 관련)
- **소분류:** 위치+부품(예: `ankle_carrier`, `pivot_rear`, `bodyA`) — 어느 파트인지 즉시 식별.
- **버전 `v<세대>.<리비전>`:**
  - **세대(앞자리)** = 프레임 세대. 현재 전부 **5**. **구조 대개편 때만** 6으로 올리고, 그때 각 파트 리비전은 `.1`로 리셋.
  - **리비전(뒷자리)** = 그 파트 지오메트리가 바뀔 때마다 +1. 이번 명명 정리 시점을 리셋 기준으로 **현행 전 파트를 `v5.1`**로 둠(이전 이력은 아래 3장 LOG).
- **마스터:** `frame_master.scad` (이름에 버전 없음). 실제 상태는 이 CHANGELOG 최신 LOG로 관리 → **항상 현행 마스터 1개**라 최신 혼동 없음.
- **원칙:** **파트당 현행 파일은 정확히 1개.** 그래서 "어느 게 최신"이 항상 자명함.
- **폐기 →** `deprecated/`, 파일명 `_DEPRECATED`, 헤더에 대체 파트 명시. **아카이브 →** `archive/`. **산출물 →** `exports/`.

### ⚙ 다른 Claude 세션 / 팀원 작업 절차 (필독)
1. **치수·형상 변경은 `frame_master.scad`를 편집**(파트 래퍼는 include만 하는 선택자라 보통 안 건드림).
2. 어떤 **파트의 지오메트리가 바뀌면**, 그 파트 파일을 **리비전 +1**로 rename(`_v5.1` → `_v5.2`), 헤더/이 CHANGELOG에 로그 추가.
3. 새 파트는 `<대분류>_<소분류>_v5.1.scad`로 만들고 `include <frame_master.scad>` + `part_mode` 지정.
4. 폐기 시 `deprecated/`로 이동 + `_DEPRECATED` + 대체 파트 명시.
5. 반드시 **브랜치 → PR**로 올리고, OpenSCAD 렌더로 매니폴드/조립 경고 0 확인 후 병합.
6. 커밋/푸시는 HTTPS+토큰(파인그레인드, 이 리포 한정). SSH 원격은 이 환경에서 불가.

## 3. 세부 변경 로그 (LOG, 최신 우선)

### v5.5 — 2026-07-24 (저녁) · 발목 캐리어 간섭 수정 + 상체 B 확정형(A/B, 도어 없음) + 피벗 검증
**① 피벗 축높이 검증(변경 없음):** `encoder_pivot_box`와 반대편 `encoder_pivot_bearing` 모두 **베어링 중심축 = 장착면(프로파일 상면) +25.0mm**로 STL 계측 일치 확인(둘 다 `axis_z`/`mount_rise` 공유 파라미터로 유도 → 구조적으로 동기). 수정 불필요.

**③ `lower_ankle_carrier` v5.1→v5.2 (간섭 2건 수정):**
- **랜드 보어 관통:** 구 컷(`2*ring_face−brg_w`)이 |y|29.85에서 멈춰 랜드월(31..33)에 8.4 축공만 남음 → 11.4 노즈가 통과 못 하고 **칼라가 엔드월 면을 눌러 마찰**. 컷을 링 페이스까지 연장, **랜드 보어 d19 완전 관통**(608 내륜 OD 12 < 19 < 외경 22 → 노즈는 내륜만 접촉, 랜드는 외륜만 지지).
- **거싯 클립:** 거싯 헐이 하우징 내측면(|y|=31)을 넘어 |y|=29.6까지 개방 중앙으로 돌출 → 회전 칼라 스윕(최대 반경 12.8, |y|24.4..30.4)과 간섭. 각 거싯을 **|y|=31 평면에서 클립** — 엔드월 면 밖으로 아무것도 돌출하지 않음.
- **검증:** 칼라 회전 스윕 솔리드(몸통 r12.82 + 노즈 r5.7) ∩ 캐리어 = **공집합**(수정 전 176mm³). 노즈-보어 반경 여유 3.8, 칼라 몸통 외측면↔랜드월 내측면 0.6, 러그 상단(12.3~12.8)↔엔드월 하단(z14) ≈1.2~1.7. 매니폴드/경고 0.
**④ `upper_bodyB` v5.1→v5.2 (확정형 A/B, 도어 없음, +22mm):**
- **높이 +22 (`robot_l2` 350→372):** 선반이 보드 상단을 3mm 위에서 덮고 있어 추가 케이블 연결 불가 → 선반/헤드만 +22 상향, **보드 상단 개방 여유 3→25mm**. 보드 자체는 그대로(ocr_center_z 불변 → **ELL_IMU 250.5 유지**). **B 파트 높이 221mm ≤ X1C 256** ✓.
- **오픈 X- 페이스:** 도어(나사 6·보스·리베이트) 전부 삭제, X- 벽 제거 + 리턴 립 3(개구 90존 79 / 헤드존 87). `upper_body_door` part_mode는 폐기 echo만.
- **OpenCR = 테이프 패드 + 하단 안착턱:** 스냅 리벳(튜브·푸시홀·핀홀) 은퇴. 격벽 전면 = 보드 배면(테이핑 패드, bulk_x0=ocr_back_x), 보드 하단은 안착턱(6×60)에 안착.
- **A-B 스플라이스 = 닫힌 텔레스코핑 슬리브**(벽 2.5, 편측 유격 0.3, split 위 8mm 플레어 용접): X-텅 파손 문제 해결. 크로스볼트 2 동일, A는 무변경.
