> **이 문서는 `cad/` 폴더의 단일 정본(single source of truth)입니다.**
> 팀원과 (다른 대화창의) Claude 모두, 작업 전 여기서 **① 현재 구성 ② 명명법 ③ 이력**을 먼저 확인하세요.

## 2. 명명법 (naming convention)

**형식:** `<대분류>_<소분류>_v<세대>.<파트리비전>.scad`

- **대분류(5종):** `frame` · `lower`(하체) · `upper`(상체) · `axle`(축) · `encoder`(엔코더 관련)
- **소분류:** 위치+부품(예: `ankle_carrier`, `pivot_rear`, `bodyA`) — 어느 파트인지 즉시 식별.
- **버전 `v<세대>.<리비전>`:**
  - **세대(앞자리)** = 프레임 세대. 현재 전부 **5**. **구조 대개편 때만** 6으로 올리고, 그때 각 파트 리비전은 `.1`로 리셋.
  - **리비전(뒷자리)** = 그 파트 지오메트리가 바뀔 때마다 +1. 이번 명명 정리 시점을 리셋 기준으로 **현행 전 파트를 `v5.1`**로 둠(이전 이력은 아래 3장 LOG).
- **마스터:** `frame_master.scad` (이름에 버전 없음). 실제 상태는 이 CHANGELOG 최신 LOG로 관리 → **항상 현행 마스터 1개**라 최신 혼동 없음.
- **원칙:** **파트당 현행 파일은 정확히 1개.** 그래서 "어느 게 최신"이 항상 자명함.
- **폐기 →** `deprecated/`, 파일명 `_DEPRECATED`, 헤더에 대체 파트 명시. **아카이브 →** `archive/`. **산출물 →** `exports/`.

### ⚙ 다른 Claude 세션 / 팀원 작업 절차 (필독)
1. **치수·형상 변경은 `frame_master.scad`를 편집**(파트 래퍼는 include만 하는 선택자라 보통 안 건드림).
2. 어떤 **파트의 지오메트리가 바뀌면**, 그 파트 파일을 **리비전 +1**로 rename(`_v5.1` → `_v5.2`), 헤더/이 CHANGELOG에 로그 추가.
3. 새 파트는 `<대분류>_<소분류>_v5.1.scad`로 만들고 `include <frame_master.scad>` + `part_mode` 지정.
4. 폐기 시 `deprecated/`로 이동 + `_DEPRECATED` + 대체 파트 명시.
5. 반드시 **브랜치 → PR**로 올리고, OpenSCAD 렌더로 매니폴드/조립 경고 0 확인 후 병합.
6. 커밋/푸시는 HTTPS+토큰(파인그레인드, 이 리포 한정). SSH 원격은 이 환경에서 불가.

## 3. 세부 변경 로그 (LOG, 최신 우선)

### v5.4 — 2026-07-24 · 42mm 모듈 실측 반영 + 명명법 전면 개편
- **엔코더 홀 실측:** 4코너 그리드 **37→34(코너 4mm 안쪽 = ±17)**, **M3 셀프탭(2.7)→M3 관통(3.4)**. 나사가 브래킷을 지나 모듈 뒷면 기둥 끝에 체결되므로 관통이 맞음. (발목·피벗 공통, `as_hole_dx/dy`, `as_hole_d`)
- **뒷면 8mm 기둥 대응(`as_back_post=8`):** PCB 뒷면 r3·8mm 기둥 4개를 고려해 장착판을 8mm 뒤로(발목 브래킷 `plate_y0`/`akc_brk_bar_y0`, 피벗 `enc_plate_in_y`). **칩↔자석 공극 1.5 불변.**
- **락칼라 내경:** `shaft_d+0.25`(8.25) → `shaft_print_d+0.1`(**7.9**). 실제 7.8 축에 헐거움(0.45) 해소 → 스냅핏. (발목·피벗 칼라 공통)
- **상체 확정:** **A/B 구성 유지**(ABC 분할·battery lid `upper_body_c` 미진행, 도어 폐기).
- **명명법 개편:** `frame_v5.scad`→`frame_master.scad`, 전 파트 `<대분류>_<소분류>_v5.1.scad`로 rename, 폐기 4종 `deprecated/`, 구프레임 `archive/`, 산출물 `exports/`. include 전부 `frame_master.scad`로 정리(구 v3/v4 include 버그 동시 해소). 전 파트 렌더 매니폴드·조립 경고 0 검증.
- 검증: 발목·피벗 공극 1.5, 전 현행 파트 단일 매니폴드, assembly 경고 0.

### v5.3 — 2026-07-19 (저녁~) · 42mm 실물 모듈 대응(설계)
- 실물 = 쿠팡 하이제니스 "AS5047P 14bit SPI 42mm"(자석 포함). 42×42 보드 대응으로 대개편.
- **발목:** 보드 상단 z=+21 → **브리지 z14→z23**, **플랜지 z0 22→31(+9)**, 하체 통째 +9(`robot_l1 250→259`). 상승 브리지를 하우징에 잇는 **엔드월** 추가. 브래킷 T→**L(46폭, 4코너 홀)**.
- **피벗:** 42 보드가 기존 창에 안 들어가 프레임 **비대칭화**(하면 프로파일 고정, 상단바 축+35). 보드 커넥터-UP 장착. 구 2×M2+슬롯 → 4코너 그리드.
- (당시 홀 그리드는 37 **추정**, 셀프탭 가정 — v5.4에서 실측 34·관통으로 정정)

### v5.2 — 2026-07-19 (낮) · 개방형 캐리어
- 닫힌 캐리어+바닥 리드 은퇴 → **개방형 캐리어**(베어링 하우징 2 + 상부 브리지). 중앙 개방으로 자석·PCB·칼라를 열린 중앙에서 조립.
- **안쪽 락칼라 2개 부활**(노즈 연장형). PCB는 **T-브래킷**으로 브리지 하부에 장착. `ankle_pcb_lid` 폐기.
