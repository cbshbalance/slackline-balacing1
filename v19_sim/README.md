# v19_sim — MuJoCo 전물리 시뮬레이터 (서보·마찰·센서 현실화) (2026-07-17)

v19 재설계 실기(카본 사다리꼴 크랭크 + φ엔코더 + 발목 베어링)를 **MuJoCo 전물리**로
세우고, 그 위에 v10/v17식 브라우저 인터페이스(슬라이더·재생속도·한 프레임 스텝·그래프)를
얹은 시뮬레이터. `v19_bringup/`(params_v19 = 단일 진실 소스)을 그대로 가져다 쓴다.

## 실행

```bash
pip install mujoco aiohttp scipy numpy      # 최초 1회
cd v19_sim
python server.py                            # → 브라우저에서 http://localhost:8199
```

단축키: `Space` 시작/정지, `→` 1장 전진, `←` 1장 뒤로, `R` 리셋.
검증(UI 없이): `python test_headless.py` — 7항목 전부 PASS 여야 정상.

## 구성

| 파일 | 역할 |
|---|---|
| `mjcf_v19.py` | 재설계 스펙 기하 그대로 MJCF 생성 — 프레임, 사다리꼴 크랭크(빗변 50×2 + 발축바 10cm, 질량분포 실물), 발목 베어링, 힙 XM430(armature·마찰·감쇠). **직렬 체인**(v14의 equality 불필요) |
| `gains_v19sim.py` | compute_gains_v19 와 동일 수식의 무부작용 게인 계산 + ★`servo_aware`(아래 발견 1) |
| `sim_engine.py` | 500Hz 제어 루프: 센서(양자화·노이즈·1g 게이팅) → 칼만5(펌웨어 동일 구조) → LQR/FWE → 서보 모델(전류 unit 양자화·데드밴드·Kt·토크-속도 곡선) → MuJoCo. 스텝백 스냅샷(결정론 보장) |
| `server.py` | aiohttp 웹서버 + WebSocket 30Hz 프레임 |
| `static/index.html` | v17식 UI: three.js 3D(궤도/사이드 뷰), 각도·A·τ 스트립차트, 전 파라미터 슬라이더 |
| `test_headless.py` | 전물리 검증 7항목 (sim_check_v19 의 전물리판) |

부호 규약: 모델 φ = −q_phi(MuJoCo), α·θ는 월드피치 그대로 (AGENTS §9의 −Rφ 함정 처리는
`sim_engine.get_state()` 한 곳에만 있음).

## ★전물리가 낸 발견 (2026-07-17, 설계 추정치 기준 — 실측 후 재확인)

1. **XM430 기어 반영 관성이 지배적**: armature = N²·J_rotor ≈ 0.0045 kg·m² 는 로봇 힙
   유효 관성 1/(EᵀM⁻¹E) ≈ 0.0018 의 **2.5배**. 이론 모델 그대로 게인을 만들면 추정기가
   4배 빠른 토크 응답을 예측해 **폐루프 즉시 발산**. → `servo_aware` 게인(M += I_a·S_δδ,
   힙 감쇠를 상대 δ̇ 감쇠로)이 기본 ON. **실물 브링업 전 compute_gains_v19.py 에도 같은
   반영 필요** + armature 실측(복합진자에 서보 포함 or 서보 free-spin 감쇠) 항목 추가.
2. **힙 기어 쿨롱 마찰(≈0.05 N·m) → LQR 유계 리밋사이클 ±13°**: 7/11 이론 노트의
   "남는 리스크는 쿨롱 스틱션 데드밴드(유계 리밋사이클)" 예측이 그대로 나옴. f_hip=0
   이면 0.5° 수렴. → 실물에서 마찰 보상(feedforward/디더) 없이는 직립 '유지'가 아니라
   '진동'이 된다.
3. **LQR+칼만 포획영역 ≈ ±0.5~1°** (전 현실화, 콜드스타트): 그 밖은 과도 피크가
   비선형 영역을 넘어 낙하. 문서의 "큰 각도 복원 경계선 = FWE의 표적" 서사와 정합.
4. **FWE 전물리 γ 갭**: 실측 접기 킥이 선형 맵(γ_cycle)보다 ~1.7배 강함 → 모델 ρ 창
   (0.82~1.18)이 아니라 **ρ≈0.7 부근에서 유계**(참상태 기준, 11사이클 |A|max 3.6°).
   이론 잔여 과제 "MuJoCo 전물리 검증 갭(γ 보정)"의 정량 출발점.
5. **칼만 추정으로는 FWE 발산** (현행 QKF/RKF 튜닝): 접기 구간의 격렬한 동역학을 관측기
   (수렴 시정수 ~1.3s)가 못 쫓아 A 추정이 무너짐. QKF ×300 도 불충분. → FWE 이식 전
   관측기 재설계(또는 φ엔코더+자이로 직접 A 산출) 필요 — 브링업 체크리스트에 추가할 것.
6. **비대칭 강건성**: m₂ 편차 −10%는 유계, **+5%는 낙하** — 상체 질량 과소평가 방향이
   위험. 실측 필수의 정량 근거.
7. **상보필터(CF) 추정기 A/B (2026-07-17 추가)**: v19에서 φ·δ·δ̇·θ̇가 전부 직접측정이라
   "θ만 CF로 잡으면 칼만 불필요" 가설을 세 번째 추정기(UI '상보(CF)')로 구현·비교.
   결과: 조용한 구간 추정 정확도는 CF가 우세(α 오차 0.29° vs 칼만 1.16°)지만 폐루프는
   **전패** — ①thAcc 선형가속 바이어스가 θ_cf를 끌어내려(k=0.002 기준 −10° 드리프트)
   1.5s 내 낙하: 펌웨어 칼만의 '선형가속 보상 측정모델'이 정확히 이걸 막는 장치임을
   전물리로 재확인(6/22 CF 폐기 결정의 정당화) ②보정을 꺼도(순수 자이로) δ̇ 양자화
   LPF 지연·φ̇ 차분 노이즈로 스틱션 리밋사이클이 자라 ~4s에 이탈. → **칼만5 유지가
   정답**, CF는 UI 옵션으로 남겨 두었으니 관측기 연구(예: FWE용 A 직접 산출)의
   대조군으로 활용할 것. CF 파라미터: real.cf_k_acc / cf_tau_phid / cf_tau_deld.

### 야간 전물리 연구 추가 발견 (2026-07-18 새벽, NIGHT_LOG.md 상세)

8. **★발목 엔코더 추정기(`enc`, 사용자 제안)가 결정타**: 절대각 3개(φ, α=φ+발목각,
   θ=α+δ)를 전부 엔코더로 얻고 속도는 각도 직접 차분+LPF(10ms). IMU 미사용.
   LQR 포획영역 0.5→3°+, 스틱션 리밋사이클 소멸(잔여 ~0.8°), φ̇킥 1.0 rad/s 회복,
   **몬테카를로 8/8 생존**(m₂±10%·Kt±10%·f_hip×2·복합). 칼만의 m₂+5% 낙하 비대칭
   소멸. ⚠자이로 혼합(α̇=θ̇−δ̇)은 금지 — 빼기 연산이 서보 킥 스파이크를 만든다.
9. **결정 실험 — FWE 이론은 무죄**: 엔진 접기 사이클의 실제 δ̈(t)를 선형 4D 모델에
   그대로 입력하면 MuJoCo와 A 궤적 차 0.16°. 기존 '전물리 γ 갭'의 정체는 비선형이
   아니라 **실행 프로파일 갭**(실제 δ(t) ≠ 공칭 삼각).
10. **γ 실행 캘리브레이션으로 반복 FEW 전물리 최초 성립**: 엔진 45사이클 최소제곱
    Gc*=5.30, gc*=0.285(공칭+44%), γ*=18.6 → 참상태·실서보에서 ρ 0.85~1.05 전 구성
    15초 유계. 실센서(enc)는 6~12초(20~31사이클)까지 연장 후 실행+센서 잔차(RMS
    0.49°) 랜덤워크가 회복 천장(~3°)을 넘어 낙하. `real.fwe_gamma_cal=18.6` 로 사용.
11. **FWE 실용 틈새 부재(이 스케일·이 서보)**: 접기 회복 천장 A*≈3° < LQR(enc)
    흡인영역 A~8° → 하이브리드도 무익. 원인 사슬: δmax=55°·서보속도·λ=6.3/s.
    권고 — 실물 제어는 LQR(enc), FWE는 γ 캘리브 절차와 함께 이론 검증 시연 트랙.

## UI 사용 팁

- **LQR 데모**: 기본값 그대로 ▶ — 스틱션 리밋사이클(±13°)이 보인다. `f_hip → 0` 으로
  내리면 수렴. `추정기=참값` 으로 바꾸면 추정 오차의 기여를 분리할 수 있다.
- **FWE 데모**: 모드 `반복 FEW` + `추정기=참값` + `ρ=0.7` 후 교란 버튼. 재생속도
  0.05×로 내리고 `⏮/⏭` 로 접기 프로파일을 한 프레임씩 볼 것.
- 그래프 위: φ·α·θ·δ(°), 아래: A(위험도, β환산°)·Â(추정)·τ(N·m).
- 물리 파라미터·플랜트 편차 슬라이더는 놓는 순간 재빌드+리셋된다(게인도 재계산).

## 한계 / 주의

- 서보는 전류모드 정상상태 근사(전류루프 대역폭·인덕턴스 무시). 토크-속도 한계는
  구동 방향에만 적용(제동은 스톨까지 허용).
- PRESENT_VELOCITY 의 내부 필터 지연은 미모델(양자화만).
- 크랭크 관성은 MuJoCo 실기하(빗변이 기울어진 사다리꼴) — params 막대근사와 0.1% 일치
  확인됨(test [0]). 실물 CAD 질량표가 나오면 params 를 교체하면 된다.
- 기본 현실화 값(armature, f_hip, b_gear …)은 전부 **설계 추정치**다. README 의
  발견들은 방향성이며, 수치는 실측(§v19_bringup 체크리스트) 후 갱신할 것.
