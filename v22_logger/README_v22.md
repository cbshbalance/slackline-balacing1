## 왜 만들었나 (사용자 의도, 9/2)

여러 사람이 펌웨어를 고쳐 오면서 **로봇이 무엇을 어떻게 재고, 무엇을 걸러서, 어떤 구간으로 어떤 적합을 해 값을 냈는지**
사람이 그래프로 확인한 적이 없다. 그래서 (1) 기본 기록·실시간 모니터링부터 세우고, (2) 측정값이 나오는 과정 전체를 화면에서
검토할 수 있게 하고, (3) 그 위에서 제어에 필요한 측정을 정확·체계·편리하게 하는 로거와 펌웨어를 새로 만든다. 이 앱은 그 (1)(2)다.

**설계 원칙 하나: 펌웨어 계산값을 믿고 그리지 않는다.** 원시 엔코더 열(phi, ank, del_now)에서 앱이 α·β·속도·Â·예측점을
**다시 계산**하고, 펌웨어 열(`_fw`)을 나란히 두어 Δ 를 보인다. 적합은 전부 **쓴 구간·쓴 점·식·잔차**를 되돌려준다.

- **라이브**: OpenCR 시리얼(115200)의 `D,…` 행을 30 Hz 프레임으로 브라우저에 보낸다. 3D·평면·표·차트가 같은 행을 본다.
- **재생**: 슬라이더·클릭·←→·Space. 차트 휠=줌, 드래그=이동, **Shift+드래그=분석 구간**, 더블클릭=라이브 복귀.

  `.folds.csv`. 마크(<kbd>M</kbd>, 콘솔에 `#메모`)는 E행으로 events.csv 와 차트에 남는다.
- **명령**: `commands.json` 의 프로파일(hangcal_fold / incremental_fold_min / p2r_test)이 버튼이 된다. δ 수동 이동, `이름 값`
  파라미터 설정/읽기, 자유 텍스트. 접속 직후 아무것도 보내지 않는다(문서 77 §6). 위험 명령(x, b)은 확인 창.
- **파일**: logs/ 와 기존 CSV(루트·lambda test·p2r test·r test)를 불러오거나(연결 끊은 뒤) 브라우저에서 업로드(+events.csv).
  p2r_logger 형식(`t_ms,phi_deg,…`)과 fold/hangcal 형식(`D,` 접두어, `# D,…` 헤더) 모두 읽는다.
- **파이프라인 탭**: P2R·r·c0·λ·wf·wb·vg·φ_eq·diff_ms·tau_ms·smooth_ms·alpha_mode·unwrap·snap·**phi_off/ank_off**(매달림 영점→직립 +180). 바꾸면 서버가
  파생열 전부를 다시 계산해 보낸다. 식은 탭 위에 그대로 적혀 있다.

## 알아둘 것

- 시리얼 포트는 한 프로그램만 연다. 아두이노 시리얼 모니터·hangcal_logger 와 동시에 못 쓴다 → 업로드 때는 「끊기」.
- 실물 PC 는 pyserial 이 필요하다 (hangcal_logger 가 쓰므로 이미 있을 것). Windows 포트 이름(COM7)은 그대로 목록에 뜬다.
- 라이브 중 파일 불러오기는 막았다(버퍼 섞임 방지). 연결하면 파일 버퍼는 비운다. 기록 파일은 언제나 그대로.
- 헤더(열 구성)가 다른 D행이 오면 버퍼를 새로 시작한다 (다른 펌웨어). 같은 펌웨어 재시작(t_ms 되감김)은 `T_RESET` 이벤트로 이어 붙인다.
- 버퍼 상한 60만 행(200 Hz × 50 분). 넘으면 앞을 버린다 — 파일에는 남아 있다.
- USB 선의 장력이 균형에 주는 영향은 코드 밖 문제 (문서 60 §6). 벤치 측정용으로 자리매김.

명령: z u k <정수> m s p t w e swap hdr · mode N g h x y fold X · `이름 값`(gam trig rel vrel dead dstep dlim rest alim sgn fdeg lock r lam c0 kv wmode wf wb p2r loghz vel acc ilim).
명령 팔레트 프로파일 `v22_raw` 가 붙어 있다. 부호 확인은 `y`(dry-run) + `mode 2` + `g` 로 FOLD E행의 부호를 본다.

1. **원시값만 찍는다**: `D,t_ms,phi,ank,del_now,hold,phase,err[,cur_mA,volt]` — α·β·속도·Â 는 앱이 만든다.
   (있어도 된다 — `_fw` 열로 나란히 표시된다. 그러나 정본은 원시.) 열 이름은 `# D,…` 헤더 주석으로 알린다.
2. 고정 길이 한 줄, 블로킹 print 금지, 200 Hz 면 1 Mbps, 115200 이면 100 Hz(loghz).
3. 명령은 한 글자 + `이름 값`. 새 명령은 `commands.json` 프로파일 하나 추가로 버튼이 된다.
4. 시행 요약(R행)·이벤트(E행)는 지금처럼. 앱도 자동 분할하므로 없어도 된다.
5. 매달림 영점·직립 변환은 펌웨어가 하되 원각(zero 전 raw)도 찍으면 앱이 영점을 사후 검토할 수 있다 — 검토 대상.
