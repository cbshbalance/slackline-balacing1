# v19 배선·연결 현황 (2026-07-31)

조립 후 브링업 과정에서 **실물로 확인된** 배선·연결 상태와 그 과정에서 겪은 함정을 기록한다.
실험절차서(`docs/어름이_조립후_실험절차서_완전판_v19.docx`) 5장의 배선표를 실물 기준으로 보강한 문서이며,
같은 내용의 그림 배선도는 `배선도_20260731.html`(브라우저로 열기).

## 1. 전체 구성

```
        [φ 엔코더]                                    [12V 배터리]
        AS5047P                                            │
        상단 피벗                                          │ 전원 입력
           │                                               ▼
           ├── 3.3V ┐                            ┌──────────────────┐
           ├── GND ─┼── (GND 핀 직결) ──────────▶│                  │
           ├── CSn ─┼── D10 (직결) ─────────────▶│     OpenCR 1.0   │◀── USB ── PC
           ├── SCLK ┤                            │                  │
           ├── MISO ┤   ┌──────────────┐         │  전원 스위치     │
           └── MOSI ┘──▶│ 공유 정거장  │────────▶│  (슬라이드)      │
                        │ 브레드보드/Y │  D13     └────────┬─────────┘
        [발목 엔코더]───▶│ 3.3V/D13/    │  D12              │ RS-485 (4핀)
        AS5047P         │ D12/D11      │  D11              ▼
        발축             └──────────────┘            [XM430-W210-R]
           └── CSn ── D9 (직결)                      허리 모터 ID 1
```

## 2. 핀 대응표 (확정)

| 신호 | φ 엔코더 (상단 피벗) | 발목 엔코더 (발축) | 공유 여부 |
|---|---|---|---|
| VCC(3V3) | 3.3V | 3.3V | **공유** (한 핀 → 두 갈래) |
| GND | GND | GND | 각자 빈 GND 핀에 직결 |
| CSn | **D10** | **D9** | 전용 (절대 바뀌면 안 됨) |
| SCLK | D13 | D13 | **공유** |
| MISO | D12 | D12 | **공유** |
| MOSI | D11 | D11 | **공유** |

- 코드 상수와 1:1 대응: `PHI_CS = 10`, `ANK_CS = 9` (SPI 공유선은 보드 기본 핀).
- OpenCR 우노 배열에서 **3.3V 핀은 1개뿐**이라 반드시 나눠 써야 한다. GND는 3개(전원 헤더 2 + D13 옆 1)라 나눌 필요 없음.
- 공유선 4개(3.3V·D13·D12·D11)는 브레드보드 세로줄(5칸이 내부 연결) 또는 Y자 점퍼선으로 분기.

### 모듈 핀 이름 읽기 (제조사별 표기)

| 뜻 | 기판 인쇄 표기 예 |
|---|---|
| 클럭 | SCLK / CLK / SCK / SCL |
| 데이터(엔코더→보드) | MISO / DO / SDO |
| 데이터(보드→엔코더) | MOSI / DI / SDI |
| 칩 선택 | CSn / CS / SS |

★ 실물 AS5047P 모듈은 **핀 헤더와 하얀 6핀 커넥터의 핀 순서가 서로 반대**로 인쇄되어 있다.
핀 헤더: 위에서 VCC→GND→CSn→SCLK→MISO→MOSI / 커넥터 쪽 인쇄: MOSI→MISO→SCLK→CSn→GND→VCC.
순서를 외우지 말고 **꽂는 구멍 옆 인쇄 글씨를 하나씩 읽고** 연결한다.

## 3. 모터·전원

| 항목 | 확정 내용 |
|---|---|
| 모터 | XM430-W210-R (**-R = RS-485**), ID 1, Protocol 2.0 |
| 포트 | OpenCR **RS-485 4핀** 커넥터 (TTL 3핀과 혼동 금지) |
| 통신 속도 | **1 Mbps 확정** (`set_baud_1m` 스케치로 57600 → 1M 승격 완료) |
| 모터 전원 | **12V 배터리에서만** 온다. USB만 연결하면 보드만 켜지고 모터는 죽어 있다 |
| 전원 스위치 | 보드 가장자리, Battery In / DC 잭 옆의 슬라이드 스위치 (On/Off 인쇄) |

### ★ 전원 관련 필수 상식 (여기서 시간을 가장 많이 잃었다)

1. **모터 빨간 LED는 전원 인가 시 한 번만 깜빡이고 꺼진다.** 계속 켜져 있지 않다.
   "깜빡였다 꺼짐" = 12V 정상 도착. 안 깜빡이면 배터리→보드→케이블 순으로 12V 경로 점검.
2. **부팅 순서가 중요하다.** 테스트 스케치들은 *부팅하는 순간에만* 모터를 탐색한다.
   보드가 USB로 먼저 켜진 뒤 배터리를 켜면 "모터 없음"으로 판정된 상태가 유지된다.
   → **배터리 스위치 ON (LED 깜빡 확인) → 그다음 보드 리셋** 순서를 지킬 것.
3. LiPo는 실험 당일 완충. 전압 기준(3셀): 12.4~12.6V 완충 / 11.1V 이하 충전 / 10.5V 이하 즉시 충전.

## 4. 브링업 트러블슈팅 기록 (실제 겪은 순서)

| 증상 | 진짜 원인 | 해결 |
|---|---|---|
| `Dynamixel2Arduino.h: No such file` | 라이브러리 미설치 (컴퓨터를 바꾸면 재발) | Tools > Manage Libraries → Dynamixel2Arduino 설치 |
| `'EXP3_' does not name a type` + SPI/EventResponder 에러 수십 줄 | 주석 32행의 `BL_*/`·`EXP3_*/`에서 `*/`가 주석 종료로 해석 | `BL_* /`처럼 별표와 슬래시 사이 공백 |
| `DXL 57600 (1M 승격 실패)` 반복 | 배터리/모터 케이블 접촉 — 실제로는 **모터에 12V가 안 갔다**. 셀프테스트의 "57600 발견"은 실제 응답이 아니었음 | 커넥터 재장착으로 12V 복구 → `set_baud_1m` 실행 → `모터 OK @ 1000000` |
| Dynamixel Wizard 2.0에서 57600·1M 모두 스캔 실패 | Wizard는 [PC→usb_to_dxl→모터] 경로라 중간 고리가 많다 | 보드에서 직접 접속하는 `set_baud_1m` 스케치로 우회 |
| 전원/토크 인가 순간 허리가 갑자기 접힘 | 토크 ON 시 이전 목표 위치로 이동 | 테스트 스케치를 "제자리 목표 설정 → 토크 ON" 순서로 수정 (07-30) |
| φ 값 0.000 완전 고정 (노이즈조차 없음) | CS(D10)·GND 접촉 불량. 공유 MISO 때문에 **발목 데이터까지 오염**(-3.6 ↔ -43 널뜀) | φ 6가닥 재장착 → 양쪽 정상화 |
| 값이 10ms 만에 3° 튀었다 복귀 | SPI 글리치 (공유선 접촉 / 모터 전원선과 나란한 경로) | 접점 재장착, 신호선 경로를 모터선과 분리 |

### 판정 기준: 노이즈가 있으면 살아 있다

엔코더 1눈금 = 360/16384 = **0.022°**. 살아 있는 엔코더는 정지 상태에서도 한두 눈금씩 흔들린다
(예: 0.022 / 0.066 / 0.154). **흔들림이 0이고 한 값에 완전히 고정**되면 새 데이터가 안 들어오는 것 —
전기 문제(CS/MISO/전원) 또는 자석이 축과 함께 돌지 않는 기계 문제.

## 7. 작업 시 규칙

- 배선 변경은 **전원 스위치 OFF + USB·배터리 분리** 상태에서.
- 꽂은 뒤 살짝 당겨 접촉 확인. 접촉 불량이 이 시스템 최다 고장 원인이다.
- 선 양 끝에 유성펜/마스킹테이프로 이름표(예: "발목 CS")를 붙인다. 재발 시 복구가 빠르다.
- 신호선은 모터 전원선과 나란히 길게 두지 않는다(노이즈). 허리 접힘·줄 스윙에 걸리지 않게 서비스 루프 확보.
- 자석은 축 끝, 칩 정중앙과 마주 보게, 공극 1~2mm.
